# 虚拟副屏后台交互机制

评估后台界面自动化时，先区分视觉定位与页面字符定位，再核对虚拟副屏创建、输入注入和 API Key 接入的实际实现。原帖未披露的接口和权限要求需要另行查证。

帖子描述了一种后台静默操作 App 的方案：创建虚拟副屏，再向副屏发送操作指令。已提及两种页面操作方式：

- **视觉定位**：通过图像模式识别页面位置并执行操作。帖子称 OpenAI ChatGPT 与字节豆包的图像模式可用。
- **字符定位**：获取页面字符，再据此操作手机。帖子称 DeepSeek V4 的字符模式可用。

当前操作依赖 API Key 模式；作者称自我学习功能表现有限，并计划训练专属 Agent。帖子未提供虚拟副屏的创建接口、指令格式、权限要求、支持的 App 范围或各模式的准确率与验证条件，不能据此推断更多兼容能力。
