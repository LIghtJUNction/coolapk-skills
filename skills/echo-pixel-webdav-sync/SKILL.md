# Echo Pixel（像素回响）Beta

Echo Pixel 是一款多平台同步相册应用，采用纯客户端实现并支持 WebDAV。项目以 GPLv3 发布，帖子欢迎提交 PR。

帖子发布时标为 Beta，并明确提示尚未充分测试。Windows 和 Android 已测试同步、删除设备功能；macOS 当时没有经过运行测试。该状态是发布帖所述情况，不代表当前版本状态。
