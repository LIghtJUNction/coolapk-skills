# 基于 WebUSB 的浏览器设备工具：能力与边界

资料称，一款原有的安卓设备维护工具被移植为浏览器前端，使用 WebUSB 与设备通信，代码纯前端实现，并提供在线使用方式及可本地运行的单 HTML 打包版本。发布说明称其面向 Chromium 内核浏览器，且手机端浏览器也可使用；评论中作者称安装 Chrome 后可用。资料未说明所需系统版本、USB 权限与连接配置、支持的设备及具体功能清单，也未给出足以复现的安装或刷机步骤。

同一项目的两条发布说明描述的是同一个包体积比较：发布者称原有包体积为 6.3 MB，单 HTML 版本约 560 KB。这是发布者的陈述，资料没有独立验证包体积，也未验证其所述的平台支持范围。评论提及曾出现录屏静默且无状态栏提示的现象；作者回应这是 Bug，录屏代码走项目自身接口而非安卓通用接口。该讨论没有提供复现条件或修复版本，不能推断当前版本状态。
