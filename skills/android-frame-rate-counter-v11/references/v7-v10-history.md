# 帧率计：版本变化与系统兼容信息

帧率计用于监测帧率。原帖发布的版本信息如下：

- **v7：**原帖称修复所有已知 Bug，并报告在 Android 13～16 上均能正常使用。部分类原生系统的“游戏空间”也有实时 FPS 功能，且与帧率计使用同一个 API，因此两者只能选择一个开启。
- **v10：**原帖称支持 Android 12 及以上，并报告已测试 Android 12～16；修复所有已知问题，更新部分文字说明和默认设置项，增加长按桌面图标的“开始监测”快捷方式。不再引入依赖，APK 体积为 167 KB。
- v10 的最低 API 从旧版的 Android 13+ 降至 Android 12+。原帖要求从旧版升级时先卸载旧版再安装新版。
- 作者表示不打算加入电流、温度、功耗数据显示，并称可直接修改其源代码；下方提供源代码仓库链接。

公开资源：

**来源与证据边界：**兼容性与测试结果是原帖报告，未独立复测。分享链接是公开分享页，未验证文件内容或下载状态。

卸载重装是该版本作者给出的升级要求，不能由“minAPI降低”推导出所有Android应用都必须卸载。分享目录是滚动入口，不保证现在仍提供v7/v10原文件；v11另见技能主页，不把不同版本体积和修复混写。
