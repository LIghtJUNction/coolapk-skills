# 帧率计 v11

帖文列出的 v11 更新内容：

- 帧率折线图与帧率录制功能可分别使用。
- 修复部分 Android 13 设备上，相邻两个有效帧率之间插入 0 帧率的问题；未列出具体设备型号。
- 悬浮窗可分别记忆横屏和竖屏位置。
- 录制期间悬浮窗变红。
- 帧率折线图记忆展开或收起状态。
- 录制结果中的折线图支持缩放、拖动和点击。
- 帖文称安装包缩小至 102 KB。
