# Cudy TR3000 256MB 安装 K-Wrt 并配置无线与 cpolar

## 设备与刷写路径

原帖针对 Cudy TR3000 256MB 版本，列出 5V3A 电源、网线、电脑，以及过渡固件和 Kwrt 固件。分享提取码为 `1314`；原文称有 123 云盘永久链接，但未提供可见 URL。

1. 连接路由器并访问 `http://192.168.10.1`（原文插入“删”标记，按其说明移除）；创建 8 位密码，进入配置向导后退出。
2. 在高级设置的固件升级中选择 `01` 文件夹内的过渡固件并继续。原帖预计刷写约 2–3 分钟。
3. 过渡固件入口为 `http://192.168.1.1`。原帖特别说明：若经 Wi-Fi 操作，刷入过渡固件后设备可能没有无线，应改用网线。进入后无需密码，按“系统 > 备份与升级 > 刷写固件”上传 `02` 文件夹中的 Kwrt 固件。
4. 取消“保留当前配置”，勾选“强制升级”，继续刷写。原帖以指示灯停止闪烁、上级路由有网时为白色作为结果观察项。
5. Kwrt 管理入口为 `http://10.0.0.1`，原帖称登录密码为 `root`；并报告默认出现 `Kwrt_5G`、`Kwrt_2.5G` 两个无密码 Wi-Fi。

## 设置 Wi-Fi 密码

在 Kwrt“网络 > 无线”中编辑相应 SSID，进入无线安全，选择加密方式并设置密码，保存后点击“保存并应用”。`Kwrt_5G` 与 `Kwrt_2.5G` 分别配置，原帖步骤相同。

## 安装 cpolar 并映射 Kwrt

在 Kwrt 终端以 root 执行原帖命令。原文明确要求删除“删”标记，恢复后的命令为：

```sh
curl -sSL https://gitee.com/jun-wan/cpolar_script/raw/master/cpolar_kwrt_install.sh | sh
```

该 URL 是按原帖明确插入标记机械恢复，未独立验证脚本内容。原帖称安装后管理页面在 `http://10.0.0.1:9200/`。默认隧道 `kwrt-web-ui-80` 指向 80 端口；可先查看在线隧道的 HTTP/HTTPS 地址。随机域名约每 24 小时变化。设置固定地址时，先预留二级子域名，再编辑隧道，将域名类型改为二级子域名并填写所保留名称。

原帖提示管理界面暴露到公网后应修改 `root` 密码。公网实际域名和访问控制配置未提供。
