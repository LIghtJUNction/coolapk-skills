# 腾达 BE5100：断流与固件替换报告

作者报告官方固件出现频宽变化和断流，且降级、切换 MLO、双频合一等尝试未能解决。之后通过拆机 TTL 刷入集客 AP，并报告一段时间内未再出现同样问题；同时指出指示灯控制存在缺口。

这份记录没有给出原官方固件完整版本、受控网络环境和完整刷写步骤，不能据此判定所有 BE5100 都有同样故障，或推荐所有用户更换固件。

排查时先记录断流发生时间、WAN 与无线连接是否同时中断、频宽变化和设备日志。一次只改变一项配置，复测同样负载；外壳改动、温度和接入设备也需保留为条件，不把它们直接推断为根因。

采用第三方 AP 固件前另行核对硬件版本、恢复材料、制品与管理方式。帖子引用的外部刷写教程和固件未核验，当前不能提供照做步骤。
