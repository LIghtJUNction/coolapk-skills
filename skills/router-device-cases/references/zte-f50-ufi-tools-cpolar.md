# 中兴 F50 安装 UFI-TOOLS 并配置 cpolar 远程访问

## UFI-TOOLS 安装与功能

原帖将 `ZTE-UFI-TOOLS` 描述为面向中兴 F50 的开源辅助软件。列出的功能包括查看信号强度、温度、CPU 占用和 IPv6 地址，以及锁频段、锁小区、USB 调试、网络 ADB 调试、远程管理、文件共享开关、指示灯控制和性能模式切换。该功能列表来自原帖介绍，未独立核验。

原帖步骤：通过 USB 数据线将 F50 接电脑，确认设备指示灯停止闪烁；双击“一键安装器 1.2”，其会下载 `UFI-TOOLS.apk` 并启动 ADB 安装及授权。完成后用浏览器访问 `http://192.168.0.1:2333/`（原文标记恢复）打开管理页。电脑 USB 供电不足可能影响操作，是原帖给出的条件。

资源方面，原帖提到安装器下载地址及 123 云盘永久链接，分享提取码为 `1314`，但正文没有可见的实际 URL。原帖提及开发项目名 `ZTE-UFI-TOOLS`，没有仓库链接。

## 安装 cpolar 插件及映射管理页

在 UFI-TOOLS 管理页登录后打开“高级功能”，添加高级功能，再进入“插件功能”添加 `f50_cpolar_install.js` 并提交；页面刷新后点击“安装 cpolar”。原帖报告版本为 `3.3.12`，并称运行状态检测成功。插件文件的公开下载链接未提供。

cpolar Web UI 中，默认隧道 `ufi-tool-2333` 指向 UFI-TOOLS 的 `2333` 端口。原帖称无需修改端口；在线隧道列表出现 HTTP 和 HTTPS 地址，并报告通过 HTTPS 可登录及读取设备数据。具体公网 URL 未给出。

要固定地址，先在 cpolar 预留二级子域名，再编辑 `ufi-tool-2333` 隧道，选择二级子域名并填写所保留名称。原帖称随机域名约每 24 小时重置。公网管理页应使用更强登录口令；公网域名与其他访问控制条件未提供。
