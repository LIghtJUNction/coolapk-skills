# Cudy TR3000 256M 从 K-Wrt 恢复官方固件

## 适用范围与材料

原帖限定 Cudy TR3000 256M 版本，准备 5V3A 电源、网线、Windows 电脑及材料包：防火墙脚本、官方固件、官方刷机工具、静态 IP 脚本、恢复 DHCP 脚本。原帖称千兆或百兆网线均可，一根网线时接 LAN 并确保电脑能访问路由器。123 云盘提取码为 `1314`，但正文未提供可见的分享 URL。

## 恢复流程（原帖记录）

1. 先确认电脑可访问 Kwrt：`http://10.0.0.1`（原文插入“删”，按说明移除）。
2. 拔掉路由器电源，保持网线连接。以管理员身份运行 `firewall_manager.bat`，在 CMD 中选 `1` 并回车关闭防火墙。
3. 以管理员身份运行 `set_static_ip.bat`，选择以太网网卡。原帖也提到可用 `Win + R` 输入 `ncpa.cpl` 打开网络连接并修改以太网配置。
4. 将 `recovery.bin` 与官方刷机工具 `tftpd64.exe` 放在同一文件夹。按住路由器侧面 Reset 键并接通电源；原帖称刷机工具出现进度后可松开，等待刷写结束。
5. 以管理员身份运行 `restore_dhcp_ip.bat`，恢复以太网自动获取 IP。
6. 原帖以指示灯停止闪烁作为其操作结果观察项；随后访问 `http://192.168.10.1`（原文插入“删”，按说明移除），设置密码并进入官方默认页面。
