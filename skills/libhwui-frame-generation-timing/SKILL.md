# 用内核 uprobe 观察应用帧生成时间

来源：[方法说明](https://blog.xzr.moe/archives/250/)

这项方法针对使用 `libhwui` 的日常应用，通过内核 uprobe 观察帧生成相关时间。帧生成耗时与两帧之间的显示间隔是不同指标：显示间隔长可能只是界面静止，不能单独作为卡顿证据。

注册 uprobe 时，探针位置依据目标文件的 inode 和文件偏移；它不是直接填写进程虚拟地址，也不是相对于 `.text` 段的偏移。原文示例环境为 Linux 4.19，不能据此推定其他内核版本或自绘游戏也适用。本文不复述源码，也不补写原文未确认的操作命令或参数。
