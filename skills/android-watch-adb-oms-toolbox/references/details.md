# 功能、参数与限制

原帖声称依据官方开发资料；这里未独立核对 SDK 文档。正文未给出 APK 下载地址，不把 `/lite.apk` 相对路径伪装成可访问的下载链接。

## 工具架构与连接方式

工具基于 OPPO Watch 开发资料使用两条通信通道：ADB 调试通道用于安装应用、执行 shell、传文件、截图录屏和修改设置；WearSDK v0.0.9 的 OMS 通道通过蓝牙查找节点、发送消息、查询对端应用安装状态，以及让对端打开浏览器或跳转应用市场。蓝牙 OMS 不要求手机和手表接入同一 Wi-Fi；文件传输仍使用 Wi-Fi 直连。连接方式包括 USB、有线 ADB、无线 ADB 配对、固定 5555 端口、mDNS 自动扫描并以端口扫描兜底、扫码连接和蓝牙通道。

### 操作与检查

- 开启软件后可自动连接，无线断开后会自动重连。
- 连接成功后通知栏提示，并自动推送保活脚本、读取并清除手表端旧日志。
- 若固件允许直写 adb_keys，则无需弹调试授权；OW211 无法写入，每次连接可能需要在手表上点“允许”。

### 参数与路径

- 无线 ADB 固定端口：5555。
- WearSDK：v0.0.9。

### 范围与条件

- OW211：无法直写 adb_keys，可能每次连接都要手动授权。
- 资料未披露支持的 Android/Wear OS 版本范围及扫码连接的具体协议。

## 保活与微信管理

保活提供温和、标准、加强三档：温和只监测，标准定时拉起，加强在检测到目标未运行时拉起，启用加强档前会提示风险。息屏后探测间隔会收紧，以应对息屏降频导致的守护失效。功能还包括深度保活优化、系统优化与微信自动拉起、实时守护、微信被杀后拉起、息屏存活测试、一键配置权限、清除优化、查看保活详情和手表状态。微信可打开、重启、杀掉、清缓存或卸载；另可卸载微信儿童版及清理后台，清理范围可包括系统应用。系统自愈机制会在脚本进程或 OPPO 智能省电设置被系统还原时重新施加设置，不需要锁屏或停用应用。

### 操作与检查

- 选择保活强度；加强档启用前会弹出风险确认。
- 可运行息屏存活测试，并查看保活详情或手表状态。
- 长期运行建议使用标准档；加强档频繁拉起可能造成微信闪退，息屏时尤其明显。

### 参数与路径

- 息屏探测间隔：加强档 6 秒，标准档 15 秒。
- 温和档：只监测；标准档：定时拉起；加强档：发现未运行即拉起。

### 范围与条件

- 加强档对微信稳定性有影响，原帖特别指出息屏时风险较明显。
- 适用机型与系统版本未逐项列明。

### 现象与排查

- 加强档频繁拉起可能导致微信闪退，尤其息屏时；原帖建议长期挂用标准档。

## OPPO 系品牌增强与权限体检

品牌增强只向 OPPO、realme 和一加系列设备下发厂商相关设置，包括关闭 OPPO 智能省电、关闭深度睡眠、启用 OPPO 推送服务、开启通知声音。检测到非 OPPO 系设备时整轮跳过，并在日志记录跳过项数，避免向其他品牌写入不适用的厂商开关。权限体检由手表端生成权限快照，再由手机端读取，帮助发现权限或 OPPO 私有省电设置被系统升级、重装或系统还原后重置的情况。

### 操作与检查

- 在手机端读取手表生成的权限快照，查看权限是否被系统还原。
- 非 OPPO 系设备触发品牌检查后，品牌增强整轮跳过，并记录跳过项数。

### 参数与路径

- 品牌增强涉及四项：关闭 OPPO 智能省电、关闭深度睡眠、启用 OPPO 推送服务、开启通知声音。

### 范围与条件

- 品牌增强目标为 OPPO、realme、一加系列。
- 非 OPPO 系手表仍可使用工具，但品牌增强会自动跳过。
- 权限快照中 OPPO 私有省电开关可能在系统升级或重装后丢失。

### 现象与排查

- 厂商省电设置可能被系统升级或重装重置；通过权限快照识别漂移，工具的自愈功能可在相关设置被系统还原时重新施加设置。

## 设备、应用与系统控制

应用管理区分用户软件和系统软件，可解析实际应用名称、下载选中的 APK、统一卸载、查询进程与 UID，并冻结或解冻应用。激活中心集成 Shizuku、绿色守护、App Ops 和空调狗。屏幕与系统控制包括唤醒、休眠、锁屏、电源键、亮度、音量、静音、动画速度、旋转开关、方屏/圆屏/手表模式、全屏显示、屏幕常亮，以及联动修改分辨率和 DPI 的显示参数切换。

### 参数与路径

- 显示参数切换可联动设置分辨率与 DPI；原帖未给具体数值或档位。

### 范围与条件

- 激活中心列出的集成项为 Shizuku、绿色守护、App Ops、空调狗；具体版本与授权要求未说明。

## 实用工具与系统操作

工具提供截图到手机、从手表拉回录屏、录屏保存到手表、网络诊断（Ping、Wi-Fi 信息、手表侧连通性）、手表校时、新旧表硬件验机、基础信息、存储与内存、电池健康、加速度/陀螺仪/心率传感器读取、存储清理、文件管理和 shell 终端。文件管理支持多选批量安装、下载和传到手表。系统操作包含重启、关机、高级重启到 Recovery 或 Bootloader、返回桌面；本机不支持恢复出厂。

### 范围与条件

- 恢复出厂：本机不支持。
- 原帖未列明验机覆盖的硬件项目、传感器读取权限或系统版本条件。

## WearSDK / OMS 蓝牙通道

蓝牙通道功能包括检测节点配对、测试消息通道、读取手表状态、启动或停止手表保活、获取手表 IP。它不依赖手机与手表连接同一 Wi-Fi。原帖标注单条消息不超过 100K（未明确十进制或二进制单位），只允许 http（80）、https（443）和 websocket，因此文件仍须通过 Wi-Fi 直连传送。

### 操作与检查

- 检测手表蓝牙节点配对状态。
- 测试 OMS 消息通道，并可通过通道读取状态、控制保活或获取手表 IP。

### 参数与路径

- 单条消息上限：原帖写 100K，未明确计量基数。
- 通道允许的协议/端口：HTTP 80、HTTPS 443、WebSocket。

### 范围与条件

- 依赖 OPPO Watch 开发资料中的 WearSDK v0.0.9 OMS 通道。
- 文件传输不走该蓝牙消息通道，需 Wi-Fi 直连。

### 现象与排查

- OMS 返回 28 通常意味着手表端 App 被系统冻结或回收，导致消息无法递达；探针正常不能证明对端正在接收。
- 蓝牙发送偶尔出现 3015 超时，原帖建议重试。

## 手表端界面与手机综合版

手表端提供 Wi-Fi 上传临时网页，手机浏览器可通过二维码将安装包传入手表，无需数据线；另设 /lite.apk 入口，可将手机版下载链接显示为按钮。不过当前描述的内嵌包已精简，页面会自动隐藏该入口。手表界面还显示保活状态、优化页，并提供 DPI 基础密度、日志置顶、中文应用名等设置。手机综合版在手机 App 内嵌手表版安装包，内嵌包为 2.36 MB，已移除其内部的手机版以避免套娃；整包 5.6 MB。连接手表后会检查是否已安装手表版，未安装时提示用户，只有点“要”才推送安装，点“不用”则不操作。桌面名仍为“通用工具箱”，设置页版本信息第一行显示“手机综合版”用于识别。

### 操作与检查

- 使用手表 Wi-Fi 上传页扫码或通过手机浏览器上传安装包。
- 手机综合版连接手表后检查手表版安装状态；只有用户选择“要”才推送安装。
- 在设置页检查版本信息首行是否为“手机综合版”，以辨认手机综合版。

### 参数与路径

- 手表版：2.0.0（100166）。
- 手机版综合版：3.2.0（60000256）。
- 内嵌手表版安装包：2.36 MB；手机综合版整包：5.6 MB。

### 范围与条件

- 当前内嵌包已精简，Wi-Fi 上传页面会自动隐藏 /lite.apk 下载按钮入口。
- 手表版与手机版版本号分别列出；未提供 Android 系统最低版本或具体兼容机型清单。

## 机型与已知限制

非 OPPO 系手表可使用通用功能，品牌增强会跳过。华为鸿蒙表采用独立 HDC 分支，能力项与本文所述工具并不完全相同。OMS 错误码 28 通常与手表端应用被冻结或回收有关；通道探针正常并不代表对端正在收消息。蓝牙发送错误 3015 为偶发超时，可重试。

### 操作与检查

- 发生 OMS 返回 28 时，应考虑对端 App 已冻结或被回收，不能仅凭探针正常判定消息链路可用。
- 发生蓝牙发送 3015 超时，按原帖说明重试。
- 长期保活优先使用标准档，降低加强档频繁拉起造成微信闪退的风险。

### 范围与条件

- 非 OPPO 系：通用功能可用，品牌增强自动跳过。
- 华为鸿蒙表：使用独立 HDC 分支，功能项不完全相同。
- 原帖标题指向高配 OPPO Watch，但没有给出具体 OPPO 型号适配清单。

### 现象与排查

- OMS 返回 28：多半是对端 App 被系统冻结/回收；探针正常不保证对端能接收。
- 蓝牙发送 3015：偶发超时，重试。
- 加强档频繁拉起微信可能造成闪退，尤其息屏时；长期使用建议标准档。
