# 屏译 v0.4.8：Android 悬浮屏幕翻译

## 项目与版本

原帖称屏译是 Android 开源屏幕翻译器，主仓库 `https://github.com/ciddwd/overlay-translator`（原帖给出仓库名，补全 HTTPS 为推断），Apache-2.0。v0.4.8 于 2026-10-24 发布，原包 56.5 MB，最低 Android 8.0，仅提供 `arm64-v8a`，不需要 root 或注册。

## 屏幕翻译流程

在漫画、视觉小说或单机游戏中点悬浮球，应用截取屏幕、执行 OCR、翻译并将译文叠回画面。划词模式可框选局部；长按可更换语言或区域、开启循环翻译，画面稳定后自动重译。还包括相册批量翻译、划词释义、译文朗读和术语表。

识别与翻译可分别更换：本地 OCR 包括 ML Kit、PaddleOCR，以及面向竖排日漫的模型；原帖称本地 OCR 图像不上传。翻译端可选离线模型或 DeepSeek、DeepL、Google、有道等服务。屏幕截图交给应用的是图像，必须先 OCR 才能翻译；细字、描边和复杂背景会增加识别难度。应用也可通过局域网 HTTP 调用电脑上的 Umi-OCR 或 LunaTranslator 识别服务。

权限和设备限制：需要悬浮窗与屏幕共享权限；Android 14 以上每次重新开启截屏服务需要再次确认。部分小米、OPPO、vivo ROM 可能杀后台，原帖建议为应用设置电池白名单。

## 在线、离线与费用

应用本体按 Apache-2.0 开源且无订阅。选择云端翻译、在线 OCR 或大模型服务时，可能需要自行配置 API Key 并按量付费。原帖称 v0.4.8 内置“B站翻译（免费）”可不填 Key 联网使用。

离线使用需要下载端侧 OCR 和翻译模型，体积从数百 MB 到数 GB；原帖建议使用 Wi-Fi 下载，低内存设备可能无法稳定加载，端侧推理主要使用 CPU。模型大小和设备负载会影响体验。

## 视频双语字幕

v0.4.8 增加语音识别模式：识别手机正在播放的声音，并在画面上同时显示原文与译文。可选本地 SenseVoice、Zipformer、Whisper。该功能需要 Android 10 以上、录音与屏幕共享权限。原帖转述 README 称此功能仍为初版，准确度、断句、延迟和服务兼容性仍在优化；部分播放器限制音频采集。在线识别会上传音频并可能收费。

## 安全边界

项目说明带反作弊的网游可能把系统截屏视为外挂行为，适用范围是单机游戏、视觉小说和漫画。设置安全标记的画面（例如部分网银或视频应用）可能截取为黑屏，应用不绕过此限制。屏幕共享权限可读取屏幕内容；API Key 据原帖称加密存储，导出配置不包含明文，明文 HTTP 仅允许局域网。
