# 相机自动水印工具与 Rust 版罗技鼠标轻量化工具

整理自酷安社区短帖发布记录（未读配图与外部网盘）。

- **相机自动液态玻璃水印工具**：[酷安原帖](https://www.coolapk.com/feed/75028875)（`imgs=4`）— 选择预设或自定义水印并开启监听模式后，使用谷歌相机或原相机拍照可自动添加预设水印。
- **Rust 重写罗技鼠标 Windows 工具**：[酷安原帖](https://www.coolapk.com/feed/74728058)（`imgs=2`）— 针对罗技官方软件与社区 Python 工具后台内存占用偏高的问题，使用 Rust 重写 Windows 端第一版以降低内存占用。
