# 实用工具案例：Liquid Island BETA8、轻量化跳广告、九号出行 NBFIX 与 Hana Agent

本参考整理酷安社区中四款 Android 实用工具与自动化方案的功能边界、架构取舍与权限/兼容说明。图片、评论与外部网盘/APK 均未在本库下载或实机验证。

---

## 1. Liquid Island BETA8（灵动岛修改版）权限与 ADB 联动

- **来源**: https://www.coolapk.com/feed/75049745
- **原版 BETA8 核心更新**:
  - 计时器/秒表支持从控制中心直接启动（需配套最新版 `Liquid Clock`），闹钟在主屏幕触发时改在灵动岛显示。
  - 新增 ADB 功能管理，分别控制 Face ID 解锁监控、屏幕捕获、状态栏颜色检测、系统命令、窗口与通知栏跟踪。
  - 低电量提示调整为 `< 20%` 显示且开启省电模式时不重复提示；浏览器播视频时不再误报下载中。
- **修改版变更与权限机制**:
  - 补全中文资源至 931 条，移除包体签名校验与 Beta 激活验证，设置中的 Developer Panel 免码直接进入。
  - **Shizuku 自动授权**: 当 Shizuku 已连接且授权给 Liquid Island 时，尝试自动补齐录音、通知、电话/通话记录/联系人、蓝牙、悬浮窗、使用情况访问及修改系统设置权限。
  - **无障碍与悬浮窗**: 需手动在系统设置授予“显示在其他应用上层”与无障碍服务（用于全局悬浮、窗口检测与部分截屏/锁屏功能）。

## 2. 68.8KB 极简开屏跳广告工具的扫描架构与过滤边界

- **来源**: https://www.coolapk.com/feed/75038993
- **体量与性能策略**:
  - 安装包 `68.8KB`（13 个文件、4455 行代码、5 项权限）。
  - 单屏探测约 22 个探测点（前 1 秒探测 11 次），单次扫描仅遍历一遍节点树（上限 250 节点）同时判定文字、控件 ID 与广告容器；命中广告容器后切入快速通道仅查该容器，扫描耗时偏高时自动退让降频。
- **三类识别与三层系统排除规则**:
  - **白名单尾部关键词**: 仅匹配“跳过广告”“点击跳过”“跳过5s”等，明确排除“跳过联网”“跳过片头”“跳过新手引导”。
  - **广告容器锚点**: 针对将跳过按钮绘制在 Canvas 上的应用（如 `ad_container` / `ksad_container` / `splash_container`），在容器内查找跳过节点、可点父节点或空心圆环按钮；控件 ID 仅在窗口类名像开屏（如 `SplashActivity`）时启用。
  - **系统排除**: 跳过无桌面图标的系统组件（状态栏、输入法、安装器、权限弹窗）及 `com.android.` / `com.google.android.` 系统工具，仅处理普通应用窗口；厂商自带商城/应用市场则保留跳过。支持流式扫描规则源（约 1.4MB，25ms 解析）更新容器锚点。

## 3. 九号出行 NBFIX-6.0（6.10.13 内嵌版）兼容取舍

- **来源**: https://www.coolapk.com/feed/75042261
- **方案变化与兼容边界**:
  - 原计划基于 6.10.12 脱壳版更新，后改为无需脱壳直接在官方 `6.10.13` 包上内嵌适配（一体版约 `322MB`，免 Root、免 Shizuku、免 LSPatch）。
  - **为何不发独立 LSPosed 模块**: 原帖实测单独模块在 LSPosed 下无法稳定通过九号出行的易盾检测。
  - **版本与安装限制**: 仅适配 `6.10.13`；因签名不同不能覆盖安装，需卸载官方版后重装并重新登录（该版已修复上午版在 ColorOS 上的兼容问题，并在行程列表新增「匀速」「极速」显示）。

## 4. Hana：开源 Android 手机端 AI Agent（Apache-2.0）

- **来源**: https://www.coolapk.com/feed/75034512
- **开源仓库**: `https://github.com/mengqingshi922-ctrl/hana`（Apache-2.0）
- **运行条件与边界**:
  - Android 12+ 可操作 App（推荐 Android 14+），需预先配置支持工具调用的模型，并完成手机操作设置与无线调试配对。
  - 支持自然语言多步操作 App 与网页、提醒定时任务及文件处理；登录、验证码、密码与付款等敏感步骤需人工接管。
  - **演示观察边界**: 原帖录屏展示尝试在小米钱包看广告领会员奖励，中途存在广告跳转与重试；工具回报“领取完成”不代表奖励实际到账，需回原 App 核对。
