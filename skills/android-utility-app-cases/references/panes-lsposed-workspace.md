# 格窗工作台 LSPosed 模块（Android 15+ 多系统作用域与 NeXtep 互斥）

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- #### [酷安原帖](https://www.coolapk.com/feed/74753611)（imgs=8 未读）
  - **模块名称与包名**：格窗工作台（包名 `io.github.yishisanren.panes`），前身为开源项目 NeXtep（包名 `io.github.lujinxin.nextep`，致敬锤子 OneStep）。两模块互斥，使用前必须在 LSPosed 中停用并卸载 NeXtep。
  - **运行环境要求**：Android 15 及以上版本，需 Root 与 LSPosed（支持 libxposed 新 API）。
  - **多系统作用域勾选规范**：
    - 小米澎湃 OS：SystemUI、系统框架、系统桌面、智能助理。
    - OPPO / 一加 / realme (ColorOS 16/17)：SystemUI、系统框架、桌面、应用分身服务、负一屏。
    - 类原生 ROM：SystemUI、系统框架。
  - **功能机制与限制**：
    - 侧边工作台支持 1 个大窗与 4 个小窗实时并存与点击交换，小窗支持上滑快捷关闭，长按可设置应用暂停、实时运行或关闭。
    - 提供应用手势黑名单（游戏免触发）、横屏视频置顶/全屏播放、双工作场景保存与桌面快捷方式。
    - 支持配合 Tasker 自动化命令调用。系统移植版和魔改版不保证动画与稳定性。免费版覆盖基础一大四小与 2 个场景；第 3 个场景、横屏视频常驻、小窗暂停等需内购解锁。
