# 通用安装程序 v1.20.0：Android 安装会话与特权后端

## 版本与平台

原帖介绍的通用安装程序采用 Kotlin、Jetpack Compose / Material 3 与 Ackpine 安装引擎，GPL-3.0。v1.20.0 于 2026-10-25 发布，最低 Android 7.0（`minSdk 24`），`targetSdk 36`。手机版约 6.96 MB；Android TV 版约 3.80 MB；Wear OS 版约 5.16 MB。原帖分享还包含 SHA-256 校验文件。

## Android 安装的三类障碍

1. **厂商拦截**：部分厂商安装器会因设备厂商策略阻止安装某些来源的 APK。原帖称此类拦截与 APK 来源、签名并非同一判断。
2. **分包安装**：应用可能按 CPU ABI、屏幕密度、语言拆成多个 APK，常见打包形式包括 XAPK、APKS、APKM。系统安装会话一次只处理一个应用，但会话可包含多个分包；安装时需选中适配设备的分包。
3. **版本、系统要求和权限**：系统可能拒绝低版本降级或不满足最低 SDK 的应用；普通安装流程还需逐次确认，批量安装不便。

普通应用即使换成其他安装器，通常仍要请求系统包管理服务创建安装会话，最后由系统确认。原帖将直接使用 `pm install` 描述为 shell 身份安装路径；电脑 ADB 与手机 Shizuku 可提供 shell 权限。该工具提供系统安装器、Shizuku、Root 三种后端。

## 不同后端的能力

系统安装器（零特权）可在同一安装会话中安装分包。工具可按本机 ABI、DPI、系统语言及英文预选分包，并允许安装前修改。它不会把不适配的 x86 或 `v7a` 分包一并安装。

原帖称游戏包中的 OBB 会解压到 `Android/obb/`。Android 11 之后该目录受系统限制，直接写入失败时依次尝试 Shizuku 与系统文件夹选择器。

接入 Shizuku 或 Root 后，原帖列出的额外能力包括静默安装和卸载、允许降级、绕过最低 SDK 限制、安装给所有用户、安装后授予全部权限，以及将安装来源标记为 Google Play、F-Droid 或 Aurora。应用是否接受这些来源标记取决于其自身检查逻辑。

Shizuku 需在重启后重新激活，可通过无线调试配对或连接电脑；未激活时退回零特权能力。原帖称要用 Shizuku 绕过部分厂商拦截，首次设置 Shizuku 前仍需处理设备纯净模式限制。授予 Shizuku 等于让安装程序取得较高安装权限。

## 附加功能与适用边界

原帖称可选 VirusTotal SHA-256 查询：需要用户在 `virustotal.com` 申请免费 API Key 并在设置中填写，扫描需手动发起；免费额度原帖记为每分钟 4 次、每天 500 次。未收录文件可按需上传，原帖所述上限为 650 MB。该功能默认关闭。多引擎检测结果不能单独证明文件安全。

内置 HTTP 服务器和网页面板可让电脑浏览器将 APK 传到手机，可选 PIN；同一 Wi-Fi 下可将包推送至 Android TV，电视扫码接收。TV 与 Wear OS 有独立安装包，可通过遥控器操作。

鸿蒙 5.0 以上按原帖所述不支持安装 APK；这是原帖对平台现状的陈述。仅有手机端应用，没有独立电脑管理软件。
