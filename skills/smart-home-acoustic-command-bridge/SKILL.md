# 用天猫精灵语音触发追觅扫地机自定义清扫

## 适用场景

当追觅设备已绑定天猫精灵，但天猫精灵只能执行开关等基础控制，而你希望触发追觅 App 中预设的房间清扫时，可以用天猫精灵播放一段语音，让追觅设备按自己的语音指令执行。

原帖实际示例是“天猫精灵控制追觅 S20”，并未展示小爱同学的配置或验证结果，因此不能据此认定双向互控已经实现。

## 配置步骤

1. 在追觅 App 中创建快捷指令，示例内容为：只清扫厨房区域，扫拖 1 遍，拖地 2 遍。快捷指令名称和具体选项以 App 实际提供的功能为准。
2. 在天猫精灵 App 中创建场景，设置所需触发条件；原帖没有指定具体触发条件。
3. 将场景动作设为播放自定义语音，示例内容依次是“你好，追觅”、停顿 3 秒、“打扫厨房”。
4. 确认扫地机能听到天猫精灵播放的语音，并且设备当前支持且识别“打扫厨房”这一实际指令，再试运行场景。

## 条件与限制

- 这是通过设备扬声器和语音识别桥接控制，不是云 API、Home Assistant 集成或设备间的原生跨平台控制。
- 3 秒停顿是该示例的设置，不保证适用于其他设备、房间或语音识别环境；应按实际识别效果调整。
- 需要追觅 App 支持所需的快捷指令，也需要目标设备支持相应语音命令。
- 原帖未提供下载链接或更细的设备兼容性资料。
