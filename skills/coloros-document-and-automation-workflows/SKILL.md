# ColorOS 文档与通知自动化工作流

按任务读取对应参考，核对当前设备中是否存在入口。来源中的ColorOS版本、演示设备和资格要求分别记录；话题标签或礼盒来源不构成全品牌兼容清单。

- 需要纸面材料电子化时，读取[扫描与PDF/Word流程](references/source-73976862.md)：文档APP或AI拍一拍的扫描入口、几何矫正与输出格式；作者的耗时和打印效果不是本库测量。
- 需要整理复习资料时，读取[AI笔记学习流程](references/source-73834707.md)：导入录音/图片/视频链接或扫描素材，选择多篇笔记整合，再基于内容生成练习；滚动记忆卡额外依赖小布Next体验资格。
- 需要把NFC触碰接入现有自动化软件时，读取[通知参数匹配](references/source-73867322.md)。来源依赖“NFC服务”通知，须同时匹配`android.title`与`android.text`，不能把所有NFC通知都当成目标触碰；可追加手动确认。保留该系统示例原始文本，不假定其他系统/语言相同。
- 需要分享现有应用安装包时，读取[桌面APK分享](references/source-73984494.md)：长按图标→分享，来源报告默认文件名`base.apk`；未验证所有应用或版本均适用。
- 需要给NFC墨水屏画框传图时，读取[光影画框与显示色差](references/source-73788610.md)：APP配对后通过NFC传图，色差可尝试在APP调整再导入；没有电池或续航实测，不把墨水屏推断当成保证。

这些记录给出可复查的具体路径与条件，未执行手机操作。图片和完整评论未读；不同机型入口变化时保留差异，不从相近功能猜出设置项。
