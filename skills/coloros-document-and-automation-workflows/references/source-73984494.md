# ColorOS 桌面分享应用安装包

在 ColorOS 桌面上，长按应用图标并点击“分享”，可以快速分享该应用的 APK。原帖称此功能已在此前多个大版本中上线，但没有提供具体起始版本或适用机型。

原帖报告：分享出的 APK 默认命名为 `base.apk`。该操作用于分享应用安装包；原帖未说明分享流程是否适用于所有应用，也没有独立测试结果。
