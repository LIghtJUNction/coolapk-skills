# 用 NFC 门禁卡误识别通知触发自动化任务

## 原帖报告的现象

原帖称，在 ColorOS 设备上让一张 NFC 小卡碰触手机的 NFC 感应区域时，系统会将其误认为门禁卡，并由「NFC 服务」发出通知。原帖报告该通知无法关闭，默认以静默通知显示在通知中心。此现象来自作者体验，未提供设备型号或独立验证信息。

## 自动化思路

所需条件：

- 能监测应用通知的自动化软件；原帖以 FV 悬浮球为例。
- 能触发上述 NFC 通知的 NFC 物件。

配置步骤：

1. 为自动化软件授予通知检测权限。
2. 新建自定义任务，将触发应用设为「NFC 服务」的通知。
3. 获取通知参数 `android.title` 和 `android.text`。
4. 同时判断标题为「检测到门禁卡」，内容为「添加到手机， 一碰开门」。原帖强调两项都要匹配，以免 NFC 服务的其他通知误触发。
5. 可选：匹配后增加手动确认窗口，减少误操作。
6. 条件满足后执行自定义任务。原帖示例是打开音乐；也提到可用于打卡、签到、收取能量或转存文件，这些是用途设想，不代表原帖已逐一实现或测试。

原帖以 ColorOS 17 为话题标签，但未写明测试机型、系统构建版本或 FV 悬浮球版本；其他自动化软件是否能读取相同字段及触发条件，需按其功能配置。
