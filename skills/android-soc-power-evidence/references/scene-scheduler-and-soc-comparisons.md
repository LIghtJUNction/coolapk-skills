# SCENE 调度参数、防盗版边界与 SoC 性能功耗对比记录

本记录整理自 5 篇社区技术动态，图片内容均未读取，未在本库实机复现。

## 1. SCENE 7.2 LP 辅助调速器与帧率/线程参数 [55357104](https://www.coolapk.com/feed/55357104)

- **辅助调速器新增参数**：
  - `excludes`：计算对应 cluster 负载时忽略指定核心的负载，用于将后台进程集中到单颗小核并避免拉高整个 cluster 频率。
  - `mt`：`mt=100` 时由“按最高核心负载调频”改为“按 cluster 多核平均负载调频”，以降低小核对零碎单核负载的敏感度（7.1.1 起非交互状态默认 `mt=100`）。
  - `capacity`：限制 cluster 所有核心负载之和不超过设定上限（例如 3 核设 `3300000` 可单核 `3300MHz` 满载或三核 `1100MHz` 满载）。
- **无操作降帧与核心分配**：
  - 聊天、音乐、阅读、短视频等应用在无用户操作时将帧率上限降至 `30`，减少静态页面下 GIF/动画/广告刷新带来的额外能耗。
  - `app_cpuset` 将普通应用线程分为主线程、渲染线程、其他线程三类并在交互状态分配核心，非交互状态还原默认；游戏 `cpuset` 增加中核/大核 IPC 描述以辅助线程放置。

## 2. SCENE 免费/付费边界与更新分发说明 [68665581](https://www.coolapk.com/feed/68665581)、[72759131](https://www.coolapk.com/feed/72759131)

- 授权边界：首次安装提供 15 天试用；仅全功能 ROOT 模式需续费，已发布版本的 ADB 基础模式免费；界面带广告或吹嘘优化效果的均为盗版。
- 更新服务端背景：原帖说明早期将更新包放于 OSS 直链曾遭遇单月数千元流量刷取及峰值 `100Gbps` 级别 DDoS 攻击，导致更新服务偶发中断。

## 3. SoC 游戏帧率与核心缓存功耗对比

- **天玑 9400 vs 9500（相同调度策略下）**[72244693](https://www.coolapk.com/feed/72244693)：原帖报告《王者荣耀》中二者性能与功耗接近；《和平精英》大战场模式下 `ace6u`（开启 120 帧）基本稳定 `117` 帧，而 `ace5u` 与 `x300` 在高温度下仅约 `70–80` 帧。
- **天玑 9300 中核 vs 骁龙 7+ Gen 3 大核（同为双电池）**[54645810](https://www.coolapk.com/feed/54645810)：原帖对比两者 X4 核心表现，指出 7+ Gen 3 大核在缓存规模较小的同时仍保持较高功耗，而 9300 中核在温控降频至 `2.6GHz` 后分数仍高于前者且功耗更低（原帖未读取配图中的具体分数与功耗数字）。
