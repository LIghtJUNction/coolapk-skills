# Android SoC 功耗与频点证据整理

本文把四条公开动态中的可复核信息整理为测量方法与案例线索。它们是特定设备、固件和测试条件下的资料，不构成所有机型的通用精度保证。图像内容未读取，不能从图片推断数据。

## 软件遥测与外部供电读数

PerfDog 等软件遥测与外部供电测量的读数来自不同测量路径。软件采样可能存在采样率限制和延迟；特定瞬时点应记录采样时序，并避免把软件曲线的单点当作瞬时真值。长期平均值、区间范围、轮次均值是不同统计量，报告时应分别列明。

一项骁龙888匿名机型对比中，作者在该单机测试范围内报告了软件和外部供电平均功耗差异未超过其设定的±5%界线。此结果只对应该设备与测试条件，不能推广为所有机型、负载或瞬时采样的精度结论。该试验中C1与C2同时改变供电电压和散热条件，因此结果不能解释为单独比较软件与仪器的影响。详细参数与原文统计值见[外部供电对比参考](references/perfdog-vs-supply-case-2021.md)。

原文转述的PMIC短时瞬时误差约±25%、长时间平均误差约±3%，没有附上DataSheet或具体PMIC型号、条件，属于未经该材料独立核验的二手说法，不能当作通用精度。66319D原文参数的条件缺口及对官方用户手册的补充核对，见下方外部供电参考；不把仪器额定范围当成被测手机的接线参数。

以下复核规则为从案例归纳的整理建议，不代表来源已完成全部实验控制。

## 对比实验的控制与记录

要让另一人能复核结果，至少记录：设备型号及样本标识（公开文档中使用匿名标签即可）、系统版本、测试软件版本、日期、供电与散热条件、屏幕亮度/分辨率/刷新率、声音状态、网络与后台控制、每个场景的持续时间和轮数、开始与结束事件定义，以及读数如何汇总。

相关案例采用恢复出厂设置、不插卡、关闭定位/蓝牙/NFC、开启飞行模式、测试前通过 `adb shell top` 查看进程、测试中不触碰屏幕；桌面待机静置两分钟后开始测量。GeekBench 5测试在处理器跑分开始时启动记录，在结果达到100%并显示上传时结束。此类同步规则应逐项写明；若测试动作和记录边界不同步，跨设备对比就难以解释。

对轮次数据应保留每轮值或可审计的原始导出，并明确均值、标准差、差值和百分比的计算定义。只给汇总数时，第三方无法核验轮次分布、异常值处理和标准差。表格中保留原文标签时，应同时标示其计算定义，不能把不同分母或先平均后求比的口径混为一谈。

## 样本差异与曲线争议

同型号三台设备的案例报告了七个场景下C2、D3、D4的平均功耗及作者定义的差异指标。其C2使用4.2V外部供电并直接接触主板散热，D3/D4则是整机加背夹；多个条件不同，不能把全部差异唯一归因于芯片体质，也不能据此认定漏电已证实。详细数值、统计口径与限制见[同型号三台样本差异参考](references/soc-sample-variance-case-2021.md)。

另一条讨论质疑“整机功耗减屏幕功耗”曲线的零点，并提及所谓19%差异、三星S21 PMIC差异说法及日常轻载观点。这些均应作为来源观点保留，不当作已证实定律。单样本结果不能代表整个型号；轻载体验也不能替代持续高负载测试。讨论原文写作 `4.7w/125fps`，作为宣传对照；未展开 w 的含义、测试项目和完整口径，不改写成“4.7万分”或确定的瓦数，也不当作实测结果。
