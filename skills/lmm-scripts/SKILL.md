# 跨平台 AI 开发环境脚本索引与审阅提示

帖子将 `https://api.lmm.best/scripts` 描述为 AI 软件及本地 AI coding agent 配置脚本的菜单或索引页，并称脚本覆盖 Windows、Linux 和 macOS。输入资料还提到可通过交互菜单选择安装配置脚本，以及可向源码仓库提交改进。脚本列表、具体依赖和平台适配细节未提供。

## 执行前审阅

一帖给出通过 `curl` 或 PowerShell 获取菜单脚本并执行的示例，同时建议将管道后的解释器替换为 `less` 等查看程序，先检查内容；也可以交由 AI 分析。此建议只能帮助阅读脚本文本，不能证明脚本安全，也不能替代对下载来源、后续下载内容及执行副作用的审计。

输入中出现的 Shell 与 PowerShell 地址带有结尾双引号，按原样记录在资源清单中；其 URL 格式和可访问性未核验，不应直接当作已确认的脚本直链。

## 证据与限制

菜单页、脚本仓库、图片及脚本内容均未读取。平台覆盖和脚本用途是帖子描述，未实测。使用前应补读仓库和具体脚本，并核对目标系统、安装内容与执行权限。
