# UniXNU 移植进展记录与核查

## 记录已声明的进展

按设备和功能逐项记录社区帖文明确提到的状态，并标注为“社区进展声明”：

- 设备：红米 K90 Pro Max。
- GPU：帖文称工作正常。
- 屏幕刷新率：帖文称 120 Hz 工作正常。
- Userdata：帖文称可持久化存储数据，不再是临时启动。
- IPA 侧载：帖文称已成功侧载自签名 IPA。
- App Store 应用：帖文称仍在尝试支持；作者认为 Apple ID 登录不可行。

## 核查与表述流程

1. 将每项能力拆开记录，注明来源帖和原文时间语境；不要把某项进展推及其他设备或功能。
2. 区分“帖文声明已完成”“仍在尝试”和“未提及”。作者自述可作为进展记录，但不是独立验收证据。
3. 未取得独立测试材料时，使用“帖文称”或“社区进展声明”等归属表达，不写成已验证结论。
4. 不把自签 IPA 侧载等同于 App Store 应用已支持；不得写成 iOS 全兼容，也不得补造安装命令。
5. 图片未读取时，不从图片推断额外设备、步骤或结果。
