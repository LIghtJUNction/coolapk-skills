# 无线调试配对与 Scene 激活

## 来源与设备范围

来源：[一加16无需电脑，免禁用权限监控，使用ADB工具激活Scene等软件教程](https://www.coolapk.com/feed/74374851)，发布于 2026-10-15。正文提到一加16；标签却写“一加15”。这一差异按原文保留，不能据此认定教程经过两款设备验证。评论是所保存页面中的个案，不代表全系列兼容性测试。

## 正文流程

教程分为配对、连接、激活三阶段：

1. 打开 ADB 工具，点击正文图示按钮后切换到小窗。在开发者选项启用 USB 调试和无线调试，再进入无线调试界面。
2. 选择“使用配对码配对”，输入配对码及地址、端口并点击配对。配对成功后，下方会显示设备；长按图示区域并复制其内容。
3. 在工具中粘贴复制的内容以连接。连接成功后从下方设备入口进入图示的工具界面，选择“运行命令”，输入 ADB 指令完成激活。

原帖未在文字中给出图示所示按钮名称、配对地址/端口或激活命令；不要自行补造这些内容。

图6的界面内容尚未读图核验，不能把它确定为Scene自身界面。

## 评论中的具体命令与排错

在 Scene 界面反复跳回初始页的问题串中，作者给出的命令为：

```sh
adb shell sh /storage/emulated/0/Android/data/com.omarea.vtools/up.sh
```

该命令保留原评论中的 `adb shell` 客户端前缀；输入材料没有确定所用终端是否已处于设备shell中，不能重复嵌套前缀或擅自改写为当前工具的保证命令。实际应以相同版本应用自己显示的激活命令为准。

命令来自作者评论 [612826711](https://www.coolapk.com/feed/74374851)，对应提问 [612822190](https://www.coolapk.com/feed/74374851)。作者随后说明应复制 SceneN1 里的命令（[612830714](https://www.coolapk.com/feed/74374851)）。同一问题串中，用户报告先进入基础模式、清理后台中的 Scene，再重新打开 Scene 进入 ADB 模式运行命令后问题消失（[612825358](https://www.coolapk.com/feed/74374851)）。这是用户报告的排错经历，不是保证步骤。

另有作者对卡在界面问题回复“重启试试”（[613345105](https://www.coolapk.com/feed/74374851)、[613350966](https://www.coolapk.com/feed/74374851)），没有后续确认结果。
