# 进程 UID 上下文与 su 截图演示

来源：<https://www.coolapk.com/feed/65740496>

原帖记录的是涉及 root 的本机演示步骤。它描述了使用 MT 管理器查看 ChatGPT UID，再运行 `chid.so` 和 `su` 来准备截图。原帖中的 UID `10323` 是该设备上的样例值，不代表其他设备上的 ChatGPT 或任何应用都使用相同 UID。

## 原帖步骤与命令

1. 用 MT 管理器查看该设备上 ChatGPT 的 UID；示例为 `10323`。
2. 执行：

   ```sh
   su -c exec chid.so 10323
   ```

   原帖称 `chid.so` 用于更改当前进程的 UID，并称可从 ShizukuRunner 安装包内解压得到。原帖没有提供 ShizukuRunner 下载链接、`chid.so` 源码或可核验的文件，因此这里不补造获取地址或实现细节。

3. 执行：

   ```sh
   su
   ```

4. 截图。原帖还给出可选的截图准备命令：

   ```sh
   sleep 5;su
   ```

   这是原帖描述的截图准备方式，不是对该操作效果或通用可用性的验证。

## 进程上下文与证据边界

- `su -c` 启动的命令涉及子进程上下文；子进程改变自身 UID 不会回写父 shell 的 UID，也不能仅凭这一点推断目标 APP 进程的 UID 已改变。
- 原帖没有说明 `chid.so` 是否会 `exec` 出 shell，也没有说明 `su` 如何解析或处理这些参数。现有文字和截图不足以证明目标应用发起了真实的 root 请求，或证明这些命令在其他设备、系统版本和 `su` 实现上可用。
- “更改当前进程 UID”的具体实现与执行结果未在原帖中得到独立验证。具体实现和结果仍待源码与实际进程状态核对。
- 本文只用于理解已授权本机调试中的身份上下文；没有执行命令、提取程序或核验截图。
