# 无线调试 UI 案例

原帖：[一加无线调试激活教程](https://www.coolapk.com/feed/74374851)。正文首句写“一加16”，标签为“一加15”；机型信息存在差异，不能据此确定适配机型。

原帖描述三个阶段：

1. **进入无线调试并配对：**打开软件，点击图 1 按钮后切换至小窗；在开发者选项打开 USB 调试和无线调试，点击图 2 箭头进入无线调试界面。选择图 3 的配对码配对，输入配对码和地址、端口后点击配对。配对成功后，下方会显示设备。
2. **复制连接信息：**长按图 4 方框中的内容并复制。
3. **连接并执行激活：**在图 5 的输入框粘贴刚复制的内容；连接成功后通过下方设备进入图 6 软件界面，选择“运行命令”，输入 ADB 指令激活。

正文没有给出 App 名称或实际激活命令；不得据此编造。主帖把软件入口指向评论；本页只复述主帖UI流程，另见[评论中的分享、提取码与具体命令](resource-followup.md)。配对、连接与目标应用激活是不同阶段，正文未提供可核验的最终激活结果。
