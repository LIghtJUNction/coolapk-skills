# 逐句递增 LaTeX 字号

## 适用场景
用于尝试让多句话分别显示，并按句子顺序增加字号。此方法只记录原帖提供的语法，不保证所有聊天界面或公式渲染器都支持。

## 方法
1. 尽量让每句话简短，并让每句话单独换行。
2. 按顺序选用以下命令：`\small`、`\normalsize`、`\large`、`\Large`、`\LARGE`、`\huge`、`\Huge`。
3. 原帖建议每句话使用独立的块级公式，并以 `\text{...}` 包裹句子内容。原帖显示的定界符仅为方括号；整理示例补入反斜杠表示块级公式，尚未在目标聊天界面实测：

```latex
\[
\small \text{第一句话}
\]

\[
\normalsize \text{第二句话}
\]

\[
\large \text{第三句话}
\]
```

后续句子可沿用列表中剩余的命令。原帖没有提供超过七句时的处理方式。

## 兼容性检查
在目标界面先用短句预览，确认块级公式分隔符和字号命令均被识别。若未渲染，按该界面支持的格式调整；不要声称此语法普遍有效。
