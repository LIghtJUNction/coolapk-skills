# HyperOS 3 主题图标：MTZ 与 MRA 证书导入

## 文件与公开资源

原帖提供 HyperOS 3 图标主题所需的 MTZ 主题文件和 MRA 证书文件。公开分享页：[https://www.123912.com/s/NdLA-lbvFh?pwd=IBrL#](https://www.123912.com/s/NdLA-lbvFh?pwd=IBrL#)。原帖标注提取码：`IBrL`。此处记录的是分享页和原帖给出的文件说明；未提供下载校验结果。

## 使用步骤

1. 导入 MTZ 主题。
2. 将 MRA 证书放入：`/storage/emulated/0/Android/data/com.android.thememanager/files/MIUI/theme/.data/rights/theme/`
3. 在主题混搭中使用图标。

原帖称该方法免 root，并报告目前在 OS 3 测试可用；未说明具体设备型号或测试环境。MTZ 文件必须保持原样，不可修改。
