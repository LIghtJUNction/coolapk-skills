# 补全计划 One：跨系统主题维护记录

以下是特定主题在发布时的说明，并非所有同系统主题的通用行为；图片和完整评论未读取，未经独立实测。

## HyperOS

- [One 在 HyperOS 3](https://www.coolapk.com/feed/68211609)：作者建议将主题应用两次，确保状态栏电池宽度正常；由于内外显电池大小需要一致，取消原有左侧内显样式，推荐右侧外显。该帖称 ColorOS 16 版本修复控制中心相关问题；One II 当时在 HyperOS 1、2 有完整版，OS3 仅先体验图标模块。
- [One II 的 HyperOS 3 版本](https://www.coolapk.com/feed/68689419)：状态栏和胶囊电池更新，修复锁屏/桌面音乐线条和桌面时钟缩放。若时钟小部件异常，原帖建议删除后从「小部件 → 全部应用 → 安卓小部件」重新添加。作者称音乐接口不稳定可能使锁屏播放器不显示或残留，可重新应用锁屏刷新；One 与 One II 应用后建议重启。
- [One 的 HyperOS 2 更新](https://www.coolapk.com/feed/62022177)：升级 2.0 后状态栏未生效，可在「我的 → 主题」删除后重新搜索、下载和应用。该版还声明修复浅色背景状态栏发灰，适配控制中心按钮和设置图标。
- [后续 One 更新](https://www.coolapk.com/feed/66419617)：状态栏隐藏 Wi-Fi 上下行标识；按商店要求取消控制中心 Wi-Fi 和移动数据磁贴图标适配。胶囊电池是后续新主题的计划，不能视作该版已有功能。

## ColorOS 与 OriginOS

- [OPPO 版 One II](https://www.coolapk.com/feed/69740227)恢复商店上架并加入 5G 标识；已购用户可在「主题商店 → 我的 → 主题」长按删除，再搜索同名主题下载应用。原帖称修复部分短焦指纹设备电量重叠及锁屏壁纸白边。
- [OPPO 版 One Plus](https://www.coolapk.com/feed/66216537)在一次更新中暂时取消控制中心图标适配，原因是深色背景下按钮动画抽动未解决；另修复两个健康应用图标重复。
- [vivo 版 One](https://www.coolapk.com/feed/65958696)称 OriginOS 5 的省电和快充模式会统一调用横向内显电池素材，因此推荐使用内显样式；折叠屏主题也同步了该状态栏样式。

这些帖子提供的是各平台主题商店的名称搜索入口，没有具体安装包直链。
