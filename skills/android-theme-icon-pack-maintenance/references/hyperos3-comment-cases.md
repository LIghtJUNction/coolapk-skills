# HyperOS 3 主题状态栏适配限制与反馈

原帖主题作者反馈：小米主题审核要求 Wi-Fi 图标显示为三格、信号显示为四格，限制了新主题的设计。作者表示尝试过用固定的小点搭配真实信号格的方案，但仍未通过审核；作者称审核会看图标视觉效果，出现四格 Wi-Fi 就可能被打回。这些是作者在评论中的经验描述，不代表官方公开规则说明。

## 图标设计边界

- 作者称 HyperOS 3 主题审核会按视觉效果判断，四格 Wi-Fi 图标可能无法通过；把 Wi-Fi 信号减少一格是作者试过但会改变整体风格的方案。
- 作者表示 One1 主题采用三格 Wi-Fi 并加大格间距，称这是在限制下尽力调整的样式。
- 作者称 One2 新状态栏隐藏了 Wi-Fi 指示器；仿 Android 原生 16 状态栏的版本也隐藏了 5G 标识。评论中的用户反馈与此相符。
- 作者说明，澎湃 OS 3 电池宽度固定，因此补全计划一代无法把竖向电池改成胶囊样式；“把状态栏整体放大”的评论建议没有得到作者认可。
- 作者称其讨论中的这版主题无法复刻三星新版状态栏的双层信号样式；这不是所有 Android 主题的能力结论。
- 关于华为折叠机，作者称其主题在鸿蒙 5 后无法继续适配；输入法与系统主题机制不同仅是该作者推测，不扩展成平台全面禁用第三方主题的结论。

## 组件异常处理

- 有用户反馈澎湃 OS 3 音乐组件自动出现。作者称这是澎湃 OS 3 音乐接口的 bug，重新应用一次锁屏可以暂时处理；若要根治需要小米修复接口。作者试过取消调用接口，但会导致音乐播放器不可用。
- 用户反馈电量或音乐小部件显示异常时，作者建议删除后重新放置；另一位用户反馈重新放置后恢复正常。作者还给出寻找时钟小部件的路径：桌面双指捏合 → 添加小部件 → 全部应用 → 安卓小部件 → 时钟，然后向左滑动查找。
- 作者称小米要求主题免费发布；有评论建议收费以减少审核压力，但作者说明无法收费。

## 其他兼容性反馈

- 作者确认 One2 新状态栏隐藏 Wi-Fi 指示器；用户询问数据箭头时，作者答复该版本确实隐藏了 Wi-Fi 指示器。
- 有用户反馈 360 智慧生活图标失效，作者回复需要特殊适配，未在这段评论中确认修复完成。
- 有用户反馈 OPPO 商店羊城通包名错误导致图标未匹配。作者称已记录并计划在后续更新修复；评论没有确认最终修复结果。
- 关于 OPPO 商店图标更新，作者曾预告下周更新，但这只是当时的进度说明，不足以证明已经发布。

## 控制中心与图标的含义

- 有用户把月亮图标当作勿扰，作者解释该主题按三星习惯将其用作深色模式。判断图标含义需要看当前主题，而非只看外形。
- 作者解释其状态栏图标表示振动模式；在该小米环境中，要关闭静音时振动需在设置关闭“静音时振动”。正文未给菜单层级，不补造路径。
- 评论提到麦当劳等应用更换启动类后需要重新适配图标，作者仅承诺后续更新。没有提供具体 Activity 类名或已发布修复版本，不能补成现成映射表。
