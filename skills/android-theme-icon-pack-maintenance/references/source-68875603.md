# One 图标包 V3.5：更新与系统适配

## 版本与适配信息

- V3.5 新增 400 多个图标，原帖称适配数量达到 5000 多个。
- 原帖报告称 ColorOS 16.0.1 及以上版本已支持该图标包，并称更新解决了通用版图标大小不一、特别版遮罩不生效和早期版本白边问题。这是原帖发布时的兼容性报告，未提供独立测试记录。
- 对偏好图标清晰度的 OPPO 用户，原帖建议升级到 ColorOS 16 后使用通用版。
- 三星用户安装最新通用版后，需按教程在主题公园重新导入、安装并应用主题。
- OPPO 用户可先切换到其他图标包、重启手机，再切回 One 图标包，以规避原帖提到的显示问题。
- One2 是否制作三星图标包当时仍在考虑中；原帖没有确认其后续决定。
- 图标替换检索功能是作者反馈的需求，原帖只表达期待，未称该功能已经上线。

## 更新方式

已购买并下载图标包的用户，可在图标包软件底部第三个按钮进入“更新相关”版块，更新至 V3.5。网盘订阅用户可在网盘查看同步更新提示。
