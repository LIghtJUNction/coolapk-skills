# Android 主题图标形状与桌面动画

## 修改图标形状

原帖描述的步骤：导出模块或 MTZ 后，以压缩文件方式打开其中的 `icons` 文件，编辑 `transform_config.xml` 中负责形状变换的部分，以改为其他图标形状。原帖没有给出 XML 片段、具体字段或可直接复制的配置，也没有包含评论区所说的其他形状遮罩，因此无法据此写出具体配置值。

形状修改后，一键锁屏等快捷方式图标、文件夹等元素仍可能保持圆角矩形；原帖称这些需要自行绘制修改。

## 调整桌面动画

原帖建议使用 Xposed 模块 hook 桌面，使桌面将图标视为未使用默认主题，从而解决动画问题；动画会回落到第三方主题的效果。原帖给出的模块地址为：`https://t.me/YifePlayte/162`。地址原文写作 `踢.me/YifePlayte/162`，将中文“踢”按音替换为 `t` 是推断，目标未核验；未提供模块名称或版本号。

启用模块后，开启桌面里的“伪装非默认图标”选项。原帖未说明桌面应用、系统版本、Xposed 实现及模块版本，也没有独立测试记录，因此该方法仅作为原帖报告的做法，不能推定对其他环境同样有效。
