# 《补全计划One Plus》C15 主题版本与模块差异

## C15 更新内容

原帖称 C15 已更新上线，面向 OPPO、一加和 realme 机型的主题商店主题。更新包括：

- 新增 One UI 7 同款胶囊电池，并在胶囊内显示电量。
- 新增适配 400 多个图标，重绘 40 多个已绘制图标。
- 重绘控制中心按钮图标。
- 将锁屏主页右下角的“自定义”入口移至向右滑动页面。
- 锁屏时钟字体改为 OneUI Sans。
- 修复小布助手、手机管家、云服务等桌面快捷方式图标未生效的问题。
- 修复最新系统关闭高级材质后，桌面文件夹背景默认呈浅色的问题。
- 恢复锁屏自定义页面的“同步桌面壁纸”功能。
- 恢复亮色模式下的解锁指纹圆圈样式。
- 暂时取消桌面应用分身角标适配，原帖注明该项问题暂存。

## 锁屏同步桌面壁纸

C15 使用锁屏同步桌面壁纸功能前，需先设置壁纸；随后进入主题详情页，打开“自定义混搭”，取消勾选“桌面壁纸”。

## 商店版本区别

主题商店内分为 Plus 全局版和普通桌面版。普通桌面版仅包含图标模块，其特色是桌面文件夹采用浅色样式。原帖推荐购买 Plus 版，但未提供价格、具体支持机型清单或各机型实测信息。
