# 《补全计划One》vivo主题：OriginOS 5 1月更新

## 更新内容

原帖报告该主题的1月更新已上线，针对 OriginOS 5 大版本迭代。更新项包括：

- **桌面**：新增并适配400多个第三方图标；桌面小文件夹新增高斯模糊背景。
- **状态栏**：重绘状态栏图标并调整大小，修复图标错位。
- **锁屏**：优化单击时钟区域进入自定义页面的方式；新增默认粗体时钟选项。
- **设置**：优化 OS5 设置页面的灰色背景与白色卡片，使其接近系统默认 UI。

## 适配与问题记录

- **快捷方式图标出现白圈或尺寸异常**：原帖称，问题与 vivo 对大圆角图标的处理有关；作者报告的恢复方法是在系统“变形器”中重新切换一次图标大小。此为原帖经验记录，未提供机型范围或独立测试结果。
- **折叠屏 Fold 的 OS5 小文件夹模糊效果**：作者表示该版本当时遗漏了此项，准备提交修正；原帖没有确认修正已发布。
- **OS4 与 OS5 共用主题包**：作者提醒部分效果在 OS4 上显示不佳。为配合设置页面，二级页面改成灰色背景，可能影响电话页面显示。
- **状态栏模式**：原帖称 vivo 最新系统已支持无字模式和深色模式下的状态栏显示；未注明具体系统版本或机型范围。

主题可在 vivo 主题商店搜索“补全计划One”体验。原帖提及其宣传图壁纸来自网络，但未提供壁纸链接。原帖标签含 vivo X200 Pro mini；这只表明帖子标记了该机型，不能据此确认它是唯一或经过验证的适配设备。
