# vivo 主题「补全计划One II」

## 主题特点

帖子介绍该主题相较「补全计划One」的变化：

- 图标采用跟进 One UI 7 设计的鹅卵石渐变风格，饱和度更高，并强调与壁纸的层次区别。
- 三方软件图标重新绘制，目标是在维持软件辨识度的同时统一图标内部图案大小；作者称重绘图标数量比官方更丰富。
- 支持 2×1、1×2、2×2 大图标样式。
- 状态栏使用三星源文件素材，并跟进帖子所称 One UI 8.5 风格；胶囊电池的宽度经过调整。充电状态使用原生风格，以减少控制中心中绿色电池过长、过于显眼的问题。
- 锁屏控制台可自定义时钟字体、排版和高度，也可设置锁屏壁纸及部分元素的显示或隐藏。

## 发布与适配信息

帖子称主题已上架 vivo 主题商店，可搜索「补全计划One II」下载试用；另有折叠屏版。发布时仍处于前期适配阶段，作者征集带有“癣”或广告的图标反馈。
