# 《补全计划One II》主题功能说明

## 主题功能

- **图标**：以 One (1) 扁平风格为基础，为系统图标加入渐变背景；部分第三方图标在保留主体元素的前提下增加光影质感，以贴近重绘标准并与默认及系统图标保持统一。
- **系统界面**：状态栏风格参考原生 Android 16，图标全部重绘，并隐藏信号类型标识。虚拟导航键在 One (1) 基础上改进三星原版素材；设置页面图标重新绘制。
- **锁屏**：左滑进入 Nothing 风格锁屏控制台；时钟提供 4 种字体，以及水平、垂直和极简 3 种排版模式。提供 3 套锁屏壁纸，并支持同步桌面壁纸。
- **壁纸与适配反馈**：主题壁纸与 One1 使用相同沙丘元素；发帖者建议也可更换为自选壁纸来观察默认风格图标的兼容度，并征集尚未适配的图标反馈。
