# KernelSU 与分支 Root 环境隐藏教程（2.2）

## 版本说明与适用范围

原帖称 2.2 版减少了自动设置，改为更多手动配置，以减少使用中的问题并适配更多用户。旧版本升级时，如果当前没有问题，建议保持现状；安装旧版或其他版本后升级时，建议先卸载全部隐藏模块再重新安装。若现有隐藏版本运行正常，可以不升级，或只更新管理模块。

教程称工具同时支持 Magisk、APatch 及其分支，并介绍 KernelSU 与分支面具方案。作者建议 Root、解锁后遇到应用闪退或无法使用时，可尝试隐藏环境；原帖称免解锁、伪回锁及越狱情形也可使用。以上兼容性与效果是原帖说明，未提供独立测试数据。

## 安装与配置步骤

1. **目录清理材料缺口。** 原帖要求根据图片圈选保留两个项目，另要求保留禁用AVB 2.0验证模块；但图片尚未读取，两个项目名称未知。不能据此执行对 `/data/adb/` 的删除；这一步尚不构成可照做的操作步骤。
2. **更新 Root 管理器。** 重启后将面具更新到最新版本或内测版本。原帖提及内测版本可从官方频道或 `Root.bszip.me` 获取；正文未给出完整 URL，域名链接按 HTTPS 补全属于推断：<https://Root.bszip.me>。
3. **重置管理器。** 清理面具应用数据，并将设置恢复默认值。
4. **刷入模块。** 在 Root 面具右下角点“+”刷入「悲伤一键隐藏.zip」。刷写时按自身需求选择方案；不确定时按默认选项等待完成。原帖称方案二适合只关注环境检测软件或游戏的情形，方案一适合极客用户，并称方案一会自动安装 LSP 框架；正常环境需求选择默认即可。具体方案差异及选项内容未在文字中列出。
5. **更新密钥。** 开机后，在模块列表打开“悲伤环境模块”的 WebUI，更新密钥文件。可选通用密钥或机型密钥；原帖提醒机型密钥不一定兼容常规环境检测软件，没有特殊需求时选择通用密钥。
6. **配置应用隐藏。** 打开应用隐藏管理，先导入云端配置，再把设备上的风险应用加入管理。原帖举例包括 LSP 插件、Root 软件及其他不希望被检测到的应用。
7. **隐藏 Bootloader 状态。** 原帖指定 Oh My Keymint-R1-1.3.6：进入模块 Web 界面同步安全补丁。作者转述有人称该模块会导致抖音封禁 30 天，并建议使用默认配置、不改其他选项；原帖没有提供验证证据。该模块也支持更新 keybox；若有 Google 密钥相关需求，可尝试模块更新后的密钥，原帖未说明适用条件或验证结果。

## 原帖报告的检测现象与限制

原帖称部分检测结果可能属于检测工具或设备环境的已知现象，并建议在实际使用不受影响时不必仅为检测软件结果反复调整：

- 春秋在部分机型上可能误报；Google 三绿在部分情况下可能因密钥吊销而失效。
- 6.12 内核版本在“牛头”检测中出现 08。
- 小米、红米及澎湃系统用户在“小男孩”检测中出现设备风险、在“紫色放大镜”中报错，或高版本 Momo 打不开、闪退。原帖给出的关联解决帖：[酷安 feed 70600694](https://www.coolapk.com/feed/70600694)。该帖正文未随本输入提供，具体解决步骤未知。
- 一加、真我、OPPO 用户在春秋检测中可能出现 TEE 不可信。原帖给出的关联解决帖：[酷安 feed 74664270](https://www.coolapk.com/feed/74664270)。该帖正文未随本输入提供，具体解决步骤未知。

原帖还提到可到对应检测软件板块查找针对性处理，但没有给出其他链接或步骤。正文含 7 张图片而图片内容未读取；评论未提供，历史评论也未完成读取。因此图片中的保留目录项、界面选项、效果截图及评论补充均无法确认。
