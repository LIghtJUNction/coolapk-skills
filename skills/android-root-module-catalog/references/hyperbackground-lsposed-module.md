# `HyperBackground`：HyperOS 4 系统设置与我的设备背景自定义模块

- **来源**：[酷安原帖](https://www.coolapk.com/feed/73430434)（`imgs=6`，`https://github.com/Solomonstery/HyperBackground/`）
- **功能边界**：面向 HyperOS 4 的 LSPosed 模块，支持为「设置主页」「我的设备」「全局背景」分别挂载静态图、GIF、MP4 或 WebM 动态背景（含透明度、模糊强度及文字明暗/HSV 取色适配），覆盖系统设置二级页、设备互联、主题壁纸、手机管家等；作者注明暂不支持 Hook HyperOS 4 的 Rust 桌面。
