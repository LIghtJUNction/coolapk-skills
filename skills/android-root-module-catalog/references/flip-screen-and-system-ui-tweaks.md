# 外屏、系统特性与显示/存储调校案例

本参考整理酷安社区中关于小米 MIX Flip / Flip2 外屏模块、HyperOS 焕新存储启用与 OriginOS 5 全局饱和度/护眼工具的公开技术记录。所有内容仅来自原帖正文；图片、评论区链接与外部网盘/模块包均未在本库下载或实机验证。

## 1. 小米 MIX Flip / Flip2 外屏与频点限制模块

- **来源**: https://www.coolapk.com/feed/73857959
- **适用范围**: 小米 MIX Flip / MIX Flip2（原帖提及已在 HyperOS 4 上测试可用，并补充适配了 Flip2 的 AOD 开启）
- **版本区分**:
  - **通用版**: 基于纯 LSPosed 模块使用外屏桌面 `fliphome`，优化 AOD 样式、外屏手电筒开启、全屏与小部件区域触摸等；附带 ADB 开关，可仅开启 AOD 而不启用全屏。
  - **属性层版**: 从系统属性层改变折叠形态判定，使用内屏桌面与正常控制中心，但存在旋转逻辑与音量逻辑缺陷；需配合 KernelSU 模块 `flip_prop` 使用，原帖提示使用有风险且需要具备 ADB 基础。
  - **命令集与频率限制模块 (`unified`)**:
    - 命令集包含 ADB 解除外屏启动限制、跳过出厂引导等操作。
    - `unified` 模块分别针对 Flip1 / Flip2 实测 CPU/GPU 频率节点，仅对最大频率做限制；原帖称在 Flip2 上限频后以低画质插帧运行《鸣潮》半小时表现稳定，亦可用于日常功耗/发热控制。
- **已知注意事项与缺口**:
  - 原帖提醒若改为单外屏后人脸识别不可用，需检查是否移除了前摄相关组件。
  - 具体模块安装包、教程文档链接及评论区网盘地址未在正文中直接给出（原帖指向评论区），图片与具体 ADB 命令全文未读取。

## 2. HyperOS 焕新存储（FBO）触发条件与云控绕过记录

- **来源**: https://www.coolapk.com/feed/61548014
- **测试设备与环境**: 原帖作者在小米 12S Pro（移植版 ROM，已解 `/data` 分区）上实测，需 Root 权限，搭配 Scene、Canta/西米露（原文写“西米露软件”）、Ceiler、MT 管理器或 Termux。
- **触发条件（原帖经验值）**:
  - 夜间作息时间：在系统闹钟中设置作息为 `22:30` 至次日 `07:00` 较易触发。
  - 网络与温控：保持联网状态（原帖建议开启 5G），夜间充电温度控制在 `40°C` 以内；作者使用充电宝配合 Scene 控制极低充电电流。
- **云控绕过与属性开启步骤（按原帖记录）**:
  1. 使用相关工具搜索“焕新存储”并开启，重启安全服务；禁用系统 `HTML 查看器`（原文“html 查看器”）及云控组件并清除数据（原帖称不禁用 HTML 查看器会导致重启后开关重新被云控关闭，单纯断网无效）。
  2. 在 Termux（或终端模拟器）中执行 `su` 获取 Root 权限后写入属性：
     ```sh
     setprop persist.sys.stability.miui_fbo_enable true
     ```
  3. 验证属性是否生效：
     ```sh
     getprop | grep fbo
     ```
     检查输出对应行末尾是否为 `true`（原帖提及此前可用 MT 管理器修改，后续改用 Termux 执行）。
  4. 重启手机后再次执行 `getprop | grep fbo` 确认仍为 `true`。
- **证据边界**:
  - 原帖提及曾结合 Ceiler、刷入“大佬的文件”等操作，但外部文件包及图片内容未读取；不同机型与 HyperOS 版本的属性键及云控机制可能存在差异。

## 3. OriginOS 5 全局饱和度调节与护眼背景工具

- **来源**: https://www.coolapk.com/feed/74950048
- **适用环境**: 原帖作者在 iQOO Z10 Turbo+（OriginOS 5）上自行开发并实测；未在 OriginOS 6/7 等后续系统版本验证兼容性。
- **机制与权限**:
  - **全局饱和度调节**: 需配合 **Shizuku** 授权调用系统接口；内含通道自检，用于检测系统是否存在 HSV 色彩空间支持。由于系统未内置类似小米/荣耀的色彩管理，作者未采用修改刷机包的高风险方案。
  - **全局背景（纸质护眼模拟）**: 需开启**无障碍服务**；通过叠加颗粒感背景减少光线直射，但原帖明确提示长时间使用存在烧屏风险。
  - **网络权限**: 原帖声明工具无联网功能。
- **还原与风险提示**:
  - **直接卸载软件不会恢复饱和度**，需在卸载前点击软件内“一键还原”，或直接**重启手机**恢复默认状态。
  - 若出现异常，原帖给出强制重启方式为长按“电源键 + 音量下键”。
  - 原帖未附带开源仓库或 APK 下载地址（相关截图未读取），仅作原理与交互边界参考。
