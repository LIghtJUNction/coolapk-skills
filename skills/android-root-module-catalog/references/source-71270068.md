# KernelSU、Alpha 与 APatch 环境隐藏包：0417教程及反馈

## 适用范围与证据

原帖称教程和文件适用于 KernelSU、Alpha、APatch 及其分支管理器，并标注 0417 更新。该适用范围和效果是原帖陈述；未提供独立测试记录。原帖有 9 张图片，图片内容未读取，因此不据此补充隐藏效果或界面细节。

原帖提到针对“春秋检测 3.2”可通过，并建议按相应检测词条继续执行其他脚本；这不是对所有检测项、应用或设备的通过保证。评论中也有新版春秋、TE 等项目未通过的报告。

## 安装与启用步骤

1. 下载环境工具包。原帖没有实际下载URL，但明确给出公开提取码 `6666`。
2. 刷入 `悲伤一键环境隐藏0417.zip`，然后重启设备。
3. APatch 及其分支管理器：先刷入隐藏用的 KPM 模块。
4. Alpha：刷入模块前，在超级用户列表中向 KsuWebUI 授予 Root 权限。
5. 打开模块，进入“悲伤隐藏环境”面板，执行第一个和第三个操作。若不需要自动更新 Ts 列表，可关闭该功能。
6. 在 LSP 面板中使用 LSP 框架激活隐藏应用列表，激活后重启手机。
7. 开机后，在隐藏应用列表中还原配置，选择压缩包内的 `白名单.json`。

原帖称无法激活模块时，常见原因可能是 Root 管理器与 Root 内核版本不匹配。这是原帖给出的排查方向，不是已验证的唯一原因。

原帖另提示：如果安装过旧版，更新前先卸载原模块。评论有人询问是否需卸载全部模块，但所给评论中没有对应答复，不能据此扩大为卸载所有模块。

## Ts名单与自动更新

- `b.txt` 是白名单：自动更新 Ts 列表时，其中的包名会加入列表。
- `s.txt` 是黑名单：自动更新 Ts 列表时，其中的包名会排除。
- 两个文件均按“每个包名一行”填写。
- 自动更新 Ts 列表默认开启。若另装了其他 Ts 更新相关模块，原帖建议关闭其中一个自动更新功能以避免冲突。

## Google相关服务设置

原帖给出的 PlayIntegrityFix 操作是：打开模块操作界面，启用“同步安全补丁”，点击“随机”后再点击“获取”。原帖称若获取界面无法打开，可尝试使用其所称的“魔法”网络环境。该操作效果未独立验证。
