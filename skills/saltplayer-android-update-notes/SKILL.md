# SaltPlayer Android 版本变更参考

本文记录来源帖中列出的版本变化和问题，不代表独立测试结果。

## 版本记录

### 12.5.0-release-2026102401

相较 12.4.1，更新包括：适配 SaltUI 组件样式；增加 USB 独占位深策略与 PCM 精度处理；优化手机横屏布局、沉浸播放和歌词切换、USB 独占设置布局与多语言文案、音乐扫描界面和封面绘制；修复清空队列后迷你歌词状态残留、Android 17 以下系统错误检查 DLNA 局域网权限、USB 独占页面系统音量双向同步、迷你播放条封面缩放锯齿及文件夹排序问题。

### 12.5.1-release-2026102402

优化手机横屏时左右安全区避让；修复 Android 12 及以下版本的横屏布局问题；调整车机播放界面的适用设备限制及说明。

### 12.5.2-release-2026102801

增加 WMA V1/V2 音频扫描与解码，以及按文件名搜索歌曲；优化 Android 12 横屏判断和切换体验；修复开关 Sheet 后状态栏隐藏功能异常。

### 12.6.0-release-2026110201

相较 12.5.2，增加专辑详情页 3D CD 盒效果；优化冷启动播放界面的封面显示；修复竖屏隐藏状态栏后下滑唤出的状态栏无法自动隐藏，以及 USB 独占状态文案国际化问题。

## 已报告的适配条件与缺陷

- Android 12 及以下版本在 12.5.0 存在横屏判断或布局问题；后续 12.5.1 的更新记录称已修复，并优化横屏切换体验。

## Android 12.4.1 的具体改动

# 椒盐音乐 Android 12.4.1-release-2026100701 更新记录

本版本将 `minSDK` 提升至 24（Android 7.0），`TargetSDK` 提升至 37（Android 17）。更新内容如下：

- 恢复重置歌曲隐藏和恢复功能；新增实验室歌词辉光效果、迷你播放条 Liquid Glass 弹性效果、调用 Lyrico 修改歌曲标签的支持，以及实验室歌曲菜单管理。
- 交错滚动效果选项移至歌词界面设置，并默认开启；该效果已视为稳定功能。更新日志改为访问应用内网页。
- 优化空时间戳行作为显式行结尾标记的歌词格式兼容性；调整播放界面开合时文本和控件的淡出距离；优化播放封面开合曲线及逐帧计算、Pro 页面布局、文件夹列表刷新与目录读取缓存、播放界面展开性能，以及歌曲菜单部分图标样式。
- 修复暂停音乐时意外释放音频焦点、播放界面未显示 FLAC 位深、通过音乐标签更改正在播放歌曲封面后保存反馈未更新、部分设备上的胶囊迷你播放条圆角不重合、Morvanium 智能过渡时播放界面闪烁等问题。
- 修复 USB 独占模式对无响应设备误报就绪并显示误导提示，以及 USB 存储歌曲路径含特殊字符时无法播放的问题。
