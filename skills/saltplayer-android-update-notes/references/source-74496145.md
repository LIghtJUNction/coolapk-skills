# 椒盐音乐 PC 创意工坊与模组开发

## 适用范围与状态

原帖报告：椒盐音乐 PC（Salt Player for Windows，SPW）1.19 创意工坊已开放；Windows 与 Linux 桌面版均支持模组，Steam 渠道可直接订阅下载。Workshop API 仍处于试验阶段，接口可能扩展或发生不兼容调整。以上为发帖时的版本与状态说明，不代表后续版本现状。

## 模组运行能力

模组运行在 SPW 的 JVM 环境中，可使用 Java 生态能力，包括网络请求、文件读写、系统接口和第三方库。播放器公开接口涵盖播放状态与进度、逐行及逐字歌词、曲库元数据与封面、应用内快捷键和全局快捷键。UI Hook 可用于修改应用方法与界面。

这些能力意味着模组可能触及网络、文件和系统接口；原帖没有描述权限隔离或安全沙箱，不能据此认为模组受到限制或隔离。

## 开发与本地测试

使用 Kotlin 或 Java 和标准 Gradle 工程：

1. 引入 `spw-workshop-api`。
2. 继承 `SpwPlugin` 编写主类，并实现扩展点。
3. 运行 Gradle `plugin` 任务，构建 `.spmod` 文件。
4. 将 `.spmod` 导入播放器测试。

原帖“用……实现扩展点”处缺少具体接口或方法名称，因此这里不补猜实现细节。API 源码与示例工程：[https://github.com/Moriafly/spw-workshop-api](https://github.com/Moriafly/spw-workshop-api)。

## 发布与分发

- Steam 版用户在启动选项添加 `--workshop-publisher`，播放器内会显示“创意工坊创作中心”；可上传 `.spmod` 和封面发布或更新，原帖称无需审批。
- 也可将 `.spmod` 发布到 GitHub Releases，并添加 `salt-player-plugins` topic，便于检索。
- 原帖提到 Steam 创意工坊可从商店页的“创意工坊”标签浏览订阅；微软商店渠道建议通过 GitHub Topics 查找模组。

创意工坊文档入口：[https://saltplayer.com/workshop](https://saltplayer.com/workshop)。原帖另列 API 问题反馈的 GitHub Issues，但未给出独立 Issues URL；API 仓库链接见上。
