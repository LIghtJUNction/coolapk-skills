# 2025 年 Windows 更新与 ColorOS 兼容性记录

## Windows 版 1.4.5—1.4.13

以下是开发者发布的更新记录，尚未独立复测：

- **1.4.5（2025-06-15）**：隐藏主窗口后通过任务栏固定图标或开始菜单再次启动时重新显示；修复商店版安装在其他盘时图片缓存无法写入、插件启动报错、远程文件夹断开导致路径解析崩溃，以及部分 Windows 10 界面渲染问题。
- **1.4.6（2025-06-24）**：新增多声道音频自动下混以匹配扬声器输出；修复跨显示器移动时可能卡住的问题。
- **1.4.10（2025-07-03）**：新增 CD 查看工具箱、CDA 播放、任务栏播放控制、音乐库数量面板、非当前歌词模糊选项及繁体中文和俄语适配；修复桌面歌词状态未保存、迷你播放条长文本错位、图片缓存写入失败及播放队列状态不一致等问题。
- **1.4.12（2025-07-07）**：向系统媒体控制传输播放进度，增加最大内存限制；改善切歌后进度刷新和歌词同步，修复任务栏快捷按钮、选择其他应用打开和暂停时从系统托盘退出的问题。
- **1.4.13（2025-07-08）**：公告仅称有内部改动，未给细节。该帖没有列出 1.4.11。

[版本记录来源](https://www.coolapk.com/feed/66044395)。另有[功能预告](https://www.coolapk.com/feed/66044492)称自定义文件夹计划在 1.4.20 EA 发布，Steam 上架、搜索和歌单仍在推进；这是当时的计划，图片未读取，不能据此确认实际发布状态。

## ColorOS 15 导航条适配

[开发者反馈](https://www.coolapk.com/feed/65983279)称 ColorOS 15 的 15.0.0.831/832 版本可能使部分原本适配底部导航条的应用出现不适配；反馈认为 15.0.0.840/15.0.0.601 可能修复，且可能灰度发布。开发者还观察到椒盐音乐将目标 SDK 提升至 Android 15 后能避免该现象，推测与 Android 15 的边到边显示有关。设备型号、复现步骤和测试矩阵均未提供，原因与修复范围尚未独立验证。升级目标 SDK 应结合应用自身适配和测试，不能视作所有设备的通用修复。
