# 椒盐音乐 12.2.0 更新记录

版本：`12.2.0-release-2026081002`。

## 功能与适配

- 播放界面新增展开、折叠动画；部分机型适配屏幕圆角，原帖未列出具体机型。
- 适配 libFLAC 1.5.0。
- 新增读取 M4A 容器中的 ReplayGain 标签。
- 新增适配词幕 Lyricon。
- “帮助与反馈”新增诊断日志辅助记录，用于反馈软件运行情况。
- 新增 USB 独占固定采样率输出模式和 300 级高精度音量。
- 优化 USB 独占模式对 Yuandao TC3 的适配；这是版本说明中的适配记录，不代表独立硬件测试结果。

## 优化与变更

- 优化音频焦点处理、播放队列稳定性及部分 UI 布局，并优化软件安全性；原帖未说明具体实现。
- “关于”页面中的 App 备案号改为 App 核准号。

## 修复

- 修复无法解析大于 3 MiB 的 MP3 格式封面的问题。
- 修复查看超大专辑封面时崩溃的问题。
- 修复液态玻璃迷你播放条效果可能导致的崩溃。
- 修复专辑详情页面反馈、启动软件悬浮窗状态栏歌词可能导致的崩溃。
- 修复内置网页页面跟随应用深色模式异常，以及部分系统上跟随系统深色模式失效的问题。
- 修复播放界面歌词区域的嵌套滚动问题。
- 修复 GB2312 日文歌词编码被误判为 BIG5 的问题。
- 修复 USB 独占模式下 FreeDSP Mini 左右声道音量不同步，以及部分系统上内核重连导致崩溃的问题。
