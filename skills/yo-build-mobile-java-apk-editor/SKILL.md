# yo_build：纯手机 APK 构建编辑器

帖子介绍一款在手机上编辑 Java 项目并构建 APK 的工具，作者称使用时不需要 Termux、root 权限或电脑。该描述是作者报告，本任务未安装或实机验证。

## 功能与构建方式

帖子列出的功能包括 Java 代码编辑、语法高亮与格式化、多标签、项目图标和包名及权限的可视化配置、构建日志，以及构建完成后弹出安装流程。作者称底层构建工具 yo_build 使用 C++ 编写，并随应用提供 aapt、d8、apksigner 和 JRE 等组件；首次打开时从 assets 解压到应用私有目录，之后在本机运行。

帖子将流程概述为：`javac → d8 → aapt → zipalign → apksigner`。这是对构建链的概括，不保证每个阶段都能按这个顺序独立、单遍执行，也不是可直接复现的构建命令；帖子没有提供命令行参数或完整构建脚本。

界面功能还包括深浅色主题、圆角图标和工作区自动恢复。

## 限制

- 支持 `.java` 和标准 XML 资源，不使用 Gradle。
- 第三方库需要手动放入 `libs/`。
- 没有真机调试；帖子称 logcat 支持仍在计划中。
- 大项目首次编译可能较慢，增量编译仍在计划中。
- 帖子称项目暂不开源，因此没有公开源码仓库可供引用。
