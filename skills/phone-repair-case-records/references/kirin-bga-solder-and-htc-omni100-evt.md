# 麒麟 960–990 虚焊维修成本与 HTC omni100 EVT 排线断裂投屏调试

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- #### [酷安原帖](https://www.coolapk.com/feed/73617800)（imgs=9 未读）
  - **华为/荣耀老款芯片虚焊风险与维修成本**：
    - 麒麟 960 与 970（发热极高，俗称“火麒麟”）：CPU 虚焊为高发通病，手机店重做 CPU（BGA 重新植锡焊接）行价约 150 元，备用机选购性价比低。
    - 麒麟 980：多核性能与骁龙 845 相当，但在夏季高温户外高负载开启 5G 时，同样存在发热导致的虚焊脱焊故障。
    - 麒麟 990 (994/995)：芯片体质与焊接做工明显改善，长期高负载运行无虚焊案例，建议到手关闭系统 OTA 自动更新。
    - 备用机避坑推荐：推荐发热低、不虚焊的麒麟 710A，或带 5G 且散热稳定的麒麟 820（荣耀 X10 散热耐受度显著优于 810）及麒麟 985。
  - **硬件兼容实测佐证**：兆芯 C4600 处理器 (VIA VX11 芯片组) 实测支持 16GB (8x2) AMD 专用 DDR3 内存条并顺利运行游戏，证实国产芯片在非标内存颗粒电气标准上的兼容容忍度。

- #### [酷安原帖](https://www.coolapk.com/feed/73464287)（imgs=9 未读）
  - **设备属性**：HTC omni100 废案工程机（早期 EVT 阶段工程样机），仓标明确带有物料说明，搭载 Windows Mobile 系统，全键盘 + 触摸屏 + 轨迹球设计，外壳配有辅助时间状态外屏（工程阶段未点亮），内置工程机专属 Debug Tools，IMEI 非常规 004 开头。
  - **机械结构缺陷与故障根因**：搭载高通 MSM7200A (528MHz) 处理器；主屏幕因排线断裂彻底失去显示，排障分析确认为设计缺陷：屏幕翻转机构内部排线在开合旋转时会持续摩擦挤压金属隔断，直至排线疲劳磨损彻底切断。
  - **联机救砖与屏幕映射方法**：在主屏彻底黑屏的情况下，通过安装微软 WMDC (Windows Mobile Device Center) 驱动连接电脑，配合使用 `mobiler` 投屏工具，成功将工程机内部屏幕画面直接映射至 PC 端进行调试。
