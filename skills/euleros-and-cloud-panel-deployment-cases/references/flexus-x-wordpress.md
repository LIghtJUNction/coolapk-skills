# Flexus X 上用宝塔部署 WordPress

## 环境与部署

原帖要求服务器已安装 PHP 8.0、MySQL、Nginx。通过宝塔软件商店选择“全部”中的 WordPress 6.6.1，点击“一键部署”。部署时可填写服务器 IP 或域名；若使用域名，需要先添加解析。

部署成功弹窗提供后续数据库配置所需信息。等待域名解析生效后访问站点，点击“现在就开始！”，填写数据库信息；其余值可保持默认或自行调整。继续点击“提交”，再选择“运行安装程序”。填写站点标题、管理员用户名、密码和邮箱，安装后即可登录后台。后台默认登录路径为 `wp-login.php`。

## 域名和端口

原帖使用阿里云 DNS 举例：添加 A 记录，主机记录为 `blog`，记录值为服务器公网 IP。若同一服务器上已有网站使用 IP 访问，另一个站点也使用该 IP 时可能发生 80 端口冲突；原帖建议在宝塔对应站点的 Nginx 配置中调整以区分站点。具体 Nginx 配置内容未提供。

## 发布文章

在后台进入“文章”→“所有文章”→“写文章”，可创建或修改文章并发布。原帖演示修改默认文章标题和正文后，通过“查看文章”检查前台效果。
