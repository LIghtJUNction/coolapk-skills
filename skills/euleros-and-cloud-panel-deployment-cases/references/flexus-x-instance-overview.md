# 华为云耀云服务器 X 实例：原帖规格与性能主张

## 柔性算力与性能主张

原帖称，云耀 X 实例提供 50 多种规格组合，支持按业务需要自定义 CPU 与内存配比，最高 CPU/内存比为 3:1；并称柔性配置可降低 25% 算力成本。原帖没有说明这些比例与成本数据对应的测试环境、计费条件或基准。

原帖称 X-Turbo 针对 MySQL、Redis、Nginx 等常见应用优化，性能最高可达业界同规格独享型实例的 6 倍；另称 GeekBench 单核及多核评测下，算力性能最高可达同规格独享型实例的 1.6 倍。文中未给出实例具体规格、测试配置、软件版本、测量结果或可复现实验步骤，因此应视为该文的宣传与评测主张。

## 调度、迁移与可用性主张

原帖将其调度能力描述为基于 QingTian 架构、瑶光云脑及盘古大模型，按业务负载动态预留资源。迁移方案被描述为先对应用性能画像并推荐匹配规格；原帖称迁移后可降本 30%，并称运行过程中可继续动态优化规格。未给出画像方法、迁移条件或成本核算口径。

原帖称单 AZ 可用性为 99.975%，跨 AZ 为 99.995%，并称面向企业建站、数据库中间件、游戏服务器、电商直播等场景提供配置推荐。这些数字和能力在该文中没有附带服务条款或独立测量证据。

## 原帖所列促销价格

文章发布时列出：4 核 8G、5M 带宽、1 年 288 元，标注原价 4140 元；另称 6 核/8 核规格适用电商直播，994.67 元/年起。价格和促销属于文章发布时的信息，不代表当前报价。文中没有给出 6 核与 8 核各自的容量、带宽或分别对应价格。
