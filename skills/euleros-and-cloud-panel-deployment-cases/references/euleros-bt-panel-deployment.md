# EulerOS 上安装宝塔面板并部署静态站点

## 确认镜像

连接服务器后运行：

```sh
lsb_release -a
```

原帖称其环境为 Huawei Cloud EulerOS，文章中的安装演示基于该镜像。原文没有写明 EulerOS 具体版本。

## 安装宝塔面板

原帖给出的通用安装命令结构如下，脚本地址在正文中显示为“查看链接”，无法据此还原：

```sh
url=查看链接 [ -f /usr/bin/curl ];then curl -sSO $url;else wget -O install_lts.sh $url;fi;bash install_lts.sh ed8484bec
```

该命令文本看起来缺少条件语句开头（例如 `if`），且链接被替换；不要把此损坏文本直接当作可运行命令。原帖另列脚本链接上下文为 `https://download.bt.cn/install/install_lts.sh;if`，但其形式也包含疑似命令残片，不能据此猜改成可执行脚本地址。

安装后，原帖指引在服务器终端输入 `bt` 查看命令编号，再输入 `14` 查看面板访问地址。需在云服务器安全组入方向开放原帖要求的 37580 端口，随后用浏览器访问该地址。端口、协议和访问限制应按实际面板设置核对；原帖没有展示具体安全组规则。

## 创建静态站点

原帖步骤为在宝塔中安装 LNMP 四件套，创建 HTML 项目站点，再将本地构建生成的 `dist` 目录内容上传至站点目录。原帖示例中站点目录名为 `myProject`。上传后通过配置的站点地址访问。
