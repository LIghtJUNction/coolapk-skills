# 华为云 Flexus X 实例配置与选型

## 产品与性能模式

原帖将 Flexus X 描述为面向中小企业和开发者的云服务器，支持自定义 vCPU 与内存配比、热变配，以及可选性能模式。未开启时采用柔性算力，通常提供接近独享实例的 QoS，但少数时间可能出现性能波动；开启后采用底层物理绑核以加强性能稳定性，需额外付费。原帖指出渲染、HPC 等对稳定性要求高的场景可考虑性能模式。性能保障描述属于原帖陈述。

其中一篇文章列出的规格范围为：关闭性能模式时 vCPU 1–16、内存 1–128 GiB；开启时 vCPU 2–32、内存 2–256 GiB。该范围与产品时期相关，不能视为当前规格承诺。另一篇文章称可选 50 多种规格，并举出 1:3、2:5 等非传统 vCPU/内存比例；这也是原帖发布时的产品描述。

## 计费、区域与实例配置

- 计费方式：包年/包月按周期付费；按需计费按使用时长计费。原帖建议短时测试考虑按需方式，常规用途可比较包年/包月总成本。
- 区域：原帖建议按用户与业务访问位置选择邻近区域，并留意各区域可用服务差异。
- 规格：可选预置规格或自定义 vCPU、内存。规格、性能模式价格及可选范围应以购买页面当时展示为准。
- 镜像：原帖列出 Huawei Cloud EulerOS、CentOS、Ubuntu、EulerOS、Debian、AlmaLinux、Rocky Linux、openEuler 和 Windows 等公共镜像；也提到私有镜像与共享镜像，共享镜像受区域等条件限制。
- Huawei Cloud EulerOS 2.0：文章列举默认应用版本 Nginx 1.21.5、MySQL 8.0.35、Redis 6.2.7，并报告相对未加速场景的收益：Nginx 小包 HTTP/HTTPS 40%、大包 15%；MySQL 约 20%（OLTP 纯读、纯写、混合读写）；Redis 约 20%（单 pipeline 小包）。这些是文章中的性能数据，测试方法与硬件条件未完整提供。

## 存储、网络与安全组

- 系统盘可选择高 IO、通用型 SSD、超高 IO、极速型 SSD、通用型 SSD V2、普通 IO 等类型。原帖表格称各类云硬盘系统盘最大 1024 GiB、数据盘最大 32768 GiB；极速型 SSD V2 标注为公测。性能和可用容量应以购买页面为准。
- 原帖将极速型 SSD 系列定位于延迟敏感或高性能负载，将通用型 SSD 用于主流企业应用与中小型数据库，将高 IO 用于中等性能需求，将普通 IO 用于轻载或不常访问的数据；并提醒普通 IO 不建议作为系统盘。
- 网络可配置 VPC、IP、安全组与弹性公网 IP。安全组按入站/出站规则控制实例访问；仅开放业务必需协议和端口。
- 原帖对静态 BGP 与全动态 BGP 作了对比，并给出可用性 99% 与 99.95% 的数值；这是原帖发布时的描述，不代表现行服务等级保证。带宽计费包括按带宽、按流量和共享带宽等方式。

## 登录、备份与场景规格

登录可使用控制台 VNC、SSH 工具或密钥对。原帖提到密码登录用户名为 root；密钥对私钥仅能下载一次，应妥善保存。云备份可选择新购、已有备份库或不购买，并配置周期、时间、全量备份和保留策略；原帖所述默认策略为每日 0 点全量备份。

文章给出的历史场景建议如下，均为原帖估算，未附独立负载测试条件：

| 场景 | 原帖建议规格 | 原帖声称的规模 |
|---|---|---|
| 电商店铺/外贸独立站 | 2 核 2G、3M 带宽、40G 系统盘 | 10 万 PV、1000 活跃用户 |
| 企业建站 | 8 核 8G、10M 带宽、40G 系统盘、200G 数据盘 | 50 万 PV、5000 活跃用户 |
| 小程序后台 | 16 核 32G、20M 带宽、40G 系统盘、500G 数据盘 | 50 万 PV、5000 活跃用户 |
| 小游戏 | 16 核 32G、20M 带宽、40G 系统盘、500G 数据盘 | 30 万 PV、3000 活跃用户 |
| 开发测试 | 2 核 4G、5M 带宽、70G 系统盘 | GitLab、Docker、Portainer 等用途示例 |
| 云端学习 | Windows Server 2019、2 核 8G、10M 带宽、120G 系统盘、2000G 数据盘 | 原帖配置示例 |
| 博客/论坛 | 2 核 2G、4M 带宽、50G 系统盘、600G 数据盘 | WordPress 等用途示例 |

另一篇文章举例 Flexus X 配置为 4 核、12G 内存、3M 带宽，用于商城部署；这不是通用推荐值。产品页：https://www.huaweicloud.com/product/flexus-x.html
