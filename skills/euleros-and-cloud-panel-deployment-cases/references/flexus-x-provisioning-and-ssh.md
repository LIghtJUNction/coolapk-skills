# Flexus X 实例选购参数与 SSH 登录

## 原帖明确记录的体验配置

原帖记录选择包年/包月、自定义规格 `4vCPUs | 12GiB`，性能模式关闭；公共镜像为 CentOS 7.9；系统盘为通用 SSD、100G；未添加数据盘；公网带宽按带宽计费，选择 3M。以上是该帖逐项明确对应的单一体验配置。

原帖说明包年/包月按购买时长一次性扣费，按需计费则按使用时长计费。购买页面可选预置规格或自定义 CPU、内存、存储等资源。其对 Flexus X 柔性算力、X-Turbo 最高 6 倍性能、按需计费及跨 AZ 99.995% 可用性的描述是文章中的产品主张，未附测试条件。

## 网络与端口

原帖说明需选择 VPC、子网、私有 IP 分配方式及安全组，并可在购买页面调整安全组规则。文章列出常见用途：

- TCP 80：HTTP 网页服务。
- TCP 443：HTTPS 网页服务。
- ICMP：用于 ping 测试连通性。
- TCP 22：Linux SSH 登录。
- TCP 3389：Windows 远程桌面。

原帖提示按需开放端口。公网 IP 与实例绑定后可供公网访问；公网带宽应按业务需求选择。文章未列出实际 IP 或安全组规则。

## 登录步骤

购买时可选择“创建后设置”或提前设置密码；作者建议体验时预设密码，之后使用 SSH 客户端连接。原帖使用 Termius，连接参数为服务器公网 IP、用户名 `root` 和预设密码。密码是个人账户凭据，不在本文重现。

原帖称控制台可查看实例配置、公网 IP，并支持网页远程登录、关机、重启、重置密码及续费等操作。
