# 核查 HireFerry 的功能与接口形态

## 适用场景
用于整理帖子对 HireFerry 的描述，或评估某项功能主张是否有帖子证据支持。此技能不是产品实测报告，也不替代对代码、文档和部署版本的检查。

## 帖子明示的内容
帖子将项目描述为开源招聘平台，并声称：
- 求职者可以介绍自己，招聘方可以介绍岗位，平台用于匹配。
- 招聘方收费计划已改为完全免费；任何人可选择公开简历或工作描述。
- 项目开放接口并提供开发者文档。
- 原生支持 MCP、CLI 及配套 skills；帖子设想将 MCP 服务器接入 AI 工具，用于自动筛选。
- 发帖者描述了 AI 推荐岗位、协助沟通和排雷的用途。
- 欢迎自行部署；帖子表示使用者可以收费，无需另行授权，并提出改版也必须开源的条件。

以上均为帖子中的陈述。发布或复述具体能力时，应注明证据来自帖子，不能据此断言当前版本仍具备这些功能。

## 接口与实现核查
1. 只记录已明确提到的接口形态：开放接口、开发者文档、MCP、CLI 和配套 skills。
2. 不推断或编造 API 路由、请求格式、认证方式、部署参数、收费细则、用户规模或实测结果。
3. 从 [HireFerry 仓库](https://github.com/TokenNotIncluded/hireferry) 获取代码及项目文档，按其中的部署、CLI、MCP 说明选择入口。具体命令尚未在本次整理中核对，不补写不存在的调用方式。
4. 如需说明接口细节或当前实现，应另行检查仓库与开发者文档，并清楚区分检查结果与帖子描述。
