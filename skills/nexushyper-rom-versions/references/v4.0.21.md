# NexusHyper 部分机型 v4.0.21

来源：Coolapk feed `73968049`。本帖没有给出各机型底包、移植来源和详细更新日志，不用相邻版本资料填补。

## 本帖列出的机型

K50U、K80、K80 Pro、K90PM、K70、K70 Pro、小米 15。仅表示本帖声明的支持范围，不外推到相同 SoC 的其他机型。

## 刷入与升级限制

主帖称同作者任意在用包可直升，指定版本官方包可直升，第三方包直升可能有 Bug；**原帖用语“不支持解密包直接刷”**，作者不承担因此造成的 data 丢失。卡刷通过 TWRP；线刷须解压完整压缩包并运行包内刷机脚本。只限作者指定机型，必须解 BL，否则可能不开机。主帖没有明确列出“指定官方包”的完整版本表。

评论里作者针对 K70 的 `澎湃 OS 1.0.20` 保数据升级问题回复“理论不会”（`608483040`）；这不是对其他底包或机型的保证。K80 用户询问官方 `OS4.0.0.9` 能否保数据直升，提供的评论没有作者答复（`608581069`）。有用户建议卡刷并核对 MD5，但没有给出实际摘要或作者验证（`608525740`）；不能视为该文件已校验。

## 内核与 Recovery

主帖指定 TWRP 为卡刷方式，没有提 OrangeFox。评论者询问 K50U 是否必须用包内内核，作者在所给评论里没有回答（`608627703`、`608627929`）。作者在“6.1 咋没有第三方内核”的提问下回复“没人做”（`608450612`）；该问答没有确定机型，不能改写成 K70 所有内核均无第三方支持。

评论中有用户报告在 TWRP 解密后刷入导致无法开机，并提醒不要在已解密的 TWRP 中更新（`608724637`、`608780160`）；这与主帖“不支持解密包直接刷”的警告相符，但不等于对所有 Recovery 的完整兼容性说明。没有本帖证据确认 OrangeFox 能否解密或刷入。

## 用户反馈

评论者报告卡顿、动画不顺、发热耗电、蓝牙音频路由、相机、应用拉起、分屏与桌面重启等个例。有人反馈后续版本修复部分问题；不应把这些体验推广到全体设备或当作作者确认的系统缺陷。
