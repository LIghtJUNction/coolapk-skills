# NexusHyper 全机型 v4.0.9

## 刷入方式与限制

- 原帖称支持“在用本人任何包”的用户直升；官方包仅限指定版本，第三方包也可直升，但作者注明可能有 Bug。原帖没有列出可直升的官方版本号或底包清单，因此不能据此确认任意官方版本均兼容。
- 解密包不支持直接刷入；作者警告这样操作可能造成 data 丢失。
- 该包为卡线一体包：卡刷通过 TWRP 刷入；线刷需解压整个压缩包后运行其中的刷机脚本。原帖没有给出脚本文件名或具体命令。
- 仅限作者指定机型，且要求已解锁 BL；未解锁 BL 或其他机型均不应刷入。
- 作者称包内置 KSU，管理器需自行从包内解压并安装。原帖没有列出 KSU 版本。
- 评论有人询问刷入后是否需清除 Dalvik，作者回复“不用”；另一条评论称清不清都可以，并认为清理后理论上可能更流畅。这是评论者的经验判断，不是明确的作者要求。
- 作者回复称可以更换内核；评论报告在 v3.05 和 v4.07 更换第三方内核后桌面卡死、无法滑动，恢复包内核后恢复。另一位评论者称自己更换内核无异常，故表现可能因内核或操作环境而异。

## 评论中的设备与功能反馈

以下来自该帖下的评论。评论所在帖子不证明评论者使用相同版本；未明确版本的反馈只作为线索，不能归为发布版统一Bug，也未在本库复现。

- Redmi K70：有用户报告 NFC 无法打开；另有用户反馈负一屏小组件、快递绑定入口或桌面小组件打开时闪退。也有人称自己的 NFC 正常。
- 小米 14、Redmi K60 Pro：分别有评论报告 NFC 异常或无法打开。
- 小米 17 标准版：多名用户报告相机问题仍存在；另有用户称更新至 v4.0.9 后仍未解决。问题细节及修复状态无法由未读取的配图确认。
- 小米 15：有评论提到徕卡水印不可用，并称存在修复包；该修复包的链接和版本信息未提供。
- 小米 13、Redmi K60 Pro：评论报告充电动画异常。
- 有用户反馈 LSP 日志异常；没有提供日志或复现条件。
- 有用户询问飞行模式持续开启，回复“起飞”属于玩笑，不能据此确定原因或解决方案。
- 小米 12S Pro：用户称 LHDC 无声、AAC 可用；作者回复称“没招”。
- 关于小米 17 断网时修改蓝牙名称，作者给出的路径是“关于设备”中操作。
- 有用户报告跨安卓版本从 v3.0 升级到 v4.0需备份数据并清数据刷；另有评论称此前使用同一作者的包可直接升级。两种说法对应条件不完全相同，原帖未提供逐版本升级表，应以包的具体底包和安卓版本为准。
- 评论称 v4.0 会删除隐私文件，且可能影响微信来电接收；这属于用户报告，原帖正文没有列出具体删除项或影响机制。
