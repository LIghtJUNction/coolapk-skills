# 小米15系列与REDMI K90U官改 OS4 v4.0.7

## 版本与适配范围

原帖标题为“【官改喵】15/15P/15U/K90U 官改OS4 v4.0.7更新”。正文列出：

- OS4.0.0.6（15）
- OS4.0.0.5（15P、15U）
- OS4.0.0.7（K90U）
- 安全更新日期：26.08.01

该版本自述支持“在用本人任何包的用户”直升，以及指定版本的官方包和第三方包直升；第三方包升级的 Bug 不确定。明确不支持从“解密包”直接刷，原帖警告可能造成 data 丢失。仅限作者指定机型，且要求已解锁 Bootloader；其他机型或未解锁设备不支持。原帖未给出官方包指定版本清单，也未给出第三方包兼容矩阵。

## 刷入方式

- 卡刷：通过 TWRP 刷入。
- 线刷：先解压整个压缩包，再运行刷机脚本。
- 评论补充：包内有两个 `.bat` 文件，一个清数据，一个保数据；回复称双击执行即可。评论没有提供文件名、脚本内容、具体主机环境或保数据脚本成功条件。
- 原帖要求不要单独使用包内文件，并称文件经过作者签名；这属于发布者声明，不能据此推断文件安全性或签名验证机制。
- 评论中有人报告从江南版本保数据升级后出现绿线、死机、黑屏，后来清数据刷入；也有人报告江南版本保数据升级成功。两者均为个例，不能据此保证或否定兼容性。作者在官方包保数据问题下的答复是“理论可以”，同时建议备份。

## 随包组件和已知差异

作者评论称包自带 KSU，管理器需要自行解压并安装。与“江南包”的对比评论称此包的调整更多、可自定义内核、含额外壁纸；评论同时提到江南包修改较少、接近官方精简。以上比较来自评论用户描述，不是版本规格表。另有评论称该包的两个内核选项都是官方内核，未提供包内截图或文件以供确认。

针对 K90U，作者回复称风扇问题“还没修”。有评论建议用 root 手动开启风扇插件，但没有给出插件名称、来源或步骤，不能作为已验证解决方案。关于 K80 精简模块的评论只表达缺少该模块，没有给出模块链接或兼容信息。

## 评论报告的问题与操作线索

下列内容是评论用户的报告或建议，未经独立复现：

- 相机切换到 50M/5000 万像素时画面卡住或相机卡死；另有用户称长焦也有此现象、其他模式正常。评论中还报告官方包双清刷入也出现相机卡死，因此现有材料不能确认故障仅由此官改包引起。
- 有用户报告微信消息或视频来电收不到、消息延迟。评论建议在“设置 → 附加功能 → 电池优化”中找到微信并设为“后台无限制”；这是用户提供的排查建议，不是作者确认的修复。
- 有用户报告主题商店动态壁纸不可用；作者回复称与“主题破解”冲突，后续会修。此处记录的是当时的计划，输入中没有后续修复版本信息。
- 有用户报告通话拨出和接入无响应；评论提及墓碑、rekernel-x，并建议重新刷一次，但没有确认原因或最终结果。
- 有用户报告 K90U 风扇不可用；作者称尚未修复。
- 有用户报告充电变慢、底部导航栏过低导致文字截断、美团人脸识别页面白屏闪退、Google 账号异常等；所给评论没有足够的作者答复或可复现条件，原因未明。
- 关于“液态玻璃高级材质”，作者回复称已加入。另有用户在对应讨论中称关闭 Magisk 模块 `hyperunlocked` 后问题解决；该反馈没有说明适用问题范围或复现条件。
