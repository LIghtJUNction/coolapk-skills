# NexusHyper 全机型 v4.0.12：刷入说明与用户报告

## 版本与刷入方式

原帖标题为“NexusHyper 全机型 v4.0.12更新”。作者称该包支持使用其本人其他包的用户直升；指定版本的官方包可直升；第三方包也可尝试直升，但作者表示可能有Bug。解密包不支持直接刷入，作者提示此操作可能导致 `/data` 丢失。

原帖说明这是卡线一体包：卡刷时通过 TWRP 刷入；线刷时先解压整个压缩包，再运行包内刷机脚本。仅限作者指定机型，要求已解锁 BL；其他机型或未解锁 BL 不支持。原帖没有列出指定机型和官方包的具体版本号。

评论中有用户报告从上一版本直升，使用包自带 TWRP，未禁用模块便刷入；也有人报告官改包换官改包时清除数据后刷入。它们是各自的使用经历，不构成所有机型和来源包均可保数据升级的保证。另有用户称从第三方系统降至 MIUI 14 可一步线刷，但这是评论者建议，未见作者确认；降级会清除数据的说法也来自评论。

## 评论报告的问题与现象

以下为用户在本帖评论中的个人报告，不能据此认定每台设备都会复现：

- **流畅度与内核：** 小米 13 用户报告仍有掉帧，并称退回 2.4.5 使用；另一位用户称其 13 使用官方内核后比先前版本好。评论还将 2.2 与 JK 内核、2.4.5 与 Neko 内核联系起来，并称两者都有卡顿、后者较轻。原帖没有说明这些版本或内核对应的设备构建，不能泛化为 v4.0.12 的统一内核配置。
- **功耗与调度：** K70 用户对比 OS3 与 4.0 时，报告游戏性能感受差别不大、4.0 游戏功耗似乎较低、部分游戏出现锁帧，且续航有所改善；同一讨论中有人称用 Scene HP 接管调度后没有再遇到锁帧。这是个人体验和归因，测试条件未给全。另有用户报告从 4.0.9 升至 4.0.12 后，B站功耗由 2 瓦多升至约 4 瓦；也有用户报告刷机后耗电异常，第二天有所改善。不能将这些个例合并为确定的版本功耗结论。
- **相机：** K90U 用户报告 v4.0.9 使用徕卡经典风格拍照时，转盘变焦可能令预览显示变绿；录像和其他徕卡滤镜未出现该现象。评论将其归因于移植相机包，但没有修复版本信息。K90U 与 15 系列用户另报告徕卡真实风格拍摄时右下角缩略预览花屏、点开照片正常，有人称次日自行恢复。K60 用户称相机不可用，并分享了一个可能的修复项目：<https://github.com/LanRhyme/MiuiCamera-Fix>。评论还提及安装其他机型相机应用作为个人尝试；未说明具体包或兼容条件。
- **系统功能及兼容：** K70 用户报告开启高级材质后通知栏和控制中心没有液态玻璃材质、桌面有；评论提示查看作者置顶，但未给出具体配置步骤。另有用户报告小爱不可用（自述为 4.0.9、未刷精简模块），原帖评论未给出诊断结论。用户还报告 NFC 开关或设置项不可用、K70 Pro NFC 异常、主题商店打不开、蓝牙无法开启、LHDC 清数据升级后无声、息屏一段时间后断网、文件互传不能发送图片、堆叠小部件重启后重置，以及内存扩展开启前后显示相同；这些问题均未在可见评论中得到明确的版本级修复确认。
- **相机以外的操作反馈：** 有用户称清除“负一屏智能助理”的数据后，小部件下载恢复，并有人反馈该办法有效。这是评论者报告，未明确验证其适用版本及机型。
- **充电与硬件功能：** 小米 15 Pro 用户报告全新刷入后只能以个位数瓦数充电；缺少充电器、线材、温度和电量等条件，不能判断原因。

## KSU、模块与系统修改

作者在评论中说明包自带 KSU，管理器需自行解压并安装。另有用户描述自己的两台设备均使用 KSU；该用户称元模块用于需要挂载系统文件或修改物理路径的场景，并报告未安装元模块时设备状态显示“全绿”。这些是评论者对其设备的经验，不能据此推定所有模块都不需要元模块，也不能确认其所说状态检测的具体工具或版本。

评论还出现对隐藏环境模块、KSU/面具、内核伪装及游戏封号风险的讨论，没有提供可复现的配置步骤或可靠验证。不要据此推断刷包一定会安装或启用某种特定 root 管理器；“自带 KSU”仅来自作者评论。

## 可见的具体修复命令

作者给出的 v4.0.12 已知问题是清数据后磨砂玻璃消失，并提供以下命令。原评论说明在 MT 管理器的终端管理器中执行，且该终端已授予 root：

```sh
su -c setprop persist.sys.background_blur_supported_overlay false && su -c reboot
```

命令先将 `persist.sys.background_blur_supported_overlay` 设为 `false`，成功后通过 `&&` 重启。原帖称该操作可解决所述问题；没有进一步说明撤销方式或其他版本适用性。
