# 国行设备语言与系统组件适配限制

排查跨地区 ROM 的语言适配时，记录机型、ROM 地区、系统版本和出现问题的具体组件，分别核对语言选项与组件翻译。

帖子举例说明了国行设备面向日语用户时的语言限制：

- 中国版小米手机的系统语言设置中没有日语选项，帖子所述用户改用中文或英语，并依靠记忆或图标操作。
- 帖子称部分国行欧加系设备（举例 Find X8 Ultra、一加 12）在 ColorOS 15 设置为日语后，仍有部分系统组件未适配日语；有人使用谷歌截屏翻译辅助操作。

这些是帖子中的具体观察，不构成所有设备、版本或组件的完整兼容表。未提供逐组件清单或系统更新后的复测结果。
