# Local Dream 生图记录

来源：[酷安原帖 74624239](https://www.coolapk.com/feed/74624239)。以下是正文描述，未复测软件、读取九张样张或下载模型。

## 计算与精度

按原帖描述，Local Dream 使用骁龙 Hexagon NPU 和 FP8 权重计算路径，NPU 承担主要矩阵去噪；提示词解析、多模态特征编码仍涉及 CPU 与内存。不能把整个流程理解成只有 NPU 工作。

模型组合为 Unsloth 的 DiT FP8 权重、Qwen3-VL 4 位文本编码器、官方 BF16 VAE 权重；运行时还会做精度适配。正文没有具体文件名、哈希或下载地址，不能补造。文件精度也不能直接证明每个算子实际采用的执行精度。

作者称这条 Qwen Image 2.1 路线主要面向骁龙 8 至尊版及之后的受支持平台，还依赖系统与运存；App 内其他模型可能门槛更低。该说法不等于独立验证过的软件兼容清单。

## 配置与结果

非 Turbo、20 步、CFG 1.0，使用 Web 控制台跑测。应用可在局域网开启服务，把手机作为生图后端；正文没有服务端配置命令或控制台源码。

| 原帖设备/条件 | 正文结果 |
| --- | --- |
| 红魔 11 Pro+，24GB，骁龙 8 Gen 5 至尊版 | 1536×1536 可整张解码；拉到 2048 触发切片并出现接缝 |
| 红魔 12 Pro+，16GB，骁龙 8 Gen 6 超级至尊版 | 与前机跨机对比统一 960×960，给预览和遥测留余量；不挂遥测时作者称 1024/1216 也能出图 |
| 相同输入、分辨率的文生图 | 后者耗时约缩短 8%，单张约 2 分钟出头；加入参考图后两机均超过 5 分钟 |
| 后者文生图整机功率 | 平均 9.8W、峰值 11.7W；前者平均略高于 10W、峰值约 13W |
| 加入参考图 | 后者整机功率反而更高，电池温度上升稍快 |
| 另一台 16GB、骁龙 8 Gen 5、原帖简称 Neo8 的设备 | 960×960、20 步文生图约 3 分钟 |

正文开头另提到 1024×1024 单张约 2 分半钟，没有明确绑定为上述统一对照组；不把它合并成 960×960 的成绩。结果不是所有同平台设备的保证。

## 成图问题

- 透明背景提示词产生花色坏块；作者检查原始 PNG，并在手机客户端复现。数值精度是怀疑方向，尚未证实与上游 VAE 半精度溢出修复同因。
- 招牌排版文字更易笔画错乱。4 位文本编码器、分辨率和推理设置都可能影响结果，不能认定单一原因。
- 电脑与手机的精度、推理实现有差别，不能要求相同提示词得到像素级一致图片。

遇到这些现象，应保留模型组件、精度与生成设置作为问题记录。原帖没有提供已经验证的修复参数，不生成所谓通用修复命令。
