# LR511C 随身 Wi-Fi（MDM9615M）设备枚举与接口线索

本记录仅保留硬件接口与 USB 枚举线索，未在本库验证基带固件与改造步骤，不传播改串号操作。

- 设备：LR511C 随身 Wi-Fi（双 SIM 卡槽 + TF 卡槽 + USB 口 + 100M 网口）。
- USB 连接与驱动枚举：接入电脑后先识别为 CD 光驱，安装驱动后枚举出一个 RNDIS 网卡和一个串口（`Qualcomm Application`）。
- 拆机基带观察：2026-06-23 更新记录指出掀开两片屏蔽罩后可见高通 `MDM9615M` 基带芯片。
