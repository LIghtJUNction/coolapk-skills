# 真我 GT8 屏幕刷新率超频记录

原帖称，作者基于版本 473 和 583 制作了 DTBO 文件，并在其设备上测试到 200Hz 可稳定运行；240Hz 会导致无法开机。作者认为 165Hz 已足够日常使用，并称《节奏大师》可稳定运行在 165 帧率。以上是单机测试记录，不代表其他设备或系统版本适用。

原帖给出的操作描述是：将下载的 `dtbo.img` 刷入 `dtbo` 分区并重启；开机后不会自动启用 165Hz，需要使用“多系统工具箱”强制全局设置为 165Hz。作者称可选 2K + 165Hz 或 1.5K + 165Hz。原帖没有提供具体刷写命令、分区设备路径或工具箱设置截图内容，不能据此补写刷机教程。

作者提示：刷错可能导致无法开机；其给出的恢复思路是刷回原本的 `dtbo.img`。超频可能缩短屏幕寿命或引发其他问题。帖子称适用基础版本为 473、583，并明确表示其他版本理论上不适用。
