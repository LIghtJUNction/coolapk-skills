# 短帖汇总：设备 ROM 移植进展、BakaSU 修复与三包换机依据

整理自酷安社区简短技术发布与维权记录（未读配图与评论，未做实机验证）。

- **vivo S18e 直刷 EROFS Android 17 LineageOS**：[酷安原帖](https://www.coolapk.com/feed/75038236)（`imgs=5`）— 通过 `fastbootd` 直接刷入（非 DSU/虚拟机），VoLTE 已通过模块修复。
- **小米 2S LineageOS 23.2（Android 17）**：[酷安原帖](https://www.coolapk.com/feed/74611693)（`imgs=5`）— 已修复早期挂载不到存储的 Bug。
- **LineageOS 24（HyperOS 4.0.5.0 底层）适配进展**：[酷安原帖](https://www.coolapk.com/feed/74596686)（`imgs=9`）— 内核、相机、指纹驱动提取自 HyperOS `4.0.5.0`，相机、指纹、背屏、外放、拨号、NFC、蓝牙与 Wi-Fi 均已跑通。
- **Windows 11 ARM 手机端适配进展（`s5khmx` 相机与驱动）**：[酷安原帖](https://www.coolapk.com/feed/74925246)（`imgs=8`）— 新增主摄 1 亿像素 `s5khmx`（AF/MF）、手电筒、听筒及自带录音无杂音支持，后续推进前摄/超广角与触摸屏。
- **红米 K30 5G `BakaSU` `v4.2.0-rc3-35252-susfs`**：[酷安原帖](https://www.coolapk.com/feed/74915186)（`imgs=3`，`https://github.com/acgmnc/BakaSU-Redmi-K30-5G-Driftwood`）— 修复编译脚本补丁应用不全问题并补齐 SUSFS 剩余 3 项功能。
- **华为应用市场 1.0.7 邀测客户端特性**：[酷安原帖](https://www.coolapk.com/feed/75041401)（`imgs=5`）— 支持单/双列切换、底部导航栏自定义、横竖屏优化与自备 API 的 AI 总结（Mate 80 Pro Max / Pura X View 话题）。
- **《移动电话机商品修理更换退货责任规定》三包换机依据**：[酷安原帖](https://www.coolapk.com/feed/75025645)（`imgs=9`）— 记录在保修期内主机经两次修理仍不能正常使用时，依据三包规定可要求销售者免费更换同型号同规格主机。
