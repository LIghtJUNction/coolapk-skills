# 一加 Ace 7 Pro：BL 解锁与 Root 刷写步骤（原帖记录）

## 适用范围与证据边界

原帖将方法归于一加 Ace 7 Pro及其所称的“8Gen5处理器漏洞”，并提到 ColorOS 17。原帖没有提供处理器漏洞细节、固件版本、镜像版本或实测记录，因此这些是发帖者的说法，不代表已独立确认的适配结论。原帖包含5张图片，但图片内容未提供；评论也未提供且评论读取未完成。

原帖列出三种方案：

1. **免解锁 Root**：刷写 `abl` 和 `efisp` 后，不解锁 BL，直接刷入 Root。
2. **解锁 BL 后伪回锁**：按教程操作；正文未说明具体步骤。
3. **正常解锁 BL 并 Root**：刷写后擦除 `efisp` 并还原 `abl`；正文未进一步说明擦除与还原命令。

## 原帖列出的刷写步骤

### 1. 获取临时 Root 权限

原帖称可从社区选择越狱软件获取临时 Root，再授予 `shell` 权限。未提供具体工具名称、版本或命令。

### 2. 推送并刷写分区镜像

原帖提到可用 adb 工具箱先推送文件再刷写，也称可用 Scene 或爱玩机工具箱。以下命令按原帖保留：

```sh
adb push efisp.img /data/local/tmp
adb push abl.img /data/local/tmp
adb shell "su -c 'dd if=/data/local/tmp/abl.img of=/dev/block/by-name/abl_a'"
adb shell "su -c 'dd if=/data/local/tmp/abl.img of=/dev/block/by-name/abl_b'"
adb shell "su -c 'dd if=/data/local/tmp/efisp.img of=/dev/block/by-name/efisp'"
```

命令通过 `adb shell` 在设备端执行，并由 `su -c` 以 Root 权限运行 `dd`，将 `abl.img` 写入 `abl_a`、`abl_b`，将 `efisp.img` 写入 `efisp`。原帖没有给出镜像校验值、备份步骤或分区恢复命令。

### 3. 开启 OEM 解锁并进入 fastboot

原帖要求设置中开启 OEM 解锁。随后重启设备，每隔约 1 秒按一次音量下键，直到进入白色小字界面；原帖称其为“superfastboot模式”。

在电脑的 adb 窗口执行：

```sh
fastboot flashing unlock
```

原帖展示的输出为：

```text
fastboot flashing unlock
OKAY [  0.009s]
Finished. Total time: 0.010s
```

原帖说明，选择免解锁方案时可跳过解锁流程。该输出只是原帖给出的示例，不能证明其他设备或版本会得到相同结果。

### 4. 刷入 Root、清除数据并启动

原帖要求再次进入其所称的“superfastboot模式”，用工具箱刷入 Root 权限，然后清除数据。若设备进入恢复模式，原帖给出的操作是选择“简体中文”并格式化数据。开机后安装“面具”软件；原帖未注明具体版本或下载地址。
