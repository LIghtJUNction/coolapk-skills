# 鸿蒙伙伴 SDK 与天马 OLED 技术发布记录

## 鸿蒙伙伴 SDK 适配（历史记录）

[2024 年论坛报道](https://www.coolapk.com/feed/61229729)列当时已适配的百度地图与定位 SDK，以及鸿蒙伙伴 SDK 市场和中国信息通信研究院的 SDK 管理平台专区；文中导航、轨迹等 SDK 仍处于后续适配计划。文章提到融云使用 Rust 共享跨平台能力，开发者当时遇到 Rust 工具支持和 ArkTS 线程模型相关适配问题。应查具体 SDK 当前文档、版本、许可和权限，不能将历史支持计划视为现状。

文章列出的合作伙伴支持计划报名期为 2024 年 12 月中旬至 2025 年 3 月 31 日，属于历史信息。9 张配图未读。

## 天马天工屏 2.0

[2026 年发布介绍](https://www.coolapk.com/feed/73439453)称 N1 发光材料面板支持 3840Hz PWM、1nit 暗光、3600nit 峰值亮度及 95% BT.2020 色域覆盖；面板样机参数不等于所有采用该技术的手机实测表现。文章提及通过光谱调整和人因研究优化体验，但蓝光与红光比例、器件寿命增加等数字缺少充分的测试定义和公开方法。

色域覆盖、调光频率、亮度、光谱、环境和使用时长是不同维度；不能凭单一指标判断护眼效果，也不能把厂商的健康宣传当作临床效果证明。7 张配图未读。
