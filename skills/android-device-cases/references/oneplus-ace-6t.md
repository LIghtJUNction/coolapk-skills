# 一加 Ace 6T：临时 Root 前置流程的边界

## 已报告范围

报告写明一加 Ace 6T、ColorOS 17，但没有完整系统构建号或已验证内核范围。不能推广到一加其他型号，也不能据此认定 ColorOS 17 的所有补丁版本均适用。

## 可提炼的知识

文字将有线或无线 ADB 的基础授权、Open Window 应用授权、临时 Root 执行分成不同阶段。排障时应逐段记录状态和错误，不把 ADB 连通当成已经获得 Root，也不把临时权限当作重启后仍有效的永久修改。

教程给出的估计耗时、自动重启和多次重试描述，只是该报告的经验。进度停滞时先保留日志并查明当前阶段，不能据此设置无限自动重试。
