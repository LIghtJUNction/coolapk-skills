# 联想拯救者 Y700 四代：112/117 系统 Root 镜像与 9008 刷机包

## 适用范围与选项

原帖更新的是联想拯救者Y700四代 **112版本** 自带Root权限的9008刷机包和免解锁Root镜像。管理器列表另注明支持112/117系统；不能据此推定9008整包也有117版本。另有单独免解锁镜像供选择管理器。

原帖列出的管理器及版本支持范围：

- APatch：无镶嵌版、镶嵌版
- KernelSU：LKM 模式
- ReSukiSU
- SKroot
- SukiSU Ultra
- FolkPatch 3.8.5：APatch 分支版本，无镶嵌版、镶嵌版

原帖称 FolkPatch 镜像没有打包进刷机包，须单独刷入 Boot 分区。

## 原帖给出的内核信息

112/117 系统的原内核版本：`6.6.89-android15-8-g14220ae4ce65-ab13680582-4k`。原帖同时列出构建信息：`#1 SMP PREEMPT Mon Jun 23 07:30:57 UTC 2025`。
