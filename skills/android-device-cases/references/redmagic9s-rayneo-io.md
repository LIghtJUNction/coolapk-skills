# 红魔 9S Pro 系列与雷鸟 iO 发布资料

## 红魔 9S Pro 和游戏本 16 Pro

[2024 年发布文章](https://www.coolapk.com/feed/57237124)列骁龙 8 Gen 3 超频版、LPDDR5X、UFS 4.0、6.8 英寸 AMOLED 屏下前摄屏及最高 22000 转/分风扇。9S Pro 配 6500mAh/80W，9S Pro+ 配 5500mAh/165W；发布起价分别 4799 元与 5799 元。充满用时和游戏帧率是厂商数据，温度、功耗和测试设置未完整说明。

同期游戏本 16 Pro 列 i9-14900HX、RTX 4060/4070 选项、16 英寸 2.5K/240Hz 屏、雷电 4、HDMI 2.1 和 80Wh 电池。文章列 4060/16GB/1TB 首发尝鲜价 10499 元起，4070/32GB/1TB 12999 元；限时渠道价格另计。扩展容量及显示输出取决于具体配置和连接方式。9 张配图未读。

## 雷鸟 iO 智能眼镜

[2026 年发布文章](https://www.coolapk.com/feed/73357577)列 34g、双目显示、单色光波导与 Micro LED，支持旋钮和头势交互；标称 33 英寸等效画面、1800nit 入眼亮度及两天续航，具体测量条件和使用负载未详述。发布定价 2499 元，首发到手价 1996 元起。

文章描述语音记录、翻译与通知，以及录音指示灯和设备端脱敏等设计；这些是厂商对功能和隐私处理的描述，不能视为独立安全审计结果。模型接入、语言数量与功能支持会随服务、地区及版本变化。9 张配图未读。
