# 联想 Y700 无极：BL 解锁、Root、伪回锁与 TEE 处理

## 适用范围与风险

原帖面向联想 Y700 无极平板，介绍 BL 解锁、Root、可选的 efisp 伪回锁、字库备份及 TEE 损坏处理。作者特别提醒：解锁 BL 会清除设备数据。原帖还提醒申请解锁名额有限，建议上午申请；若使用 QQ 邮箱，需在自助查询中查找邮件。

## 解锁前准备与申请

原帖列出的准备项：ADB 工具箱、SN 解锁文件、预先安装的 Android 驱动、一键 Root 工具箱、efisp 伪回锁文件。原帖没有给出这些工具的版本或独立下载地址；文件分享页的具体文件清单未提供。

1. 在平板设置中开启 USB 调试和 OEM 解锁（原帖描述 OEM 解锁开关位于 USB 调试上方）。
2. 重启到 bootloader 并读取设备信息：

   ```sh
   adb reboot bootloader
   fastboot getvar all
   ```

3. 原帖称 `fastboot getvar all` 输出中的 `(bootloader) gserialno` 后面是序列号。Bootloader SN 由两段拼接：

   ```text
   Bootloader_SN = Bootloader_SN_Part1 + Bootloader_SN_Part2
   ```

   申请时读取并拼接自己设备的两段值；不复制他人的设备身份串。
4. 通过官方申请页申请解锁文件。原帖报告每日申请名额有限，并建议尽量上午提交。

## BL 解锁

确保已进入 bootloader；若已退出，重新执行 `adb reboot bootloader`。将下方占位说明替换为实际解锁文件路径，原帖命令为：

```sh
fastboot flash unlock 解锁文件地址
fastboot oem unlock
```

原帖称第一条命令执行后出现两个 `OK` 表示写入成功。随后执行解锁命令，并用音量键选择第二项、电源键确认。解锁会清除设备数据。

## Root

原帖给出的做法是：设备启动后开启 USB 调试，使用“一键 Root 工具箱”执行 Root。原帖未说明工具名称、版本、具体操作、适配固件或验证方式。

## 可选：efisp 伪回锁

原帖将此步骤标为按需操作。进入 bootloader 后刷入伪回锁文件，再进入 recovery：

```sh
adb reboot bootloader
fastboot flash efisp 伪回锁文件地址
fastboot reboot recovery
```

原帖接着建议在恢复模式执行双清并开机；其报告称开机后无需重新刷 Root，直接安装所用的 Root 管理器（原文仅称“面具”，未明确种类和版本）。原帖没有提供双清菜单的具体选项、Magisk 版本或验证结果。
