# OPPO A7 Pro Max、vivo X Fold6 与雷鸟 iO 发布资料

## OPPO A7 Pro Max

[2026 年发布文章](https://www.coolapk.com/feed/73078953)列 10000mAh 电池、80W 有线充电、27W 反向充电、6.78 英寸 1.5K 屏和前后 5000 万像素摄像头，后摄支持 OIS。发布价为 8+128GB 2199 元、12+256GB 2699 元、12+512GB 2999 元。

文章称通过 IP69K 和特定环境、跌落测试，具体条件与试验报告应单独核对；实验室防护等级不能保证实际跌落或进液后无损。七年电池寿命、72 个月流畅度与充电效果为厂商宣称，不构成实际使用寿命保证。9 张配图未读。

## vivo X Fold6

[发布文章](https://www.coolapk.com/feed/72536609)列天玑 9500 超能版、8.02 英寸内屏、6.51 英寸外屏、等效 7000mAh 电池及 80W 有线/40W 无线充电；标称 IPX8/IPX9 防水与 IP5X 防尘。发布价 12+256GB 7999 元起，16GB+1TB 限量版本 11299 元。

文章介绍工作台的五窗口串行布局、四窗口平铺，以及跨窗口拖放和保存布局；应用对分屏、拖放与并行的支持需逐项验证。手机远程操作 PC 智能体需先在电脑端部署；可导入自定义技能的描述不代表导入的代码或远程操作自动安全。外接增距镜的等效焦距不能当作裸机镜头参数。7 张配图未读。
