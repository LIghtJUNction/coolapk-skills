# 魅族 21、MYVU 与 Flyme Link 发布资料（2023）

[发布文章](https://www.coolapk.com/feed/51650029)列魅族 21 使用第三代骁龙 8、6.55 英寸 120Hz AMOLED、2 亿像素主摄、4800mAh 电池、80W 私有快充及最高 65W PD，标称 198g、7.9mm。发布价为 8+256GB 3399 元、12+256GB 3699 元、12+512GB 3999 元；通知环灯支持来电、充电等场景。具体 PD 功率依充电器、线材和温度而变。

MYVU 普通版文章列重 43g、单色 Micro LED 光机及 2499 元发布价；探索版列重 71g、双目全彩光波导及 9999 元预售价。Flyme AR 介绍触控、手机、语音和指环交互，翻译与导航等依赖设备、软件及服务支持，发布宣称不保证当前服务可用。

Flyme Link 当时介绍手机与车机间的任务和地址流转，文章列银河 E8 为首款接入车型；功能和适配应按车机、手机及系统版本核查。9 张配图未读。
