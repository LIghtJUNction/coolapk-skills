# OriginOS 4、BlueOS 与 iQOO Neo11 至尊版

## OriginOS 4 和 BlueOS（2023 发布资料）

[开发者大会报道](https://www.coolapk.com/feed/50695939)描述 BlueLM 的 1B、7B 等模型，以及 OriginOS 4 的离线翻译、会议助手和系统助手；具体模型、功能和离线能力按机型及版本核对。文章称 7B 模型与微调框架开放，但未给出下载地址和许可证，使用前应自行核验发布方的权重、代码及授权条件。

底层方面，文章将“不公平调度 2.0”描述为对计算、网络、I/O 和内存资源的调度优化；BlueOS 则描述通过内核抽象层兼容 Linux 和 RTOS，提供 SDK 与 Studio。文章称部分系统框架使用 Rust；Rust 的内存安全机制不能保证整个系统不存在安全漏洞，也不能据此推断全部组件均由 Rust 实现。9 张配图未读。

## iQOO Neo11 至尊版（2026 发布资料）

[发布文章](https://www.coolapk.com/feed/73313165)列天玑 9500M、LPDDR5X Ultra、UFS 4.1、9100mAh 电池及 100W 有线充电；屏幕为 6.83 英寸 2K，标称全亮度 DC 调光和最高 500Hz 多指触控采样。后置 5000 万像素主摄及 800 万像素超广角，文章列 IP68/IP69、NFC 与超声波指纹。

发布零售价列 12+256GB 3699 元、16+256GB 4099 元、12+512GB 4299 元、16+512GB 4699 元；首销价和补贴价取决于时间、地区及资格。文中 Wi-Fi 穿墙距离、游戏帧率和电池寿命为厂商宣称，不应脱离测试环境推广。9 张配图未读。
