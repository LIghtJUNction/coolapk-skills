# ColorOS 17 界面观察

[用户观察](https://www.coolapk.com/feed/71901855)称，众包中的新版云服务展示了浮窗与底部弹出菜单的界面变化：浮窗菜单去除分割线、增加背景模糊并调整选中状态；底部弹出菜单也增加背景模糊并调整布局，另有圆角优化。这是当时预览版本的观察，未给出应用版本、系统构建号或稳定版适用范围；两张图片尚未读取，未独立验证。

[另一条反馈](https://www.coolapk.com/feed/73831786)称新版“山之道”实时天气壁纸在下雨时显示雨滴，并在时钟上留下水迹。正文未说明设备、系统或壁纸版本，图片未读取，不能据此确认所有设备均支持。
