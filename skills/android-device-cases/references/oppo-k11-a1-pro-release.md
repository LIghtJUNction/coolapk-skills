# OPPO K11 与 A1 Pro 发布资料

## OPPO K11（2023）

[发布文章](https://www.coolapk.com/feed/47922807)列骁龙 782G、6.7 英寸 120Hz OLED、5000mAh 电池及最高 100W 有线充电，主摄为 5000 万像素 IMX890、1/1.56 英寸并支持 OIS。文章称支持存储卡最高 1TB；安装方式和版本限制需另查。文章正文称最高 12GB 内存，价格表却列 16GB+512GB，两处矛盾，实际配置应核对具体销售版本。

发布价列 8+256GB 1899 元、12+256GB 2099 元、16+512GB 2499 元；前两款首销分别优惠 100 元。1% 至 100% 最快 26 分钟和四年流畅为发布方宣称，缺少完整测试条件。7 张配图未读。

## OPPO A1 Pro（2022）

[发布文章](https://www.coolapk.com/feed/41048424)列 120Hz OLED 曲屏、2160Hz PWM、1 亿像素主摄、4800mAh 电池及 67W 充电；标称厚 7.7mm、重 171g。文章仅写高通 6nm 八核、最高 2.2GHz，未明确芯片型号，不据此推断具体型号。

发布价为 8+128GB 1799 元、8+256GB 1999 元、12+256GB 2299 元。RAM 扩展借用存储空间，不能当作同容量物理内存；30 分钟由 1% 充至 80% 是厂商数据，未独立验证。9 张配图未读。
