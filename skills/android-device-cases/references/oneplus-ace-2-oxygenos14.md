# 一加 Ace2：OxygenOS 14 历史刷机记录

来源：[原帖 56788384](https://www.coolapk.com/feed/56788384)。作者使用一加 Ace2、Windows 11 和可传输数据的 USB 线，记录一次刷入 OxygenOS 14 的过程。没有完整 ROM 构建号、解锁和分区布局资料；下列内容是历史路径，不是可直接照做的完整安装流程。

## 资源寻找与 payload

原帖明确不提供下载网址，只给搜索词：`fastboot enhance 大侠阿木云盘`、`oxygen os14`、`大侠阿木工具箱`、`柚坛工具箱`，另提到 Super ADB 与 Ace2 板块中的 TWRP。不能据此补造下载地址或把搜索结果视为可信制品。

其在 Fastboot Enhance 中选择设备，再“重启到 fastboot”，观察到设备代号变化；随后搜索 `cow` 并逐个删除，最后以“忽略未知的分区”方式刷入 ROM 内的 `payload.bin`。**原帖没有列出 COW 项、快照状态、应保留的分区或适用固件条件，所以不能将这段删除操作推广为通用刷机准备步骤。** 界面上的代号变化本身也不足以确认模式和分区状态。

## 更新后恢复 Root 的原帖路径

当时缺少当前系统包，作者用柚坛工具箱从物理分区提取 `boot_a`、`boot_b`，选当前槽位的镜像，交给所选 Root 管理器修补，再把修补文件传回电脑。原文没有给出槽位检查命令、镜像校验或各管理器与该固件的兼容证据。参见 [OTA 镜像与 Root 目标](../../ota-boot-image-extraction/SKILL.md)；先核对实际固件和修补目标，不能仅凭管理器偏好决定刷哪个分区。

以下是原帖两条字面命令，**占位路径并非可执行参数，且只在分区实际存在、镜像与设备及当前固件匹配时才有意义**：

```text
fastboot flash boot 新boot文件路径
fastboot flash recovery 你的twrp.img
```

原帖还将“没有 recovery 分区就嵌入 boot”一并提及，但没有提供构造镜像的步骤或该机型布局证据，不整理成替代命令。作者另写首次重启前格式化 data 并备份；没有列出应备份的分区、恢复方法或数据保留条件，不能承诺无损。
