# 在 HyperOS 2 桌面启用 HyperOS 3 搜索框

## 原帖报告的机制与修改

原帖称，HyperOS 3（OS 3）桌面的小搜索框由桌面根据系统版本号判断是否显示，不需要额外底层依赖。帖中给出的 Smali 指令为：

```smali
sput-boolean v0, Lcom/miui/home/common/utils/HyperOsVersionUtils;->ATLEAST_OS3:Z
```

原帖说明将上方指令中的 `0x3` 改为 `0x2`，即可在 OS 2 开启搜索框；但贴出的指令本身没有出现 `0x3`，因此无法从正文确认该数值所在的具体指令或修改位置。不要据此臆造完整补丁。

原帖还称，修改版需要核心破解，并且要配合 OS 3 搜索应用。未提供桌面或搜索应用的包版本、适用机型范围、核心破解方式及具体安装步骤。小米 14 只出现在原帖标签中，不能据此认定为经过验证的适配机型。
