# 极空间 NAS 初始设置及 cpolar 隧道记录

## 初始设置与访问

原帖描述的硬件流程为拆下磁吸前盖、打开硬盘盒锁、抽出硬盘盒安装硬盘，再接电源和网络开机。首次注册时，手机需与极空间处于同一局域网；找不到设备时可扫描设备前盖二维码。按 App 指引注册管理员并格式化硬盘，原帖称格式化后方可作为极空间硬盘使用。

电脑端可通过 `zconnect.cn` 登录管理员账号；原帖另提到可用设备 IP 加 `5055` 访问，但未给出具体地址。文章还描述在应用中添加 Docker 到桌面并选择 Docker 数据存放硬盘；Docker 版本、镜像与容器配置未提供。

## cpolar 安装与隧道

原帖命令如下：

```sh
sudo curl https://get.cpolar.sh | sh
sudo systemctl status cpolar
```

正文明确说明移除插入的“删”字后执行；恢复出的 `https://get.cpolar.sh` 与 coordinator-reviewed 链接一致。原帖称在 NAS 主机 IP 的 9200 端口打开 cpolar 管理界面，输入注册账号登录。示例外链为 `http://192.168.50.100:9200`，这是文章演示地址，不保证适用于其他设备。

在 Web UI 创建隧道：名称示例 `jkj`，协议 `http`，本地地址 `5050`，域名类型选随机域名，地区选 `China VIP`。原帖称可从在线隧道列表取得公网地址并访问。固定地址流程为先在“预留”中保留二级子域名，再编辑 `jkj` 隧道，设置域名类型为二级子域名、填写保留名称、地区选 `China Vip` 并更新；示例名为 `jkj1`，不是通用地址。
