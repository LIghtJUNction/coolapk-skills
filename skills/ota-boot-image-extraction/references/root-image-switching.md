# Root 镜像与管理器卸载不是同一个问题

[问答 56458251](https://www.coolapk.com/feed/56458251)的标题问 Magisk 转 KernelSU 后如何卸载面具，答复只说从当前系统镜像提取 boot、修补并刷入，没有给管理器 APK 的卸载步骤。

[问答 56414328](https://www.coolapk.com/feed/56414328)针对 Magisk 转 APatch，描述刷入含对应补丁的 boot，并提出无法开机时刷回能启动的镜像。该答复还称同一 boot 可含两者；没有兼容性测试、打补丁顺序和具体设备条件，不能当作可稳定共存的保证。

可保留的思路是：镜像包含哪些改动、管理器应用是否安装、其他分区或模块是否还保留，应分别确认。刷回原厂 boot 只能说明该镜像里的改动被替换，不能据此断言整个设备的所有 Root 痕迹或管理器已清理。

两条答复没有型号、完整固件、分区布局、插槽、下载 URL 或命令，也没有说明 boot/init_boot 等不同安装目标。因此不生成通用刷写命令，不把其他设备的镜像当恢复包。这里是历史问答范围说明，不是完整迁移/卸载教程。
