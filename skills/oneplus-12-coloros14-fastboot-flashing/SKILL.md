# 一加 12 ColorOS 14 线刷流程（原帖记录）

## 适用范围与证据边界

## 所需组件

原帖列出的电脑端组件：

- OPPO USB Driver Setup V4.0.1.6
- ColorOS 助手 1.3.29
- `adb_driver`
- 高通 Fastboot 驱动：`fastboot_driver_32`（32 位系统）、`fastboot_driver_64`（64 位系统）
- MTK Fastboot 驱动：`MTK_USB_All_v1.0.8`
- 一加全能工具箱 21.2

## 操作步骤

### 1. 备份

刷机前备份手机数据。原帖提到两种方式：云盘备份，或使用 ColorOS 助手备份到电脑；微信数据建议再用微信电脑端单独备份一次，以降低备份损坏导致数据丢失的风险。

### 2. 解锁 Bootloader

1. 打开“设置 → 关于本机 → 版本信息”，连续点击 7 次以开启开发者模式。
2. 打开“设置 → 其他设置 → 开发者选项”，启用“OEM 解锁”和“USB 调试”。
3. 关机，同时按住音量减和电源键，进入 bootloader/Fastboot 模式，再用 USB 连接电脑。
4. 在一加全能工具箱 21.2 中选择“2，一键解锁 Bootloader（Root 前必须执行）”；输入 `2` 进入确认页面，再按工具提示输入随机码。
5. 手机端用音量减选择 `UNLOCK THE BOOTLOADER`，按电源键确认。原帖说明解锁会自动格式化 `data` 分区并重启，因此此前必须完成备份。

### 3. 刷入镜像

1. 关机，同时按住音量减和电源键进入 Fastboot 模式，并连接电脑。
2. 打开 `Lian-Payload-Flash-Tool`，输入原帖给出的口令 `lianbox123` 进入功能界面。
3. 选择“1.欧真加常规设备刷机降级转国际”，输入 `1` 并按 Enter 继续。
4. 选择已在电脑解压的镜像目录 `线刷包PJD110-Coloros14.0.0.803CN01`。原帖称其对应包名为“一加12-Coloros14.0.0.803CN01-标准镜像包-By_lian86”。
5. 等待智能刷机完成并重启。

原帖没有给出工具界面以外的命令行指令；此处保留其菜单路径、输入值、目录名和条件，不推测额外命令。

### 4. 重新上锁

原帖在刷机完成后记录了重新上锁步骤：关机并按音量减和电源键进入 Fastboot，USB 连接电脑；在一加全能工具箱 21.2 选择“8，一键上锁 Bootloader（慎重）”，输入 `8`，再按提示输入 `Y` 和随机码，等待重启。

重新上锁前应确认当前系统镜像与设备相符。原帖没有说明不匹配时的后果，也未提供此步骤的独立验证结果；不要把这段记录视为适用于其他机型或镜像的保证。

### 5. 恢复数据
