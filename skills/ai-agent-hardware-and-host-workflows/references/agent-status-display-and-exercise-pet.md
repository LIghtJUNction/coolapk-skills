# Agent 状态显示与运动数据养成宠物

## Agent 状态显示

系统分为两部分：Agent 端运行状态桥服务，接收并整理运行状态，再通过 SSE 推送；小方块屏幕上的 App 收到状态后，切换角色动作和提示效果。示例覆盖休眠、思考、工作、调用工具、完成和报错等状态，共 10 种。App 有主页面和设置页面，设置项包括状态桥地址、访问令牌和形象选择。

角色表现本质上是把状态字段映射到对应静态图片或提示效果。案例另有动作和提示音，但原帖未提供状态字段定义、SSE 消息格式、服务端实现或 App 下载链接。

## 角色素材制作

原帖描述的素材流程是先制作角色母版，固定比例、结构和核心特征；再按连续帧生成动作，后续帧以前一帧为依据，以提高角色一致性；最终可导出透明背景 PNG。该方法也可用于制作一组表情图。原帖没有提供生成工具、提示词或可复用素材。

## 运动数据驱动的宠物 Demo

手表把每日步数、热量消耗等数据同步到 NAS 服务端，服务端宠物有饥饿、体力和心情等状态。运动数据兑换为食物、玩具和互动道具；小方块端运行宠物并与服务端同步。宠物支持跑动、跳跃、注视方向等简单互动。

原帖明确指出这仍是简陋 Demo：宠物种类少、动作帧数偏低、部分动作未调顺，手表同步不够顺滑，生病与进化系统尚未完成。没有提供兑换公式、同步协议、支持的手表型号或健康数据接口，不能据此假定特定设备可接入。
