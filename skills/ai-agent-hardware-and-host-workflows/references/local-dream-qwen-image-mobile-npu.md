# Local Dream：手机 NPU 运行 Qwen Image 2.1 的实测记录

## 计算路径与硬件门槛

原帖称 Local Dream 利用高通骁龙 Hexagon NPU 和 FP8 权重计算路径，减少运行时权重反量化与数据重排开销；NPU 负责主要矩阵去噪，提示词解析和多模态特征编码仍由 CPU 与内存协同完成。作者称 Qwen Image 2.1 的这条 NPU 加速路线主要面向骁龙 8 至尊版及之后的受支持平台，并依赖系统调度和运存配置。原帖还指出应用中可能有硬件要求较低的其他生图模型。

## 原帖测试条件与结果

测试使用 Local Dream 内置非 Turbo 配置，20 步、CFG 1.0。作者用 Web 控制台自动跑测，记录整机放电功率、速度和发热。原帖未提供 Local Dream 版本、完整脚本或 Web 控制台地址。

- 红魔 11 Pro+：24GB 运存，骁龙 8 Gen 5 至尊版（原帖简称 8E5）。1536×1536 可整张解码；2048 分辨率触发底层切片并出现明显接缝。
- 红魔 12 Pro+：16GB 运存，骁龙 8 Gen 6 超级至尊版（原帖简称 8EE6）。为给实时预览和遥测留出内存，跨机比较使用 960×960；作者称不挂遥测时，16GB 机器本地运行 1024 或 1216 也能出图。
- 在作者相同输入、相同分辨率的比较中，8EE6 平均耗时约缩短 8%，纯文生图单张约 2 分钟出头。加入参考图后两边均超过 5 分钟。
- 纯文生图测试中，8EE6 整机平均放电功率 9.8W、峰值 11.7W；8E5 平均略高于 10W、峰值约 13W。加入参考图后，8EE6 整机功耗反而更高，电池温度上升稍快。
- 另测 16GB 的牢真 Neo8（骁龙 8 Gen 5）：960×960、20 步文生图约 3 分钟。

这些结果来自作者测试，原帖没有提供可用于跨设备复现的完整遥测数据；不能视作所有同芯片机型的性能保证。

## 模型文件与质量现象

原帖描述的模型组合为：DiT 使用 Unsloth 发布的 FP8 量化权重，文本编码器使用 Qwen3-VL 4 位量化版本，VAE 使用官方 BF16 权重文件，运行时会做精度适配。手机端和电脑端的推理实现、精度设置有差别，结果不保证像素级一致。

作者复现了两个问题：输入官方推荐的透明背景提示词时，背景变成花色坏块；招牌等排版文字比电脑端更容易出现笔画错乱。作者怀疑透明背景异常可能涉及数值精度，但未确认与上游曾修复的 VAE 半精度溢出是否同因。文字问题也可能受 4 位文本编码器、分辨率和推理设置影响，原因尚未确定。

手机离线生成可用于头像、简单海报、服装参考和概念草图；作者提醒高负载会带来功耗和发热。文章未提供项目仓库或应用下载 URL，不能补造资源链接。
