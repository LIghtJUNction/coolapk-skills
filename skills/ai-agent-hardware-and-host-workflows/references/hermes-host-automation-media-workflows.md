# Hermes 主机助手：HTML 视频、可编辑 PPT 与本地模型实验

## HTML 动画生成视频

原帖描述的生成链路是：HTML 组织页面结构，CSS 负责视觉样式，GSAP 管理动画时间轴，HyperFrames 逐帧渲染网页画面，最后由 FFmpeg 输出 MP4。该方法适合可调整、可复用的图表动画、展示和报告视频；作者指出它不适合炫酷特效或视觉表现要求很高的宣传片。原帖未提供具体命令、版本或资源链接。

## SVG 页面转换为可编辑 PPTX

原帖介绍的 PPT Master 工作流：接收需求并整理内容结构，规划页面并制定设计规范，生成 SVG 页面，进行质量检查和后处理，最后导出 PPTX。其目标是将 SVG 页面转换成原生可编辑的 DrawingML 形状，兼顾版式自由度与后续编辑。作者提醒实际产物仍可能有元素未对齐、句子过长等问题，需要人工调整；精细、稳定地持续输出需要针对不同主题打磨模板和规范。原帖未提供该 skill 的公开链接或具体操作命令。

## Obsidian 收藏夹与本地模型

作者复刻了 AI 智能收藏夹，并与主机 Obsidian 联动，自动同步文件、总结归纳，提供向量搜索和 RAG 问答。运行主机处理器为 Ultra 5 125H，作者称本地处理速度偏慢。

作者记录了一次模型对比：此前使用 Qwen3.5 9B，问答响应约需 2 分钟；随后让 Hermes 比较 Gemma4 E4B，并检查 GPU 加速表现。Hermes读取运行日志获取预填充和解码数据后，按报告更换了 E4B，但视觉模型没有更换，因为精度不如 miniCPM-v。原帖没有提供量化方式、推理框架、完整测试参数或原始成绩，不能据此推导普遍性能结论。

## 主机与用途

案例把 Hermes 放在一台空置的极摩客 K9 上，设备刷入 Ubuntu，作为与主要数据环境隔离的试验主机。作者还用它查看服务和日志、记录环境、部署容器、自检修复，以及生成视频和 PPT。原帖没有提供容器部署命令或 Hermes 配置细节。
