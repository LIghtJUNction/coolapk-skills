# 超级风扇 App：ROOT 风扇控制与适用性说明

来源：[酷安动态 72675182](https://www.coolapk.com/feed/72675182)

该动态介绍一款“超级风扇”App，称其可让散热风扇以极限状态运行，转速比官方“超级强冷”模式高 40%。动态没有提供实现代码、安装包下载地址、版本号或测试数据，因此此性能描述是来源中的产品宣称，不能据此推导具体转速上限或其他机型兼容性。

## 使用步骤

1. 安装 App 后授予 ROOT 权限。
2. 点击桌面图标切换风扇开关。App 没有可交互界面，桌面图标本身就是开关。
3. 可通过控制中心开启风扇，以覆盖游戏专属转速。
4. 风扇转速大于 20000 时会显示 `MAX` 标注。来源未说明转速单位，也未提供读数或截图细节。
