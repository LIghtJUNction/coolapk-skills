# Root 环境下的手机风扇控制：已知行为与适配限制

资料介绍的应用通过桌面图标切换风扇开关，也可从控制中心开启风扇；作者称这可覆盖游戏专属转速。使用前需授予 Root 权限。作者在评论中表示，应用需要向 `/sys` 写入内容，因此 Shizuku 权限不足以替代 Root。

1.1 版本说明在帖子[应用介绍与更新记录](https://www.coolapk.com/feed/72682726)中明确描述新增一键提升转速功能，用来处理进入游戏或解锁后转速恢复默认的问题。帖子还宣传其转速比官方“超级强冷”高 40%，并称超过“20000”时显示 MAX；原文未提供“20000”的单位。这些数字与效果是发布者陈述，不是本资料独立测量的结论。有用户提到转速下降或智能调速受影响；机型、系统与复现条件不全，不能确认因果或普遍性。

目标硬件没有被明确确认。K90Max 只是待验证的推测，不能视为已适配；其他机型的评论反馈彼此不一，也不足以建立兼容列表。高转速的温度、功耗、噪声、风扇寿命与长期安全性均无可靠测量数据。资料中的 Root、风扇驱动及热管理操作有设备相关风险，应先核实设备、内核接口和原厂控制行为。
