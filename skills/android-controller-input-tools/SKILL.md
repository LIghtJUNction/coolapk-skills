# Android 蓝牙手柄与虚拟手柄

## 蓝牙手柄应用

原帖称该应用支持 Android 9 及以上，不需要特殊权限，可把安卓设备作为蓝牙手柄连接到 Windows、Linux 或 Android。连接 Linux/Android 后可直接使用；连接 Windows 时输出为 DInput，需要在 Windows 安装随分享内容提供的软件转换为 XInput。应用不支持震动（力反馈）和线性扳机。原帖没有提供应用名称或单独项目页，下载分享页：<https://www.123865.com/s/iu7KVv-bAssH>。

## 虚拟手柄 v1.0

原帖称该版本用于支持手柄的游戏，支持陀螺仪；其输入被描述为驱动层虚拟手柄，而不是虚拟键盘。悬浮窗会遮挡触摸，可通过调整键位缩小遮挡区域。触摸事件不能同时交给虚拟手柄和游戏处理，因此不能用一根手指控制虚拟手柄、另一根手指同时滑动游戏视角。

下载分享页：<https://www.123865.com/s/iu7KVv-zj2sH>。原帖未给提取码、应用包名或具体兼容机型；图片未读取，无法补充图片中的界面或配置细节。上述兼容性与功能均为帖子报告，未独立测试。
