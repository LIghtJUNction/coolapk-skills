# ROM 二次打包对比中提到的文件与组件

## 帖子描述的检查对象

一篇针对小米 10 系列 ROM 二次打包争议的帖子提到，包体对比时检查了以下对象：

- `boot.img` 哈希，用于比较两个镜像是否相同。
- 刷机脚本中的机型认证部分。
- `system`、`product` 与 `vendor` 分区内容及文件位置。
- `system` 中的修复 rc 文件，以及从 `product` 移到 `system_ext` 的 WebView。
- NFC 相关应用与服务文件的放置位置。
- `product` 中的屏幕 `displayconfig`、生物识别组件及构建工具留下的 identifier 文件。
- `vendor` 中的 zram IO 优化二进制文件，以及与其配套的 rc 和 SELinux 规则。

这些可作为 ROM 结构审查时的对比线索，但原帖没有给出对应命令、文件路径、哈希值、工具版本或可复现的完整操作步骤。不能仅凭该帖把其指控视为已独立证实。

## 证据边界

原帖包含多张图片，但图片内容未提供，无法核对截图中的具体差异。帖子附有两条酷安链接，链接指向的内容在本次输入中未展开；它们不是 ROM 下载链接，且不能代替缺失的图片证据。哈希相同只能说明被比较对象在该哈希算法下匹配，不能单独证明软件安全或阻止文件被修改。
