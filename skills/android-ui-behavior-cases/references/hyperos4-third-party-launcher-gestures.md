# HyperOS 4 第三方桌面强制三键导航 ADB 全面屏手势修复

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- **小米澎湃 HyperOS 4 第三方桌面强制三键导航的 ADB 手势修复**
  - [酷安原帖](https://www.coolapk.com/feed/74793217)（`imgs=0`）
  - 现象与根因：小米 HyperOS 4 在使用第三方桌面（如锤子桌面、Nova 等）时，系统底层会强制锁定为传统三大键导航栏，无法直接在系统设置中启用手势导航。
  - 验证解决方案：
    - 手机连接电脑开启 ADB 调试，执行命令：
      ```sh
      adb shell settings put global force_fsg_nav_bar 1
      ```
    - 搭配第三方手势导航软件（如 Fluid NG、边缘手势），即可完美实现第三方桌面与全面屏手势共存。
  - 常见替代方案缺陷排障：部分教程提出“在手机分身内开启全面屏导航后再切回主空间”隐藏三键，实测该方案存在严重交互缺陷：底部手势必须从屏幕内部的手势识别区起始向上滑才能识别，无法支持日常从屏幕外边缘向上滑动的自然操作习惯。
