# MateBook Pro S 鸿蒙7、iPhone 18 Pro、X500PM、一加16 与经典老机实测汇编

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- #### [酷安原帖](https://www.coolapk.com/feed/74695624)（imgs=9 未读）
  - **机型与系统版本**：华为 MateBook Pro S，出厂 HarmonyOS 6.1.0 (API 24)，更新至鸿蒙 7（全量包 18.24GB），实测推送 7.0.0.111 SP7 及 SP15 版本。
  - **离屏渲染与多屏输出实测**：
    - 接口限制：Pro S 仅右侧 USB-C 接口支持视频输出，单机仅支持扩展 1 块外接屏幕。
    - 外接 2K 显示器（2560x1440@60Hz）与 1080p 显示器时，系统截图分辨率为 3120x1755（横向像素强制与内屏 3120x2080 一致）；官方文档确认采用离屏渲染（Offscreen Rendering），在中间画布渲染后缩放输出以保证 HiDPI 清晰度；接 4K 显示器则直接映射 3840x2160。
  - **交互手势与触控板冷知识**：
    - 触控板隐藏中键：三指双击（三指轻触两下）即为鼠标中键，可在浏览器中后台打开标签页或关闭标签页。
    - 三指上滑回桌面，三指上推停顿进多任务，SP15 支持三指横滑切换应用（全屏应用按序切换，非全屏小窗会被统一收纳到单侧）。
    - 快捷键体系：鸿蒙键+A（应用中心）、+N（通知中心）、+C（控制中心）、+F（文件管理器）；动画缩放在开发者选项中支持调整至 0.5x。
  - **外设与文档兼容性**：惠普 OfficeJet Pro 9020 通过 USB 直连即插即用自动识别打印。WPS 打印存在字体自动替换：Times New Roman 替换为 FT Thymes，宋体替换为书宋-简，版式排版需人工核对。

- #### [酷安原帖](https://www.coolapk.com/feed/74594691)（imgs=9 未读）
  - **硬件配置与接口规格**：安克（Anker）高刷桌面扩展坞，后置 1x USB-A 10Gbps、2x USB-A 5Gbps、千兆 RJ45、100W PD 输入；前置 1x USB-C 10Gbps、SD/TF 双卡槽（104MB/s）。
  - **多屏输出实测**：ROG 27寸 4K 走 DP 1.4，当贝投影走 HDMI 2.1。实测可稳定输出 ROG 4K + 投影 1080P@60Hz，或 ROG 4K@60Hz + 投影 1080P。

    - macOS 系统连接双外屏仅支持镜像模式，不支持 MST 独立画面扩展；
    - 调整刷新率与升级固件依赖桌面专属应用程序；自带 70cm 主机连接线为固定设计不可更换。
