# G304滚轮飘：原帖转述的售后渠道

## 故障与售后信息

原帖报告一只罗技 G304 的滚轮开始“飘”，但没有提供检测结果、故障原因或维修方法。

发帖者转述客服对两种售后渠道的说明：

- **京东售后**：购买超过180天后申请，原帖称维修是“80%概率”；“80%”为原帖用语，未说明估算或统计依据，不能作为客观概率。客服称处理约需 **7–15天**，寄回时需要附上延长线，并称售后大概率为维修。原帖还称此渠道不会生成新订单。
- **罗技售后**：客服称处理约需 **3–5天**，可换新并报销运费；原帖称此渠道也不会生成新订单。

以上是单篇原帖对客服说法的转述，未独立核实，不应视为当前政策或处理保证。原帖没有说明最终选择及处理结果。
