# OEM 系统温控频点、音频/备份限制与硬件做工反馈

本记录整理自 3 篇社区设备与系统使用反馈，图片未读取，未在本库实机验证。

## 1. OriginOS 5 温控频点与系统功能限制反馈 [60851643](https://www.coolapk.com/feed/60851643)

- 原帖报告温控频点阶梯：`35℃` 约 `2.2GHz`、`40℃` 约 `1.7GHz`、`41℃` 约 `1.5GHz`，且 `41℃` 时相机后期算法失效。
- 同时记录功能限制：tws4 HiFi 禁用了 LDAC 与低延迟模式（仅使用 AAC/SBC），且系统仅支持云端或局域网套件备份图片，不支持直接将应用与数据备份至本机。

## 2. 2 亿像素多档输出与背屏/做工实机反馈

- **2 亿像素多档输出与系统响应** [67942678](https://www.coolapk.com/feed/67942678)：原帖评价 `1200W`、`5000W` 与 `2e`（2 亿像素）三档均可调用算法，但 `5000W` 与 `2e` 出片速度明显更慢；同时肯定冷热启动与相机开关动画流畅度。
- **背屏设计与机身做工** [67548298](https://www.coolapk.com/feed/67548298)：原帖认为该机型衔接缝隙较上代更小、音量键无松晃，背屏具有辨识度但存在大圆角屏占比与手感取舍。
