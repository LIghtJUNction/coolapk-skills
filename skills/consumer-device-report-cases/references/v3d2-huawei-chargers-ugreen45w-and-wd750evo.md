# 节奏坦克 V3-D II、华为原厂头隐藏参数、绿联 45W 卡片与航嘉 WD750EVO 拆解

整理自酷安社区硬件评测与拆解记录（未读配图与评论，参数均按原帖实测/丝印记录）。

## 1. 节奏坦克 V3-D II 便携纯数字转盘体验

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74897995)（`imgs=9`）
- **摘要**：在 V3-D 基础上增大机身与屏幕、继续搭载非智能海贝 OS，专注纯数字输出与捆绑玩法，优化操作逻辑、数字线路、抗干扰与续航（具体听感与接口细节见原帖图文）。

## 2. 华为 22.5W / 40W SCP 原厂充电头隐藏参数与代工厂识别

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74834799)（`imgs=9`）
- **代工厂识别**：新款 22.5W（10V 2.25A）丝印不再直接标注代工厂，可通过序列号首字母区分：`B`=比亚迪、`K`=赛尔康、`H`=航嘉（5V2A 中 `P`=达宏电子）；40W（10V 4A）需通过 3C 认证官网分别检索“华为终端有限公司”与“华为技术有限公司”核对。
- **隐藏规格**：部分带美标能效 V 级标识的 10V 40W 充电头（如 C04）虽铭牌未标，实际需通过 115V 低压测试从而支持 100–130V 输入；早期华为 SCP2 10V 充电头（10V2A / 2.25A / 部分 4A）实测隐藏支持 QC 12V 输出（约 1.5A 水平），而后期畅享 90PM/100PM 配头则无此隐藏档位。

## 3. 绿联 45W 卡片充电器实测与 Y700 四代兼容异常

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74811057)（`imgs=6`）
- **实测表现**：支持 PD 45W 与 PPS（仅给到 11V 档，无 20V）；PD 45W 持续半小时后微降至 40W 可稳定输出；22℃ 环境下通过 11V 4.5A PPS 给拯救者 Y700 四代充电 18 分钟后过热降档至 PD 40W / PPS 11V 2.75A。
- **兼容异常**：接入 Y700 四代长边 USB 3.0 接口时反复断连无法充电，改接短边 USB 2.0 接口可正常充电。

## 4. 航嘉 WD750EVO 炫金战神 ATX 电源拆解记录

- **来源**：[酷安原帖](https://www.coolapk.com/feed/73682736)（`imgs=9`）
- **方案与核心器件**：航嘉自产新布局（区分于老 750EVO），主动 PFC + 半桥 LLC + 同步整流 + DC-DC；风扇为悦伦 `D12SH-12`（12V 0.3A）；EMI 含两对 Y 电容、两颗 X 电容、两级共模电感、NTC+继电器（无 MOV）；整流桥 `GBU608`（800V 6A）、主电容万裕三信 85℃ `450V 390uF` LP；PFC 与 LLC 开关管均为东微 `OSG65R380FEF`、PFC 二极管瑞能 `BYC8X600P`；同步整流东微 `SFS04R011UGF`×2 + 稳先微 `WS2995A`；DC-DC 茂达 `APW7159C` + 华润微 `HGQ22N03A`×4；管控 `NDP5201KC`，5Vsb 极创 `IN2P380C`；输出滤波含柏瑞凯 105℃ 16V 680uF RT×11 与万裕 105℃ 6.3V 1000uF ULR×4。
