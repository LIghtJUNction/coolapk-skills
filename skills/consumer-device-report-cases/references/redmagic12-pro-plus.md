# 红魔12 Pro+：原帖发布记录


**状态与证据：**来源是产品发布稿，规格及性能描述均为厂商发布信息；未提供独立测试数据。文章称于10月15日发布并开售，具体年份在该段未重复标明。

- **平台与性能：**第六代骁龙8超级至尊版、LPDDR5T、UFS 4.1 Pro；CUBE擎天游戏引擎4.0提供AI帧率调度。红芯R5电竞芯片支持全场景光线追踪，包括环境光遮蔽、全局光照，并宣称支持2K分辨率与185Hz超分超帧及多款游戏三效并发。具体适配游戏清单未给出。
- **散热：**ICE魔冷系统采用脉动水冷引擎、驭风5.0主动风扇、超导热复合石墨烯、4D冰阶VC、液态金属4.0。厂商称双晶水冷微泵动力较上代提升85%、功耗20mW；双环抱流道覆盖CPU、电池等热源，使用氟化液。风扇最高转速25500r/min，宣称支持IPX8并具有防尘结构，耐用性提升30%。水道覆盖风道，形成风道与水道之间的热交换。RGB灯效可随游戏状态变化。
- **屏幕与操控：**第九代屏下技术与京东方X11发光材料；185Hz屏下真全面屏，黑边0.96mm、屏占比96.3%。新思触控芯片全局采样率500Hz、瞬时5000Hz，支持湿手触控；肩键全局采样率700Hz。
- **机身与续航：**223g、厚8.5mm、2.5D微弧中框。电池8400mAh，支持120W有线、80W无线充电和旁路供电。双1115E对称扬声器、0815 X轴线性马达、全功能NFC（宣称支持330多个城市交通卡和门禁卡）、Wi‑Fi 7、红外遥控。
- **系统及跨端：**REDMAGIC OS 12，发布稿列出AI魔力岛、跨应用记忆、语音唤醒助手、使用习惯提醒，以及与iOS互传文件。PC模拟器宣称支持Steam直连、账号和存档互通、近百款3A游戏下载即玩，并新增Steam创意工坊和成就展示；文章未列游戏名单或模拟器限制条件。
- **其他产品与上市信息：**GOLDEN SAGA臻金典藏版计划提供24GB+1TB；上市安排待公布。另发布5184分区Mini LED显示器，支持5K双模：2K 330Hz或5K 180Hz。发布稿价格为手机12+256GB 6999元、16+512GB 7999元、16+1TB 8999元；显示器6499元。典藏版信息属于预告，非已上市确认。

发布稿另称机身上下与电源键附近配备双麦克风，并称与育碧合作对《孤岛惊魂》系列等进行全链路调优；没有给出具体版本、兼容名单或复测数据。
