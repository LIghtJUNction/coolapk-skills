# 荣耀WIN2系列：原帖发布记录


**状态与证据：**来源为2026年10月13日技术沟通会报道，系列计划于10月21日发布；数据属于发布前厂商口径。

- **散热：**东风双子星涡轮散热采用双风扇立体架构；稿件称机身最高降温14.4℃，50秒降温10℃。未提供环境温度、负载或测试方法。
- **显示与触控：**2K 185Hz双芯绿洲屏，配荣耀自研WIN Display超显芯片和WIN Touch触控芯片。采样参数包括瞬时触控5000Hz、真十指触控报点率520Hz、陀螺仪800Hz。护眼部分称5920Hz低波动PWM覆盖全高刷档位，并获莱茵全局护眼6.0认证。
- **电池与性能：**WIN RT2为12070mAh，WIN2为10100mAh。WIN2搭载第六代骁龙8超级至尊版，2nm工艺，CPU超大核最高5.0GHz，搭配LPDDR5X Ultra和UFS 4.1。荣耀幻影引擎支持2K+185Hz超分超帧并发及144/165/185Hz原生高刷档位；稿件称多款游戏在2K+185Hz重载场景稳帧超过5小时，40余款头部手游已完成原生高刷适配。未列出具体游戏或测试条件。
- **产品矩阵：**同场亮相的有荣耀WIN平板；稿件还将WIN游戏本、耳机和游戏手柄列入电竞生态矩阵，未提供其规格。
