# iQOO Neo12与“天空之镜”屏幕：原帖发布记录


**状态与证据：**两篇发布前沟通会稿件描述同一屏幕技术和Neo12规划，关键参数略有差异，分别保留原稿口径。Neo12上市后的实机表现未在来源中验证。

- **材料与显示：**维信诺、清华大学和iQOO联合研发“天空之镜”发光材料，基础技术为pTSF（磷光辅助热活化敏化荧光）。沟通稿将其描述为由TADF主体、磷光敏化剂和窄谱荧光材料组成的能量传递体系。维信诺稿称效率提升8%、全局峰值亮度提升10%、寿命提升50%、功耗降低6.5%；30°视角色偏改善18%、75°改善40%。另一篇iQOO稿确认前述主要数值及75°改善40%。这些是稿件报告，未提供测试条件或独立测量数据。
- **2K与185Hz：**维信诺稿称2K像素总量较1.5K提升30%；185Hz相对120Hz每秒多输出54%画面，刷新间隔约5.41ms、单帧渲染时长减少35%。为支持高刷，稿件提到优化微米级屏体电路和走线，薄膜晶体管短沟道由17微米缩至12微米，并使用定制驱动芯片与全灰阶校准。
- **Neo12屏幕口径：**iQOO稿称全屏峰值亮度2200nits；相较Neo11的2K屏，屏幕功耗降低27%，相较Neo11的144Hz刷新率提升至185Hz且屏幕功耗降低10%。维信诺稿则称整机调优后的发光效率较上一代提升18%、屏幕整体功耗降低27%。两种效率口径对象不同，不宜合并为同一指标。iQOO稿另称最低亮度1nit、游戏眩光防护使视觉舒适度提升29.1%，并有XDR动态范围增强。
- **游戏与触控：**Neo12预告搭载自研电竞芯片Q3，支持2K+185FPS超分超帧并发；《穿越火线-枪战王者》被列为该模式适配示例。《王者万象棋》适配原生2K；另称超过50款游戏适配原生185FPS。超感触控芯片支持瞬时采样率最高5000Hz、多指采样率最高500Hz，并使用Q-flex操控技术。性能配置预告包括第五代骁龙8至尊版和冰穹风冷散热系统。
- **时间信息：**发布前稿件称Neo12计划于2026年10月底亮相，并计划与iQOO数字系列构成双旗舰阵容；这是预告信息。
