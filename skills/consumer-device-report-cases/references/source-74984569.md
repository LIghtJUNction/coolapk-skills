# 仰望鼎曜首发信息与原帖参数

## 原帖报告

原帖称，仰望鼎曜在阿联酋阿布扎比全球首发，定位为超豪华行政旗舰轿车，提供行政版与山河鼎韵限量版。车身长度为 5.6 米，前后门可开启至 90 度，采用中轴对开门设计；音响系统为 39 个扬声器，并宣称提供 360° 声场。

原帖还称该车采用四电机驱动系统“易四方”、全新一代“天神之眼”智能辅助驾驶、第二代刀片电池与闪充，CLTC 续航超过 1000 km。

## 价格与限量信息

原帖给出的山河鼎韵限量版预售价为 208 万元，全球限量 399 台。该价格与限量数量明确对应山河鼎韵限量版；原帖没有给出行政版售价。上述价格、配置和续航均是原帖发布时的报道，不代表当前销售、交付或量产状态。
