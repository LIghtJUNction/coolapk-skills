# 国产 MS2131S USB3 采集卡静电击穿与 MS9332 HDMI 隔离实践

- **来源**：[酷安原帖](https://www.coolapk.com/feed/73800232)（`imgs=9`）
- **故障现象**：未做 HDMI 与 USB 3.0 端 TVS 静电防护的国产 MS2131S 采集卡在热插拔（如 DVI 转 HDMI 接显卡）时出现明显电火花，导致主控芯片大短路烧毁，甚至引发显卡对应接口短期花屏。
- **接地误区与隔离方案**：作者指出部分笔记本三孔 DC 电源适配器实际地线未真正连通（“风味接地”），单纯更换电源难以消除电位差；通过先接一层带隔离作用的 MS9332 HDMI 一分二分配器缓冲插拔冲击，可降低直插损坏采集卡与显卡的风险。
