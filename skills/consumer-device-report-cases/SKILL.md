# 消费设备参数与设计案例

先按机型和来源日期选记录，再比较同一统计口径。游戏渲染FPS、屏幕刷新Hz、触控采样Hz是不同指标；屏幕自适应范围也不能直接当作所有游戏的输出帧率。材料效率、面板功耗、整机功耗、典型容量与额定容量各自保留基线，不把不同版本混成一组规格。

这些记录保留原帖已有技术内容，发布稿数据作为厂商宣称、爆料作为未核实报道；均没有独立硬件复测。按具体设备查询：

- [一加16屏幕、游戏芯片与配件](references/oneplus16.md)
- [Neo12与pTSF显示材料](references/neo12-ptsf.md)
- [荣耀WIN2系列散热与双芯屏](references/honor-win2.md)
- [FindN6折叠结构与四窗口工作流](references/findn6.md)
