# 微信 7.0.22 平板模式登录记录

原帖日期为 2025-09-01，并称微信 7.0.22 是支持平板模式的最低版本。作者报告其账号使用微信官网最新 32 位版本仍提示需要更新，因而记录以下操作顺序：

1. 将设备机型改为三星 Galaxy Z Fold 系列；原帖使用 Magisk 模块，但没有提供模块名称或版本。
2. 安装微信 64 位最新版，并以平板模式登录。
3. 执行以下命令，保留应用数据后卸载微信：
   ```sh
   pm uninstall -k com.tencent.mm
   ```
4. 重启设备，安装微信 7.0.22。

作者报告之后可正常使用 7.0.22 的平板模式。原帖另有一个机型伪装模块分享页：<https://wwkb.lanzouw.com/iMsQM3555ivi>。
