# 红米 K60 Pro 刷入 PixelOS 17 卡刷流程与故障排障

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- **红米 K60 Pro 刷入 PixelOS 17 卡刷流程与故障排障**
  - [酷安原帖](https://www.coolapk.com/feed/74936500)（`imgs=1` 未读）
  - 机型与系统：红米 K60 Pro（骁龙 8 Gen 2 / SM8550），刷入 PixelOS 17（基于 Android 17 类原生）。
  - 卡刷标准流程：解 BL 锁 -> 刷入第三方 Recovery -> 刷入 PixelOS 17 卡刷包（非官方底包需先刷一遍官方包以防异常）-> 格式化 Data 分区重启。
  - 核心排障方案：
    1. 耳机无声：刷入 LHDC 模块；
    2. 第三方应用调用系统相机异常：安装核心破解（Core Patch），将相机 APK 包名重命名修改为 `open.android.camera` 后强制安装；
    3. 信号阈值显示不适：使用 Pixel IMS 调节（重启后需重新调整）；
    4. 国内应用通知推送：配置 HMSPush 解决；
    5. 续航表现：1100 多次循环的原装电池实测约 7 小时续航。
