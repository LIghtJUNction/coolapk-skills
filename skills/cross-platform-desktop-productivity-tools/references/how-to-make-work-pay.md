# How to Make Work Pay：可追溯职场指南的构建与证据分级

## 内容结构与证据分级
原帖称 How to Make Work Pay（原名 HowToWorkBetter）包含 32 节、576 条职场建议。每条固定六栏：成本、说人话、收益、证据等级、来源、备注。覆盖入职前调查、工资社保、加班休假、工伤生育、解除劳动关系、竞业保密、退休与失业金等主题。

帖子举例：解除劳动合同时，先取得书面解除通知，写明解除日期和依据；引用《劳动合同法》第四十条、第五十条及最高法相关司法解释。这里记录的是原帖举例，不构成具体案件结论。

原帖列出的证据分布为 A 级 518 条（法律法规、部委规章和官方统计原文）、B 级 51 条（研究或共识）、C 级 7 条（作者经验），合计 576 条；称有 885 处可回到原文的链接。无中立依据的内容会标注“已检索，无可用依据”。这些数量和链接状态按原帖记载。

## 构建与输出
正文为 Markdown，使用 Python、pandoc、typst 构建。原帖称一份源文件生成四种形式：在线检索页、离线单文件 HTML、A4 PDF、EPUB。CI 中有三份检查器，用于检查交叉引用和格式；输入未包含脚本、命令或具体检查规则。

在线检索页可按成本（金钱、时间、毅力）与收益筛选。原帖称 PDF、EPUB 和在线检索页均可在项目 GitHub 获取，但输入未提供具体项目 URL，不能猜测仓库地址。
