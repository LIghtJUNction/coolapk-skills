# BrimDeck：Windows 顶部媒体控制与 AI 用量面板

## 平台与版本

原帖描述 BrimDeck 为 Windows 11 x64 应用，不支持 Windows 10、macOS 或 Linux。顶部界面可设为刘海、胶囊或指示条，调整位置与尺寸；最大化窗口时切换为指示条，全屏游戏或视频时隐藏。鼠标移入展开，移出或按 `Esc` 收起。

原帖记载稳定版 v1.1.1，另有 v1.2.0-alpha.1；分享的是稳定版，安装包约 61.5 MB、单个 EXE。项目较新，原帖报告 2026-09-03 建仓。程序未签名，首次运行可能触发 SmartScreen。

## 媒体控制

面板显示封面、曲名、同步歌词和进度，可播放、暂停、切歌及调整随机、列表循环、单曲循环。它依赖 Windows 系统媒体控制（SMTC），只对能提供系统媒体卡片的播放器生效。可在多个播放器间手动切换或固定一个。

网易云音乐默认可显示曲目封面；要播放和切歌，需在“设置 → 系统”开启“SMTC”。拖动进度、切换循环和红心操作还需开启“完整控制”；原帖指出该模式会让网易云开放本机调试端口，并建议用户自行评估。QQ 音乐可拖动进度；其他播放器能力取决于其媒体会话支持。

## AI 工具用量

面板可并列显示最多 7 个工具的剩余额度、重置倒计时、当天与 7 天 Token 用量及估算费用。原帖列出无需手填密钥、依赖本机登录状态的工具：Claude、Codex、Cursor、Grok Bot、Antigravity、ZCode、DeepSeek Harness。需填写密钥的来源包括智谱 GLM、Z.ai GLM、DeepSeek、New API、Sub2API。还可编写 JavaScript `fetchUsage(ctx)` 接入自定义来源，脚本在沙盒中运行，单次最长 10 秒。

原帖称令牌只在内存中使用，不写入磁盘；手动填写的密钥通过 Windows 加密保存在本机，删除面板列或更换来源时同步删除。使用率达到 70% 与 90% 各提醒一次，每次显示 5 秒。

费用是按接口金额或公开模型单价计算的估值，不是账单。工具登录失效时可能显示“未连接”，需要回原应用重新登录。原帖未实测常驻内存。
