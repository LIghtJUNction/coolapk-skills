# PhotoSuite：PSD 与 PSB 文档编辑

## PSD 保真与文档结构
PSD 不只是单张位图，而包含图层记录、蒙版、混合模式、通道、描述符、图层效果、智能滤镜栈、文本引擎数据、矢量路径、切片和色彩配置等结构。若编辑器无法理解某些结构，可能只显示合成预览或将其压平；保存压平结果无法恢复原有图层结构。

原帖称 PhotoSuite 将 PSD 作为原生格式，目标是往返保留层树、蒙版和混合模式，并支持大型文档 PSB。文章中的保真描述来自项目 README 的转述，没有提供文件样例或独立往返测试。重要工程编辑前应保存副本。

## 原帖列出的功能
- 图层：栅格层、矢量层、图层组、剪贴蒙版、图层蒙版；投影、内阴影、外发光、内发光、斜面浮雕、缎面、颜色/渐变/图案叠加和描边。
- 非破坏性编辑：智能对象与智能滤镜栈，可回改滤镜参数。
- 工具：选框、套索、魔棒、裁剪、画笔、仿制图章、钢笔、文字、渐变、减淡和加深。
- 液化与镜头校正：液化采用交互式网格变形；镜头校正使用 Lensfun 镜头数据库。
- 矢量与文字：Paper.js 处理路径几何和布尔运算；Typr.js 解析字体；HarfBuzz（WASM）处理复杂文本整形，FriBidi（WASM）处理双向文本。支持路径文字、文字变形、OpenType 连字和字距。
- 自动化：解析和回放 `.atn` 动作文件；以 Acorn 提供 JS/JSX 脚本引擎。
- 格式：原帖列为 PSD、PSB、AI、XD 原生支持；位图包括 PNG、APNG、JPEG、WebP、AVIF、TIFF、GIF、TGA、OpenEXR；文档侧包括 SVG、PDF、PostScript。

## 架构、版本边界与适用性
原帖称应用基于 Tauri v2，使用系统 WebView 运行 HTML5、WebAssembly 与 WebGL 前端，由 Rust 宿主处理文件系统、原生菜单、系统对话框、剪贴板和打印；模糊、中值滤波、WebP 编解码及 zstd 压缩等任务使用 WebAssembly。

文章将功能范围描述为 Photoshop CS6 时代，不包括 3D 和生成式填充。浏览器内核处理大型 PSD 可能面临内存压力；原帖建议 8GB 内存设备避免硬开 200MB 以上 PSD。这是经验性建议，不是兼容性保证。原帖称许可证为 GPL-3.0：个人使用可行，修改后再分发需遵守相应开源义务；商业使用条件应以许可证文本为准。板绘画笔与依赖 `.8bf` 商业插件的工作流不适合该工具。
