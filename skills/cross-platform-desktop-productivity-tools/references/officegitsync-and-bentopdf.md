# OfficeGitSync 本地文档防抖备份与 BentoPDF 自托管 PDF 编辑器

整理自酷安社区工具发布与自托管评测记录（未读配图与外链仓库）。

## 1. `OfficeGitSync`：本地无感办公文档版本备份工具

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74082055)（`imgs=0`，`https://github.com/fuypck/OfficeGitSync`）
- **机制**：后台监控指定工作目录中的 Word/Excel/PPT 等文档保存变动，自动过滤 Office/WPS 临时锁文件（如 `~$*.docx`）并在停止编辑数秒后防抖弹窗提示输入 Commit 说明，支持可视化历史回溯与纯本地零联网运行（提供 Windows 单文件绿色版）。

## 2. `BentoPDF`：可自托管的开源 PDF 编辑器

- **来源**：[酷安原帖](https://www.coolapk.com/feed/73345968)（`imgs=3`，`https://github.com/alam00000/bentopdf`）
- **定位**：用于替代高价订阅制 PDF 工具（如 Adobe Acrobat），支持私有部署（与 NextCloud / Immich 同类自托管隐私思路），覆盖基础编辑及扫描件 OCR、隐私涂抹遮盖、文档对比等常用能力。
