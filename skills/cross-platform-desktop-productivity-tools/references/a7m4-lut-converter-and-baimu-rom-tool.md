# 索尼 A7M4 创意外观 LUT 转换器与白幕 ROM 桌面检索工具

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- **索尼 A7M4 滤镜转换器 (a7m4-lut v1.4.0) 开源项目**
  - [酷安原帖](https://www.coolapk.com/feed/75029122)（`imgs=1`，配图未读）
  - **开源地址**：`https://github.com/Itinerary200/a7m4-lut/releases/tag/v1.4.0`
  - **核心原理与转换精度**：索尼无反相机破解固件中自定义 LUT 本质依赖机身“创意外观（Creative Look）”实现，无法直接导入工业标准 CUBE 格式 LUT。该开源转换器通过对通用 LUT 色彩映射进行反解，转换为匹配索尼创意外观的底层色彩参数；当前算法实测色差偏差控制在 $\Delta E_{00} = 0.8 \sim 3.0$。

---

- **白幕ROM：Windows 桌面端多品牌官方与第三方固件检索工具**
  - [酷安原帖](https://www.coolapk.com/feed/74944697)（`imgs=0`，同 [酷安原帖](https://www.coolapk.com/feed/74941292) `imgs=3` 未读）
  - 软件功能：Windows 桌面端 EXE 检索工具，支持按品牌、中文机型名或硬件代码精准查找系统固件版本。
  - 收录库规模：收录 OPPO、一加、真我、小米、红米、联想、红魔共 64,149 条固件记录。
    - 小米 / 红米：合计 54,276 条，覆盖老版 MIUI、HyperOS 历史版本与开发版，清晰标明卡刷包与线刷包；
    - 联想：727 条，覆盖 59 个机型组、102 个硬件代码（如通过 TB522FU 检索拯救者 Y900 13，收录 Y900 14.5/11/13、小新 Pro GT 11.1/13 等线刷入口及 YOGA/启天历史包）；
    - OPPO / 一加 / 真我：独立专区，支持按地区及包类型筛选全量 OTA 与售后包。
  - 使用规则：官方直链与第三方镜像独立标注；增量 OTA 明确注明依赖的基线版本；提供 123pan 下载链接（`https://1817544437.share.123pan.cn/123pan/iJ4Tjv-JUNNv`）。
