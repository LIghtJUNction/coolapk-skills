# 启喵：跨平台统一搜索与本地工具

## 功能与实现
启喵通过用户设置的快捷键打开统一搜索框，涵盖应用搜索、剪贴板历史、计算与单位换算、Emoji、词典、时间戳转换、JSON 格式化和窗口摆位。窗口摆位提供九种布局；锁屏、休眠等动作会先要求确认。macOS 可从搜索框运行 Apple 快捷指令；帖文提到 macOS 26 的系统玻璃效果。

应用搜索支持中文名、别名、全拼和拼音首字母。可关闭自动扫描并手动添加应用；刷新时会清理已卸载项目。剪贴板另有独立窗口，支持搜索、置顶、分组、导出、图片和文件引用及敏感内容打码。系统剪贴板历史需单独启用，另有快捷键；统一搜索框还支持接力粘贴。

翻译与 AI 查询使用用户配置的 OpenAI 兼容服务，需自行填写服务地址与密钥；请求会发往所选服务商。帖文称剪贴板、文件检索、自定义片段默认仅保存在本机，两个同步开关默认关闭；启用多设备同步需配置 WebDAV，敏感条目和文件路径不参与同步。剪贴板历史在本地磁盘以明文保存，重要设备可启用系统磁盘加密。

实现上，帖文称应用使用 Rust 功能层和系统自带网页渲染层，不额外捆绑完整浏览器内核。帖文还称部分命令模型与导入兼容来自 TinyCast 移植，官方署名文件说明了来源。Raycast 扩展兼容仍标记待补齐。

## 平台与使用条件
- Windows：帖文所述为 64 位安装包，双击安装。管理员权限窗口中，手动粘贴可能更合适。
- macOS：Apple 芯片 M1 及以后机型有对应版本；Intel Mac 也有官方发布文件。首次打开可能需在“隐私与安全性”中选择“仍要打开”。自动粘贴需授予辅助功能权限。
- Linux：官方发布页有对应版本；自动粘贴需 X11 与 `xdotool`，Wayland 下手动粘贴更稳。
- 需要联网的实时汇率功能在帖文中仍标记为待补齐。

上手可先设置快捷键、用拼音首字母搜索一个应用，再从剪贴板历史找回刚复制的内容。帖文称功能和参数整理自官方文档与兼容矩阵，但本来源未附具体文档链接或安装包直链。
