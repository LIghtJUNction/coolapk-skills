# Fly Island：Windows 屏顶提醒、剪贴板与待办

## 平台和版本

原帖介绍 Fly Island 为 Windows 10/11 x64 应用，使用 Tauri 2，安装包约 5.45 MB，不打包浏览器内核，依赖系统 WebView2。采用 MIT 许可。原帖记载最新版本 v0.2.15，项目由 FocuSD 更名而来，并于 2026-10-28 至 11-04 连续发布五个版本。项目处于 0.x 快速迭代阶段。

## 功能

应用在屏幕顶部显示无边框置顶小岛，集成消息提醒、剪贴板历史、每日待办、笔记和媒体控制。待办可标完成、设为当前任务，未完成项目可自动结转；每日笔记按天归档为 Markdown，任务和笔记可导出。

剪贴板支持文字和图片，按时间排序，可搜索、收藏、备注并重新复制；可设置历史条数、图片记录和全局唤起快捷键。历史保存在本机应用数据目录，原帖称不上传服务器，断网仍可查看。复制的密码或验证码也可能进入历史；应用提供删除记录和关闭图片记录的设置。

消息来源包括 QQ、微信和 QQ 邮箱。原帖称 QQ 通知与邮箱各保留最近 20 项；邮箱可在岛内查看正文。微信只能提示有新提醒，不展示发送者、正文或条数。QQ 需电脑版登录并开启系统通知权限；QQ 邮箱需开启 IMAP 并使用邮箱授权码，凭据存于 Windows 凭据管理器。

媒体控制接入 Windows 系统媒体会话，实际能力取决于播放器支持。快捷翻译用 `Alt+C` 呼出，可自动判断中英方向或手动指定；按 `Tab` 填入剪贴板内容，每次最多 5000 字，译文可复制。翻译需自备 DeepSeek API 密钥并按用量付费。

AI 状态灯可接入 Codex 与 Claude Code 生命周期钩子，显示运行、完成、错误状态；设置中可安装或修复钩子。外观有经典与液态玻璃模式，字体、颜色、透明度和顶部距离可调，可保存 6 套预设。

## 安装与更新

安装后小岛显示在屏幕顶部，托盘可管理开机启动、更新和设置。缺少 WebView2 Runtime 时按安装提示补齐。原帖称每版附 `SHA256SUMS.txt`，应用内更新包经过签名校验；哈希匹配与签名校验本身不等于证明软件无恶意，也不阻止本地文件被改动。卸载通过系统“设置 → 应用”。

原帖分享：夸克网盘 https://pan.quark.cn/s/863ac3c5ff00，包含 EXE 与官方校验文件；原帖未列出提取码，本文未下载验证。应用仅面向 Windows，没有 macOS 版。
