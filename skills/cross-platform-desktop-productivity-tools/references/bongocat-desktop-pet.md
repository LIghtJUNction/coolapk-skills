# BongoCat：全局输入联动桌面宠物

## 输入事件与动画
原帖将 BongoCat 描述为监听全局键盘按下、鼠标移动和点击、手柄摇杆与按键，并据此驱动桌面模型动作的应用。其模型使用 Live2D，能连续变形呈现表情和动作，不只是循环播放几张 GIF。

原帖称键鼠数据在本地处理、不上传服务器、不记录操作习惯，且应用开源；这是文章的描述，未附网络流量检查或隐私审计结果。

## 架构与资源表现
应用采用 Tauri 2.0：Rust 后端配合系统 WebView 渲染前端。原帖称 Windows 使用 WebView2、macOS 使用 WKWebView；与打包 Chromium 的 Electron 路线相比，Tauri 依赖系统已有 WebView。文章报告 CPU 占用不到 1%，但未给出设备、系统版本和测量方式，不能视为固定性能保证。

## 设置和平台权限
原帖列出的设置：窗口缩放 50%–150%；透明度 25%–100%；鼠标穿透；更换官方模型中心或社区模型。平台为 Windows、macOS、Linux。macOS 首次运行需按系统提示授予“辅助功能”权限，以便监听全局输入。

文章称可下载免安装便携版，解压运行，删除时移除文件夹；没有给出实际文件名、版本或便携包格式。该工具没有喂食、成长、好感度等养成系统，也不以导入 VRM 3D 模型为目标。
