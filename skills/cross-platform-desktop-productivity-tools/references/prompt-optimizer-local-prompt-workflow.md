# Prompt Optimizer：本地提示词优化与测试

## 功能与工作流
原帖介绍的 Prompt Optimizer 为 MIT 协议开源工具，支持系统提示词和用户提示词优化、连续多轮迭代、原始与优化版本对比评估，以及提示词收藏和版本历史。可管理上下文变量、测试多轮对话和 Function Calling，也支持文生图、图生图提示词优化。

模型接入包括 OpenAI、Gemini、DeepSeek、Grok、智谱、硅基流动、MiniMax，以及用户自定义的 OpenAI 兼容接口。模型调用仍由用户承担 API 费用；优化结果会随模型和输入而变化。

原帖列出的使用形态：在线网页 `https://prompt.always200.com`、桌面应用、Chrome 插件和 Docker 自部署。Docker 部署可通过 MCP 协议接入 Claude Desktop 等客户端。原帖未提供桌面端、插件、Docker 的具体安装命令或配置参数。

## 请求与数据存储
按原帖描述，该工具采用纯客户端架构：在网页或桌面端发起优化请求后，设备直接请求模型厂商，不经 Prompt Optimizer 自有服务器中转；提示历史和 API Key 加密保存在本地。此为文章对项目架构的介绍，未附独立审计结果。

不要在公开部署的网页中预置 API Key。原帖引用官方文档警告：`VITE_` 开头的环境变量会打包进前端资源，可能暴露密钥。自用时在界面填写 Key。原帖还称项目于 2025 年因 SSRF 风险移除了内置代理；网页版可能受跨域限制，建议使用桌面版或自建反向代理。没有提供反向代理的配置示例。
