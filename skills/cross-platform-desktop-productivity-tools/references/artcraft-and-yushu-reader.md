# artCraft 安卓移植与鱼书多端阅读器功能要点

整理自酷安社区介绍与发布记录（未读配图与外链仓库）。

## 1. `artCraft`：基于 Rust 的创意/CAD/办公软件复刻与安卓平板移植

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74606418)（`imgs=1`，移植仓库 `https://github.com/MostafaXS1/artcraft-android`）
- **摘要**：原项目使用 Rust 重写专业软件（Adobe/AutoCAD/Office 类功能），体积小、启动快；社区开源将其移植到 Android 平板端（仍在快速修复早期 Bug）。

## 2. `鱼书`：小说、漫画与有声书多端阅读器

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74374709)（`imgs=9`）
- **主要特性**：支持 TXT/EPUB 导入、漫画清晰度增强、有声书刮削与 MultiTTS 插件朗读、文本净化与正则替换、第三方插件/书源导入、WebDAV/AList/OpenList 同步（支持 Android 与 Docker 部署），并支持鸿蒙眼动翻页。
