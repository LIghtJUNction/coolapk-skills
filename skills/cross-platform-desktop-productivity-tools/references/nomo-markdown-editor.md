# Nomo：所见即所得 Markdown 编辑器

## 编辑与文件管理
原帖介绍 Nomo 支持所见即所得编辑和源码模式切换，快捷键为 `Ctrl + E`；两种模式编辑同一份 `.md` 文件。内置侧边栏文件管理、多标签页和最近文件，可直接打开文件夹。安装后自动关联 `.md` 与 `.markdown`；可在设置中绑定常用文件夹作为工作区。

内置 Shiki 代码高亮（含行号）、KaTeX 公式和 Mermaid 流程图。导出格式为自包含 HTML 和 A4 尺寸 PDF；原帖未列出 Word 或 ePub 导出。

## 双向映射与架构
所见即所得 Markdown 编辑器需要让富文本呈现和纯文本 Markdown 语法保持同步。原帖以 ProseMirror 的语义模型解释 Nomo 的双模式设计：渲染结果和源码文本作为同一模型的不同视图。

Nomo 使用 Tauri 2、Svelte 5 和 Rust，通过系统 WebView 渲染，不打包 Chromium。旧版 Windows 可能需安装 WebView2 运行库。文章记录安装包约 17MB，但未给出具体构建版本或测量条件。

## 许可、平台与版本边界
原帖称许可证为 PolyForm Noncommercial License 1.0.0：可使用、修改和分发，但仅限非商业用途；商业使用需取得授权。文章记录当时支持 Windows 和 macOS 12.0+，没有 Linux 版。macOS 快捷键尚未从 Ctrl 迁移到 Cmd，触控板手势和原生菜单仍在完善。

原帖记录项目首版于 2026 年 5 月底发布、当时版本处于 0.4 段位；这属于历史状态。重要文档保留独立副本。Mark Text 的维护状态在原帖中存在相互矛盾的二手说法，不能据此认定项目已停更或已恢复。
