# Go Music DL：聚合音乐搜索与本地曲库

## 项目形态与搜索流程
原帖将 Go Music DL 描述为 Go 编写、AGPL-3.0 许可的音乐搜索工具，项目名为 `guohuiyuan/go-music-dl`。提供 Web、TUI 终端、桌面应用三种形态，并有 Android APK；桌面端据称使用 Rust（Tao/Wry）或 Go 原生窗口。原帖称桌面支持 Windows、macOS、Linux，Android 提供 APK；iOS 只有未签名 IPA，需自行签名。

聚合搜索会并发请求多个平台接口，再按歌名、歌手和时长对齐、去重、排序。试听使用 HTTP Range 请求，支持边下载边播放和拖动进度。原帖称平台共 12 个，举例包括网易云、QQ、酷狗、酷我、咪咕、千千、汽水、B 站、JOOX 和 Apple Music；接口可失效，实际可用平台随接口状态变化。原帖称默认过滤需付费资源。

## 使用方式和本地数据
Web 模式命令原样为：

```sh
./music-dl web
```

该命令启动本地服务，可在浏览器中试听、管理歌单和批量处理。TUI 支持全键盘操作，适合 SSH 远程和脚本场景；原帖建议新用户先使用桌面版。

本地歌单以 SQLite 存储，使用 GORM。原帖称数千首曲库打开较快，但首次目录扫描需要等待；没有提供设备配置或量化耗时。Android APK 内置 ffmpeg。

## 文章所述同类工具差异
原帖称洛雪音乐（LX Music）为 Electron + Vue 3、Apache-2.0 项目，并提到新版默认不带数据源，需要导入自定义源脚本；MusicFree 本身也依赖插件提供数据。以上为文章写作时的状态描述，不能视为当前版本保证。
