# Snow Shot：截图、贴图、OCR 与录屏

## 版本与平台

原帖介绍 Snow Shot 1.4.3，主仓库 `https://github.com/mg-chao/snow-apps`（原帖给出仓库名，补全 HTTPS 为推断），主程序 GPL-3.0，支持 Windows 与 macOS。完整版离线安装包约 59 MB，Mini 版约 23 MB。Mini 版移除 AI 和翻译，保留截图、标注、贴图、拼图、录屏和手动 OCR。默认快捷键为 `Ctrl+F1`，初次使用可在设置中修改以避开冲突。

原帖称 1.4.3 于 2026-10-28 发布，修正录屏工具栏稳定性；1.4.2 修复录制指针颜色偏差。macOS 要求 15 及以上，提供 arm64 和 x86_64 DMG；没有 Linux 版。项目快速迭代，原帖提醒非本地功能接口可能与旧版不兼容。

## 截图、标注和贴图

截图模式有区域、窗口、全屏、滚动和延时。窗口模式可自动识别鼠标所在控件边界。标注工具包括矩形、圆、箭头、序号、文字、气泡、马赛克、取色和裁剪；箭头可加描边，气泡可选云朵形，马赛克强度可调。截图可复制到剪贴板或保存文件，并在可搜索的历史记录中查看。

截图可钉在其他窗口上方；贴图支持图片和文本，文本可设默认字体、字号。

## 离线 OCR 与需要密钥的功能

本地 OCR 使用 PP-OCR 中文模型，检测和识别模型分开，合计约三十多 MB。首次启用需加载模型，之后本地识别；设置中可更换模型大小并启用 GPU 加速。原帖称图片不上传。

表格识别、LaTeX 公式识别和图片转 Markdown 使用视觉模型，需要自行填写 API Key；翻译同样依赖服务配置。原帖列出的翻译配置包括 DeepL、百度、有道及 OpenAI 兼容接口。Mini 版不含 AI 和翻译。

## 录屏、拼图和长截图

录屏可包含鼠标光标与声音。拼图可把多张截图拼成长图，也可将长图分割成多段；滚动截图则用于采集网页、聊天记录或长表格。
