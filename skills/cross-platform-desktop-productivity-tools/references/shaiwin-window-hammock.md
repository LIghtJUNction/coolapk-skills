# 晒窗 ShaiWin：Windows 窗口收纳机制与使用说明

## 版本与适用范围

原帖介绍的 ShaiWin v0.1.4 面向 Windows 10 1809 及以上、Windows 11 x64。项目使用 Rust，单个 EXE 约 1.77 MB，解压即可运行，不要求管理员权限，也不依赖 .NET 或 VC++ 运行库。许可为 MIT + Commons Clause：原帖称可用于公司商业场景，但不能将软件本身拿去出售。仓库：`https://github.com/` 下的 `ShaiWin` 项目地址原帖未给出，不能据名称猜测具体仓库。

## 窗口如何收纳和恢复

拖动窗口标题栏至屏幕顶端并松开，可将窗口收纳为晾衣绳卡片；点击卡片后按收纳前的矩形位置和大小恢复。窗口仍在运行，只是原地最小化；任务栏按钮和 Alt+Tab 项目仍保留。程序只处理用户主动收纳的窗口，不改变任务栏、Alt+Tab 或 Snap 布局。

- `Ctrl+2`：挂起当前窗口。
- `Ctrl+T`：展开或收起晾衣架。
- 快捷键可在 `settings.txt` 修改。
- 卡片可沿绳移动，拖动边角调整尺寸；多卡片避免重叠，布局重启后保持。
- 晾衣绳可常驻，也可设置为鼠标移到屏幕顶部时显示。
- 托盘菜单可挂起当前窗口、全部取下、展开/收起、打开设置、设置开机启动或退出。

“取下”只把窗口放回桌面；之后窗口再次最小化，仍可能自动回到绳上。“取消挂起”才会停止管理该窗口。退出程序时，各窗口分别在原坐标最小化。

恢复时，程序以窗口句柄、进程 ID、进程创建时间和停靠矩形四项信息核对后重新挂回。程序崩溃时，窗口仍是原地最小化状态，可从任务栏恢复。支持多显示器和 Per-Monitor V2 DPI，窗口移到另一屏后按所在屏幕重新计算挂起区域。

## 限制与排障

- 管理员权限窗口受 UIPI 限制，不能挂起，程序会提示失败。
- Chrome 和 Electron 应用可能显示占位卡片而非实时窗口画面，收纳功能仍可用。
- 未签名 EXE 首次运行可能触发 SmartScreen。
- 日志路径：`%LOCALAPPDATA%\ShaiWin\shaiwin.log`。
- 解压 ZIP 后原帖称包含 `shaiwin.exe`、`LICENSE`、`README` 三个文件。卸载为删除程序目录及 `%LOCALAPPDATA%\ShaiWin\`。
- 项目处于快速迭代期；原帖记载 2026-10-28 建仓，数日内更新至 v0.1.4。仓库测试数量（67 个单元测试、7 个端到端脚本）为原帖报告，未独立复核。
