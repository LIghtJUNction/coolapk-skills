# PicLite 图轻：本地图片压缩与批处理

## 图片处理功能
原帖介绍 PicLite 为本地图片压缩工作台，安装包约 2MB。支持 JPEG、PNG、WebP、GIF 互转、等比例缩放和最大宽高限制；自动比较多种候选格式以选择较小输出；可将输出限制为 200KB、100KB、50KB 或自定义目标。

批处理功能包括文件夹递归导入、监测文件夹自动处理、剪贴板监听和全局快捷键。压缩结果可在悬浮窗中复制、预览、撤销、继续缩小或切换格式。其他功能包括文字水印、清除拍摄信息/GPS/设备型号等元数据，以及上传到 WebDAV、S3、R2、OSS、FTP 图床。

## 目标大小与处理架构
原帖称每次调整画质时都会从原图重新编码，并根据真实编码结果显示体积；若参数导致文件变大，“智能防增大”会降级，无法压小时保留原图。文章没有提供编码格式下的测试样本或误差数据。

应用基于 Tauri 2 与 Rust，界面使用系统 WebView；文章以此解释其安装包约 2MB，并与内置 Chromium 的 Electron 应用作对比。原帖称 4K 以上图像在浏览器端处理较慢，建议改用桌面端；没有给出设备和基准测试条件。
