# Chaty：本地模型、文档问答与生成工具

## 功能与运行方式
帖文将 Chaty 描述为整合本地模型运行、聊天界面和文档问答的桌面应用。模型文件保存在本机，由应用加载；作者称无需账号或密钥，断网仍可聊天，聊天记录与上传文档留在本机。此隐私与离线能力为帖文描述，未独立验证。

应用内可搜索并下载模型，下载前会估算机器内存是否足够；也可指向硬盘上已有模型目录，并在设置中切换国内镜像端点。帖文称 Windows、Linux 使用通用显卡运行路径，Apple 芯片使用原生路径，并可按可用显存调整模型运行需求。

PDF 问答先检索用户提供的文档，再生成回答；回答可查看页码引用，找不到依据时会提示未找到。其他功能包括读取代码文件夹、查找问题、修改后运行测试、图像生成、音乐生成和离线语音对话。模型加载、下载与图像生成进度显示在任务栏图标；长任务期间应用会阻止机器自动睡眠，完成后图标提示用户。

## 资源与平台要求
- 小型量化模型约需 8 GB 内存；图像生成建议预留 16 GB 以上。实际需求取决于模型、显存与设备，帖文未给出具体模型清单或基准测试数据。
- Windows：Windows 10/11 64 位，无需管理员权限安装。
- macOS：帖文所述安装包适用于 M1 及以后 Apple 芯片；首次打开可能需在“隐私与安全性”中选择“仍要打开”。
- Linux：官方版本标记为 beta；本帖分享的安装包仅称包含 Windows 与 macOS 版本。

建议先下载较小模型试聊，再拖入 PDF 检查引用。帖文称许可文件随包附带，但未提供项目主页或模型下载直链。
