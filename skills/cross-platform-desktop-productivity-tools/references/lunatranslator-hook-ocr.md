# LunaTranslator：Windows HOOK、OCR 与翻译流程

## 版本和平台

LunaTranslator 是 Windows 翻译工具，原帖列出仓库 `https://github.com/HIllya51/LunaTranslator`（仓库名来自原帖，补全 HTTPS 为推断），GPLv3。v12.1.3.8 于 2026-11-02 发布，原帖称为正式版。x64 主包为 66,686,562 B（约 66.7 MB）；另有 Win7 包和 `x86_winxp` 包。仅支持 Windows。

## 文本获取

三种输入路径：

1. **HOOK**：从目标进程接收正在输出的文本字符串，适合持续出现的游戏对话。原帖说明需要选择目标进程并从候选文本行中辨认对话；选错可能得到菜单文字或乱码。HOOK 失效时可改用 OCR。
2. **OCR**：框选屏幕区域识别文字，可使用内置本地模型，也可接在线或离线 OCR 引擎。OCR 面对的是像素，细字、描边和复杂背景可能漏识别。
3. **剪贴板**：通过剪贴板输入输出；提取结果还可通过 WebSocket 发送给其他程序。

HOOK 与 OCR 的差别在于，HOOK 接取应用绘制前传递的文本，OCR 从图像识字。HOOK 不受画面字体与背景直接影响，但需找到适用进程和文本流；OCR 适用范围更广，却会受图像质量影响。

部分游戏引擎允许把译文嵌回原对话框，其余情况使用浮窗；原帖明确这只适用于部分引擎。工具还包含 Mecab 日语分词与假名注音、MDICT 离线和在线辞书、AnkiConnect 加词、Yomitan 浏览器插件，以及在线/离线 TTS 和 Windows 10/11 系统语音识别。

## 翻译接口与限制

软件 GPLv3 且无订阅；翻译服务另行配置。原帖将接口概括为免注册在线接口、需注册申请凭据的传统翻译服务，以及需要自备 API Key 并按量计费的大模型服务。免费接口可能限流，翻译效果取决于所选服务。

仅 Windows，不支持 macOS 和手机。HOOK 需要配置进程和文本行；OCR 不是视频字幕系统，不提供字幕时间轴，也不处理视频文件。原帖特别指出，针对带反作弊的网游不属于适用场景。本文不提供游戏本体或补丁获取信息。
