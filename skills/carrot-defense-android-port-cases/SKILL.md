# 《保卫萝卜》安卓修改版

## 第一代

原帖称其制作的版本包含以下调整：

- 内购破解，内置修改器。
- `targetAPI 34`。
- 游戏画面全屏、居中显示。
- 移除全部权限、Java 层无关代码及无关资源文件。
- 默认存档位置改为 `Android/data`。
- 可长按游戏桌面图标导入或导出存档。

下载分享页：<https://www.123865.com/s/iu7KVv-Ei2sH>。原帖未提供提取码、应用版本号、包名、具体存档目录或导入导出步骤；图片未读取，不能补充其界面细节。
