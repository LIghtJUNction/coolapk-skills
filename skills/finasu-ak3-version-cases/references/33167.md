# FinaSU-33167 AK3 版本与内核隐藏步骤记录

本记录整理自 FinaSU-33167 AnyKernel3（`5.10.x–6.12.x` 全内核版本）发布说明，原帖外链与图片未读取，未在本库实机刷写验证。

## 版本与适配范围

- **通用 AK3（Android 12–16）**：适配小米、红米、vivo、iQOO、联想、红魔（原文注明除欧加真/魅族外可刷，且仅支持官方系统，不支持第三方系统）。启用 ZRAM 增强算法、BBG 防格机、SUSFS `v2.3.0` 与 0 宽修复。
- **一加 AK3（Android 15–16）**：基于一加官方内核源码编译，仅支持一加官方系统（OPPO、真我勿刷）。启用 BBG 防格机、BBR 网络增强、SUSFS `v2.3.0` 与 0 宽修复。
- **KPM 说明**：需要 KPM 功能时原帖建议改用 KPN 模块实现。

## 刷入与切换注意

1. 匹配设备内核版本选择对应 AK3 包，在 Root 管理器中刷入；若 LKM 模式出现驱动版本不匹配，在工作界面执行“直接安装修补并重启”以对齐版本；管理器内直接刷写失败时可用爱玩机工具箱或第三方刷写工具。
2. **GKI vs LKM 区分**：LKM 模式修改 `init_boot`，AK3（GKI）直接修补 `boot` 镜像；从 GKI 切回 LKM 需先刷回原厂 `boot` 镜像。刷写前务必备份原厂 `boot`。

## 内核版本 / 构建日期隐藏步骤

原帖方法：使用爱玩机工具箱将当前 `boot` 镜像刷入对立槽位，通过 `ReKernelFlasher` 读取对应槽位的内核参数，复制信息后利用 SUSFS 完成内核版本与构建日期隐藏。
