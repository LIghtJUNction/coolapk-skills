# FinaSU-33194 AnyKernel3

## 版本与适配范围

原帖介绍通用版和一加版 AnyKernel3（AK3），覆盖 Linux 内核 5.10.x–6.18.x：

- **通用 AK3**：标称支持 Android 12–16；原帖列出的已知可刷设备品牌为小米、红米、vivo、iQOO、联想、红魔，原文另用“除了O加真/魅族都能刷”限定范围；此缩写不展开为逐品牌已测清单。原帖没有提供逐机型测试结果。
- **一加 AK3**：标称支持 Android 15–16。原帖称该版本用一加官方内核源码编译，只支持一加设备，不支持 OPPO、真我。
- 两个版本均标注只支持官方系统，不支持第三方系统。

原帖同时给出同一个 [OnePlus_KernelSU_SUSFS v2.4.0-r1 GitHub 发布页](https://github.com/LingLuo17/OnePlus_KernelSU_SUSFS/releases/tag/v2.4.0-r1)作为通用版和一加版 AK3 的 GitHub 链接。两个标签指向同一发布页；该页面对通用版设备的适配尚未核验，不能据此确认通用包兼容性。

## 功能

- **通用版**：启用 ZRAM 增强算法、BBG 防格机；含 SUSFS v2.4.0。
- **一加版**：启用 BBG 防格机、BBR 网络增强；含 SUSFS v2.4.0。
- 原帖称两个版本都自带“0宽修复”。
- 如需 KPM，原帖指示通过 [KPatch-Next-Module（KPN）](https://github.com/KernelSU-Next/KPatch-Next-Module)模块实现。

以上为原帖的功能说明，不代表此处另行测试或确认。

## 刷写流程

1. 在 ROOT 管理器中选择与系统设置所示内核版本相同的 AK3 包并刷入。
2. 如果使用 LKM 模式时出现驱动版本不匹配，原帖建议进入管理器的“工作中”，直接安装修补并重启，再刷 AK3。
3. 如果管理器刷写失败，可改用爱玩机工具箱或原帖另列的刷写工具；正文没有明确给失败替代工具命名。教程与工具的分享入口见下文，分享中的文件尚未读取。

## 隐藏内核版本与构建日期

原帖给出的操作顺序如下：

1. 用爱玩机工具箱将 boot 镜像刷入 **b 槽位**；如果当前系统在 b 槽位，则改刷 a 槽位。
2. 返回 ReKernelFlasher，查看 b 槽位显示的内核版本并复制。
3. 使用 SUSFS 隐藏内核版本和构建日期。

原帖未展示相应界面、SUSFS 配置项或具体命令；步骤依赖图片的部分无法从文字还原。

## 备份、恢复与模式差异

刷写前备份原厂 Boot 镜像。若设备无法启动，进入 Bootloader 并恢复原厂镜像。原帖解释：LKM 修补 `init.boot`，AK3（GKI）修补 `boot`；因此从 GKI 转为 LKM 时，应刷回原 boot。

原帖提醒，该内核覆盖的内核版本较多，发布者没有逐一测试，也不保证每个版本都能正常开机。无限重启、无法开机或设备变砖等风险均由刷写者自行承担。这里记录的是原帖声明，不是独立验证结论。
