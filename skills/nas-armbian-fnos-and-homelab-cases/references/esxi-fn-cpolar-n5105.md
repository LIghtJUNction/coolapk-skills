# N5105 上安装 ESXi 7.0、飞牛 NAS 与 cpolar

## 适用范围与证据边界
原帖以 N5105 小主机为例，介绍 ESXi 7.0、飞牛 NAS 虚拟机和 cpolar 隧道配置。正文报告安装及页面访问成功，但没有独立复测。图片未读取；云盘链接未在提供的正文中显示，虽然原帖明确给出 123 云盘永久链接及提取码，缺失的链接不能据此还原。

## ESXi 7.0 启动盘与安装
原帖列出的准备项：N5105 小主机、U 盘、安装时使用的显示器和键盘，以及 ESXi 镜像资源。云盘提取码：`1314`。所需文件名为：

- `ventoy-1.1.09-windows.zip`
- `ESXi-7.0U3v-24723872-NVME-NET-USB-GVCB.iso`

在 Windows 解压 Ventoy 包，运行 `Ventoy2Disk.exe`，选择 U 盘并点击 Install；完成后把 ESXi ISO 复制到 Ventoy U 盘。BIOS 中关闭 Security Boot（原帖解释该镜像不是 VMware 官方签名的操作系统或内核模块），把 U 盘设为 Boot Option #1，按 F10 保存退出。

从 U 盘启动后按屏幕提示进入安装程序，选择 N5105 内置硬盘作为安装位置，设置密码并开始安装。安装完成后拔掉 U 盘并重启，网线接入 ETH0；原帖称启动完成后可通过设备显示的 Web 地址进入 ESXi。

## 在 ESXi 中创建飞牛 NAS 虚拟机
在 ESXi 虚拟机页面创建新虚拟机，按原帖截图选择操作系统和版本，选择存储位置。原帖示例资源配置为 2 CPU、4 GB 内存、100 GB 磁盘；将 CD/DVD 驱动器改为数据存储 ISO 文件并挂载飞牛 NAS 镜像，在虚拟机选项中取消“启用安全引导”。启动虚拟机后按向导安装，安装步骤会提示抹除所选磁盘；选择网卡配置并等待系统启动。

原帖示例飞牛 NAS 地址：`http://192.168.50.109:5666`。地址属于示例局域网环境，不是可复用的公共地址。

## 在飞牛 NAS 安装并配置 cpolar
在飞牛系统设置中启用 SSH，从电脑连接并切换 root：

```sh
ssh cpolar@192.168.50.109
sudo -i
```

安装与状态检查命令：

```sh
sudo curl https://get.cpolar.sh | sh
sudo systemctl status cpolar
```

原帖对安装 URL 的“删”字恢复规则适用于 `https://get.cpolar.sh`。Web UI 示例地址：`http://192.168.50.109:9200/`。注册并登录 cpolar 后，在“隧道管理 > 隧道列表”编辑 `website` 隧道，原帖默认说明该隧道指向 8080/http；将本地地址改为 ESXi 管理界面的实际访问地址。在线隧道列表提供 HTTP 和 HTTPS 地址。

免费随机域名据原帖约每 24 小时变化。长期使用可升级任意付费套餐，在 cpolar 官网预留固定二级子域名，再把隧道域名类型改为二级子域名并填写预留名称。原帖示例名称 `esxi01` 仅是示例，账号间名称唯一性需以实际预留结果为准。
