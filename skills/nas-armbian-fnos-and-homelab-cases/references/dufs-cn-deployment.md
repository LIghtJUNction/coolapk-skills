# Dufs 文件服务：Docker 部署、访问控制与 cpolar 远程访问

## 项目与功能
Dufs 是以 Rust 编写的轻量文件服务器，原帖描述其为单二进制、无需数据库，支持静态文件服务、上传、断点续传、浏览器在线编辑、按文件名搜索、访问控制、WebDAV、目录 ZIP 下载和 curl 操作。原帖报告二进制约 2–9 MB，实际大小取决于编译选项和平台；“9 MB”是作者部署时对其使用版本的描述，不是所有构建的固定大小。

原帖作者修改了界面，增加中文适配、网页初始化密码和拖拽上传提示，并称设置中可切回英文。上游仓库：<https://github.com/sigoden/dufs>。修改版仓库：<https://github.com/JunWan666/dufs>。文中 Docker 镜像为 `tannic666/dufs:latest`。

## Docker 部署
替换宿主机共享目录后运行：

```sh
docker run -d --restart unless-stopped -p 5000:5000 -v /vol1/1000/要共享的目录:/data tannic666/dufs:latest
```

原帖以飞牛 NAS 为例：先确认 Docker 服务已开启，在镜像仓库搜索 `tannic666/dufs` 并下载默认 `latest` 标签；从本地镜像创建容器，勾选开机自启动，在存储设置中把 NAS 文件夹映射为容器数据目录，然后创建容器。打开服务页面后，按页面提示初始化管理员账号。原帖建议重要文件使用复杂密码。

WebDAV 客户端可连接 `http://飞牛NAS的IP:5000` 并输入账号密码。若 Windows 自带映射网络驱动器失败，原帖建议尝试 HTTPS 地址或其他 WebDAV 客户端；原帖未给出 HTTPS 的具体配置步骤。

## 文件、静态页面与权限
网页可拖拽上传文件或文件夹，传完可复制文件链接；原帖说明局域网地址默认只能在同一局域网访问。将 `index.html` 上传至共享目录后，可通过对应链接提供静态页面。目录下载按钮会打包为 ZIP。设置中可调整匿名访客权限，包括全站只读、仅开放 `public` 目录、禁止匿名访问；全站只读模式还可按需允许通过完整链接访问指定文件。

## cpolar 公网访问
原帖在飞牛 NAS 上开启 SSH 后连接终端，再执行以下命令安装 cpolar 并查看服务状态：

```sh
ssh 飞牛用户名
sudo -i
sudo curl https://get.cpolar.sh | sh
sudo systemctl status cpolar
```

安装脚本 URL 原文为 `https:/删/get.cpolar.删sh`；按原文明确说明删除“删”字恢复为 `https://get.cpolar.sh`。原帖称服务显示 `active (running)` 表示启动成功。其示例 Web UI 地址为 `http://192.168.50.212:9200/`，该地址来自原文示例，应替换为实际 NAS 地址。

创建 HTTP 隧道时，将本地地址设为 Dufs 的 5000 端口。原帖称默认 website 隧道指向 8080，需编辑为 5000；随机域名会变化，适合临时测试。固定二级子域名需基础套餐或以上：先在 cpolar 后台预留子域名，再在隧道配置中选择二级子域名并填写预留值。公网分享前检查匿名访问权限，只开放需要公开的文件，并让其他文件保留登录限制。
