# 斐讯 N1 安装 ARM 版飞牛 NAS 与 cpolar

## 适用与证据范围
原帖以官方默认 Android 系统的 N1 为例，描述降级、U 盘启动、将系统写入 eMMC，以及 cpolar 远程访问。文章包含 9 张图片但图片未提供；刷机界面、镜像校验结果和实际安装画面无法复核。步骤及运行成功均为原帖报告。

## 资源与设备
- N1；电源 12V/1A 或 12V/2A；建议大于 8GB 的 U 盘；Windows 电脑、网线、HDMI 线。
- 原帖称 123 云盘资源包含降级脚本、N1 ADB U 盘启动脚本、ARM fnOS 镜像和 balenaEtcher，提取码 **1314**；未提供实际分享 URL。
- 指定镜像文件名：`fnos_Mainland-PE_arm_1.0.0_phicomm-n1_257.img`。
- 指定烧录工具：`balenaEtcher-Setup-1.18.11.exe`。选择目标磁盘时需确认是 U 盘，烧录会格式化目标盘。原帖建议烧录失败时重试，或更换 U 盘并重启电脑。

## 降级和 U 盘启动
1. 设备开启 ADB：按原帖描述，在固件版本处快速点击 4 次。
2. 确认电脑与 N1 在同一网段。Windows 命令提示符执行 `ipconfig`；原帖示例网段为 `192.168.50.xxx`。
3. 运行降级工具目录中的 `run.bat`，输入 `2`，再输入 N1 IP；按提示按任意键（可回车）开始降级。原帖称工具显示完成后即可继续。
4. 用 Etcher 将上述 `.img` 镜像写入 U 盘。运行 `U盘启动.BAT`，输入 N1 IP。设备重启后从 U 盘启动；原帖浏览器地址示例为 `http://192.168.50.254:5666`。

## 写入 eMMC
先在 Web 界面创建管理员账号。Windows 命令提示符通过 SSH 连接，原帖给出的命令为：

```sh
ssh 你的飞牛Nas用户名
```

输入密码后切换 root，再运行 U 盘中的安装脚本：

```sh
sudo -i
./install-to-emmc.sh
```

原帖称写入完成后拔掉 U 盘并重启。此步骤会将系统写入设备内置 eMMC。

## 安装 cpolar 与访问
SSH 登录飞牛终端后执行原帖命令（按其明确说明移除 URL 中插入的“删”标记）：

```sh
sudo curl https://get.cpolar.sh | sh
sudo systemctl status cpolar
```

原帖以 `active (running)` 作为服务正常运行的状态示例。Web UI 地址为飞牛 IP 加 `9200` 端口；原帖示例 `http://192.168.50.254:9200`。登录 cpolar 后，在“隧道管理 > 隧道列表”编辑 `website` 或创建隧道；原帖称默认有两条隧道，在线隧道显示 HTTP 与 HTTPS。测试时访问 HTTPS 地址。

## 固定二级子域名
原帖称免费随机域名约 24 小时变化一次；固定二级子域名需升级任意付费套餐。在预留页面填写地区、名称、可选描述，再编辑隧道，选择二级子域名并填入名称。示例地区 `China Top`、子域名 `fnos01`，每账号唯一。
