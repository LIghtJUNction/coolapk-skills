# 闲置 Android 手机：运动录像、FTP 上传 NAS 与远程查看

## 方案组成与设备条件
原帖方案由 Android 手机运行 IP Camera（沈垚开发）、可选 NAS 接收录像，以及 cpolar 隧道组成。手机检测到画面变化后录像；录像可留存在手机并循环删除较早文件，也可通过 FTP 在事件录像产生后上传 NAS。飞牛相册用于集中查看和回放。作者称事件触发上传无需 NAS 全天接收视频流。

原帖建议 Android 7.0 及以上、摄像头/Wi-Fi/充电正常的闲置手机；演示机为小米 MIX 2S。NAS 为可选项，需支持 FTP；演示使用飞牛 NAS。应用名称相近，原帖提醒下载时核对开发者。其称使用的是免费版，并给出 123 云盘永久链接及提取码 `1314`，但正文未实际显示链接地址，因此无法据此恢复可用下载 URL。

## 固定手机局域网地址
可在手机 Wi-Fi 详情中把 IP 从 DHCP 改为静态，并填写空闲局域网 IP、网关、前缀长度及 DNS；或在路由器中使用 DHCP 静态分配、静态租约或 IP-MAC 绑定。原帖更推荐路由器绑定，避免手填网关和 DNS。示例手机地址为 `192.168.50.162`；绑定后断开并重新连接 Wi-Fi，确认地址不变。若 Wi-Fi 使用随机 MAC/隐私 MAC，原帖建议改为设备 MAC，以便路由器规则匹配。

## 手机录像与本地预览
在 IP Camera 设置中按需配置后，启动“打开 IP 摄像头服务”，按提示授权录像、音频和定位权限。开启运动检测后，画面变化会触发录像并保存到相册；浏览器访问应用显示的局域网地址可查看实时画面。若应用设置了用户名和密码，浏览器访问时需认证。原帖还建议设置后台不受限制、锁定后台等保活措施。

原帖示例实时地址为 `http://192.168.50.162:8081`。该链接原文写作 `http:/删/192.168.50.162:8081`，按原文说明删除“删”字恢复；实际使用应换成手机自己的地址。

## FTP 上传至飞牛 NAS
在 NAS 的“系统设置—文件共享协议—FTP”中开启 FTP。原帖示例 NAS 地址为 `192.168.50.212`，默认端口 `21`，FTP 地址写作 `ftp:/删/192.168.50.212:21`，按原文说明删除“删”字恢复为 `ftp://192.168.50.212:21`。为上传账号配置录像目录的读写权限；原帖使用飞牛相册的 `Photos` 目录。

在手机 IP Camera 的 FTP 上传设置中填写服务器 `192.168.50.212`、端口 `21`、有目录写入权限的 NAS 账号及保存目录 `/Photos`，然后开启录像自动上传。手机和 NAS 应在同一家庭网络。原帖明确不建议将 NAS 的 21 端口直接暴露到公网。

可在镜头前走动触发一次录像，等待上传完成后在飞牛相册查看和回放。若新录像未立即出现，可在相册设置中点“扫描全部”以重建媒体索引。以上为原帖给出的检查步骤及体验报告。

## cpolar 远程查看
在 NAS 开启 SSH 后，通过终端连接 NAS，安装并检查 cpolar：

```sh
sudo curl https://get.cpolar.sh | sh
sudo systemctl status cpolar
```

安装脚本原文为 `https:/删/get.cpolar.删sh`，删除明确标出的“删”字后可恢复为上面的 HTTPS 地址。原帖称 `active (running)` 表示服务已启动。示例管理页面为 `http://192.168.50.212:9200/`，应替换为实际 NAS 地址；文中原链接为 `http:/删/192.168.50.212:9200/`。

在 cpolar Web UI 创建 HTTP 隧道，隧道名称可自定义，例如 `ipcamera`；本地地址填写手机完整地址 `http://192.168.50.162:8081`，不能只填端口，因为 cpolar 运行在 NAS、摄像头服务运行在手机。原帖称隧道在线列表会为同一隧道生成 HTTP 与 HTTPS 两个公网入口，建议使用 HTTPS。首次访问使用 IP Camera 中设置的认证账号密码。免费随机域名会变化；固定二级子域名可在 cpolar 后台预留后绑定到隧道。

公网可访问后，原帖建议确认手机监控页面已启用强密码认证，不要复用 NAS 管理员密码或公开公网地址；无远程查看需求时可暂停隧道。手机长期运行还需留意散热、电池状态、Wi-Fi 稳定性和后台保活。
