## UEFI 后无法返回 Android 的旧帖恢复路径

前提是已备份这台设备对应的 `boot` 镜像，并按工具箱步骤启用 LG fastboot。原帖称启用过程会替换下载模式；它不是一般 Android 的通用准备步骤。

在持续连接数据线的条件下，原帖按音量下+电源重启，黑屏时按音量上进入 fastboot，然后刷回原先备份的 boot。原帖字面命令为：

```sh
fastboot flash boot "path to you boot.img"
```

这是有占位路径的历史恢复命令；没有原镜像、设备状态和分区确认时不能当作可直接运行的操作。本库没有执行。原帖还称 TWRP 不能挂载存储但能进大容量模式时可忽略该挂载问题，不能由此保证存储无故障。

WOA 助手、Mindows 助手和工具箱官网的完整下载页没有给出，不猜地址。原帖配图与评论仍未读取，更新能力和恢复效果均未在设备验证。
