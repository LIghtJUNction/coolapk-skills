# 在 LG G8 上安装 Windows 11 24H2

原帖作者称已提取 Windows 11 24H2 官方版镜像，并将镜像及 `alpha-drivers` 放在 123 云盘。帖子给出的分享码是 `nice`。评论补充了下载链接：https://www.123pan.com/s/FWYIjv-ywIJ3.html

## 刷入步骤

1. 借助 Mindows 工具箱进入大容量模式。
2. 下载并打开 DISM++。在左上角选择“释放镜像”，目标选择手机所在盘，**不要勾选引导**。
   - 原帖还提到另一种处理方式：使用 Mindows 云盘中最新的功能补丁；作者称该补丁修复了无法安装 24H2 的问题。
3. 退出 DISM++，回到 Mindows 工具箱，选择“修复系统引导”。
4. 从作者的 123 云盘下载 `alpha-drivers`，解压并打开 `offlineupdate.bat`。
5. 输入手机处于大容量模式时对应的盘符。
6. 等待驱动安装完成。
7. 启动手机并耐心等待。

## 原帖和评论补充

- 作者在评论中建议不要使用 Windows 7 或旧版 Windows 10 为手机刷入 Windows 11，称这些系统无法识别大容量模式，并指向 Mindows 官方文档；该文档的具体链接没有提供。
- 有评论者报告成功后触摸和声音可用，但 HUB 和 GPU 驱动仍显示感叹号。这是单个用户的反馈，不代表所有设备的结果。
- 作者称自己测试 LG 的骁龙 855 驱动时，驱动覆盖较全。
- 对小米平板 5 的提问，作者回复称小米平板 5 可用、小米平板 5 Pro 当时因骁龙 870 缺少驱动而不可用。这些是评论中的设备兼容性说法，不是对 LG G8 以外设备的完整兼容性保证。
- 作者表示没有测试电话和短信功能，并称可以切换回 Android 系统。扩展坞外接显示器等问题没有得到答复。
