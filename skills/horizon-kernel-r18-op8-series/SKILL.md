# Horizon R18：一加8系列历史内核资源

R18补档发表于2023-06-05，称修复高温时部分CPU无负载；不代表B1–R17均有补档。下表区分三款设备及氢氧11/11底包类原生，不可混刷。

编译入口：内核仓库分支 `oos11/final`，AnyKernel3分支 `op8/11`；两仓库与Clang目录同级，工具链执行文件为 `clang/bin/clang`，R18测试使用16.x。完整构建脚本见博客，本稿未执行构建。

- [内核源码](https://github.com/libxzr/android_kernel_oneplus_sm8250)
- [AnyKernel3](https://github.com/libxzr/AnyKernel3)
