# OPPO Reno7 开源内核、UEFI 移植排障与 Kali 6.1 主线 Linux 进度

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- #### [酷安原帖](https://www.coolapk.com/feed/74610583)（imgs=0）
  - **机型与原厂底层突破**：OPPO Reno7，借助 AI 辅助使原厂开源内核源码顺利过编，成功启用原厂内核 USB Gadget 并提取设备树 (Device Tree)。
  - **UEFI 移植与 WinPE 尝试**：成功移植第三方 UEFI 固件并引导启动 Windows PE 系统。排障定位发现：加载自定义 I2C 驱动会导致黑屏崩溃，根因定位为底层 `gpi_dma` 通道报错崩溃；GPU 驱动因高通硬件限制需修改硬件或应用特定补丁方可驱动。
  - **主线 Linux (Kali 6.1) 引导与外设修复进度**：
    - 成功通过主线内核输出屏显日志，借助开源修补修复 Gadget 与 UFS 存储识别，进入标准主线 Linux。
    - 外设修复矩阵：触摸屏、Wi-Fi、蓝牙、电池充电管理、ADSP 音频子系统就绪。
    - 屏幕面板调优代价：针对型号为 `s6efc3` 的 OLED 面板，目前硬核点亮依赖牺牲显示传输带宽（带宽暂未完全修复）；整机仅剩音频驱动尚未完成。
    - 提供 Reno7 永久刷入 GSI 的 Recovery 机制。
