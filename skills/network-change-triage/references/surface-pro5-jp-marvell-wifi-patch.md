# 日版 Surface Pro 5 Marvell 无线网卡 5GHz 149-165 信道驱动补丁

> 整理自酷安公开动态正文；图片、评论及外链未逐一核验，实际操作请以对应硬件版本与上游仓库为准。

- #### [酷安原帖](https://www.coolapk.com/feed/74703091)（imgs=0）
  - **故障背景**：日版微软 Surface Pro 5 硬件锁死日本国家码，屏蔽了 5GHz Wi-Fi 下的 149-165 信道；国内部分手机热点仅支持 149 信道，导致日版设备无法扫描连接热点。
  - **驱动补丁与破解原理**：通过二进制修改 Marvell 无线网卡驱动中的 19 个字节，阻止驱动读取主板 UEFI 中锁死的区域国家码，强制重定向至 CN / US 国家码，恢复扫描并握手 149-165 频段信道。实测修复后网卡协商速率最高达到 887Mbps。
  - **部署要求与执行流程**：
    - 由于修改后驱动失去微软数字签名，Windows 必须运行在“测试模式”（Test Mode）下，桌面右下角会出现测试模式水印。
    - 安装步骤：解压补丁包 -> 以管理员权限打开 PowerShell -> 执行 `.\09-Install-Patch.ps1` -> 阶段一完成后手动重启进入测试模式 -> 再次运行脚本完成阶段二，脚本将自动验证信道解锁状态。
