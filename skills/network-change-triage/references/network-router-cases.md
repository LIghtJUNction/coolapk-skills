# 路由器与组网案例

## E2633 固件分享与报告

原帖：[E2633 刷机固件](https://www.coolapk.com/feed/69083165)。

- 固件分享：[蓝奏云链接](https://wwbqj.lanzout.com/b00csrctte)，原帖公开提取码：`af71`。这是分享提取信息，不是账户登录密码。
- 刷机教程：[视频入口](https://b23.tv/9g8Y1Jq)。
- 原帖报告：出现一批 E2633 1.1.0 版本，魔改包刷不了；无线中继功能缺失；可能出现路由器拨号后断网并重启。这些是原帖报告，不代表已独立复测。
- 原帖作者个人意见：E1630 完全没有必要刷；E2633 若没有锁机也没必要刷，因为功能比运营商固件多不了多少。此处保留为作者意见，不作设备结论。

## 中兴光猫与零售路由组网

原帖：[组网调整说明](https://www.coolapk.com/feed/72723958)。作者称先前的一键组网教程仍可用，但因副路由状态下无法绑定中兴 App，且中继模式下上级 IP 改变后需登录光猫查路由 IP，管理不便。原帖给出两种调整：

1. 组网成功后直接关闭 Mesh。
2. 先关闭 Mesh，改为中继，再手动设置 Wi‑Fi。

这是原帖所述环境下的经验，不是通用设置建议。
