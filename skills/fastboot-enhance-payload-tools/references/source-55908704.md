# 通过服务提取 payload 分区镜像

[原帖](https://www.coolapk.com/feed/55908704)介绍 Payload Dumper Web 和 Bot：从指向含 `payload.bin` 的 ROM 的链接提取指定分区，例如 `boot` 或 `init_boot`，用于修补或恢复原厂镜像。作者称该服务需要服务器中转，当时不支持 `system` 等大分区。

正文未给服务网址或 Bot 地址，也没有兼容 ROM 格式、文件大小上限或安全性验证；两张图片及完整评论未读。不能从工具名称推断下载链接或把服务限制推广到其他本地 payload 工具。修补或还原时应核对镜像与设备、系统构建对应。
