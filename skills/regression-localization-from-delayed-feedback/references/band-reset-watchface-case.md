# 手环更新后的抬腕亮屏异常记录

原帖未说明手环型号或固件版本，以下仅记录作者描述的先后顺序，不据此推定根因。

1. **更新前：**未开启抬腕亮屏，只保留一个表盘，其余表盘已删除。
2. **更新后首次开机：**闹钟消失；抬腕亮屏自动开启，尽管设置中显示关闭。作者在设置里重新开关后，抬腕亮屏可正常关闭。当时未发现灵敏度异常。
3. **使用数日：**未见明显问题。
4. **随后发生软重置：**闹钟再次消失，抬腕亮屏再次自动开启。作者称心率记录因此缺失一段。
5. **恢复出厂设置后：**抬腕亮屏无论如何开关都彻底无法打开。表盘仍只有原先设置的那一个，并非官方默认表盘。
6. **增加官方默认表盘后：**抬腕亮屏恢复，但作者感觉灵敏度较低。

作者猜测可能有指针跑丢并改动数据，但这只是猜测，帖子没有证据确认原因。文中也没有给出可复现的修复步骤、固件信息或型号。

来源：[酷安原帖](https://www.coolapk.com/feed/26554618)。

这个案例可复用的是状态变化记录：固件更新、软重置、出厂重置和表盘变更是不同触发条件，设置页状态与实际行为也要分别记录。加入默认表盘后恢复只是相关现象，不证明它适用于其他型号。
