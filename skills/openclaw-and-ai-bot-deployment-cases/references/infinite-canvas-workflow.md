# Infinite-Canvas：AI 创作节点工作流与远程访问

## 功能结构
Infinite-Canvas 将提示词、图片素材、生成结果和创作节点组织在无限画布中，支持拖拽、缩放及节点连接。原帖列出本地功能、在线生图、AI 对话、无限画布和素材库：本地文生图、图片编辑、角度控制等可通过本机 ComfyUI 执行；部分页面还提供 ModelScope 云端模式，配置 API Key 后可切换。在线生图可配置 ModelScope、RunningHub 或其他 OpenAI 兼容服务的接口地址、API Key 和模型。AI 对话可用于构思、优化提示词和图像分析建议。素材库用于管理上传的图片、工作流、提示词及画布生成资产。

## Windows 部署
原帖说明从 GitHub 仓库使用 Code → Download ZIP 下载源码，解压后依次双击 `安装依赖.bat` 与 `run.bat`。依赖安装等待数分钟，终端出现 `Done` 后按任意键退出，再运行 `run.bat`。本地页面示例为 `http://127.0.0.1:3000/`；原文为 `http:/删/127.0.0.1:3000/`，按原文说明去除“删”字后恢复。

原帖称若无法访问 GitHub，可从 123 云盘下载当前仓库源码压缩包，免登录下载，提取码 `1314`。正文没有提供云盘永久链接 URL，因此不能恢复下载地址。

## 配置在线 API
原帖示例以 Agnes AI 为 OpenAI 兼容服务，在 API 设置中新增平台，填写平台名、API Key 和请求地址 `https://api.agnes-ai.cn/v1`。原文 URL 为 `https:/删/api.agnes-ai.删cn/v1`，依照原文明示删除“删”字恢复。随后验证地址、拉取模型、勾选并应用模型列表，保存后在 AI 对话页面选择该渠道模型测试。原帖称该示例服务有 RPM（每分钟请求数）限制；免费额度及可用性属于发帖时描述。

## 无限画布节点
新建画布并进入后，可通过右键添加提示词节点，填写内容后从节点边缘拖出连接线，连接到 API 生成节点并执行。也可添加参考图节点、循环/并发节点以生成多个候选结果。生成图片可单独拖出、放大、裁剪、扩图、修改或进行宫格切分；原帖举例九宫格切分后可下载。

## cpolar 远程访问
安装 cpolar 后，原帖用命令确认版本：

```cmd
cpolar version
```

本机 Web UI 示例地址为 `http://127.0.0.1:9200`（原文插入“删”字，按说明删除后恢复）。在隧道管理中编辑 website 隧道或新建隧道，协议选 HTTP，本地地址端口设为 `3000`。原帖称默认 website 隧道指向 8080，需调整为项目端口。在线隧道列表会显示 HTTP 与 HTTPS 公网地址；随机域名适合临时访问，可能变化。

固定地址流程：在 cpolar 后台预留二级子域名，地区与隧道保持一致；编辑隧道，将域名类型设为二级子域名并填写预留值，协议仍为 HTTP、本地端口为 `3000`。原帖示例地区为 China VIP、子域名例子为 `infinite`，实际名称须以账号成功预留的值为准。

可在隧道高级设置中配置 HTTP Auth，格式为“用户名:密码”，为公网入口加一层浏览器认证。原帖明确此为 cpolar 隧道认证，并非 Infinite-Canvas 自身用户系统；建议使用独立强密码并优先使用 HTTPS 公网入口。
