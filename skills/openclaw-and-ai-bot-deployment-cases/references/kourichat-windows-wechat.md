# KouriChat 部署参考

## 环境和版本
原帖演示环境为 VMware 中的 Windows 10 22H2，建议 Windows 10、4 GB RAM、不要求显卡，Python 3.11。示例压缩包版本为 `KouriChat-<服务器IP>.zip`，文章发布时称为最新版；此版本结论仅对应原帖时间。云盘含工具、系统资源和完整录屏，提取码 `1314`，但原帖没有给出分享 URL。

安装 `python-3.11.8-amd64.exe` 时勾选 `Add python.exe to PATH`。命令提示符验证：

```bat
python --version
```

解压项目后运行 `run.bat`。原帖描述脚本会检查 Python、创建虚拟环境、使用阿里源安装依赖并启动网页；默认示例访问地址为 `http://localhost:8502`。

## 微信与模型配置
原帖指出当时项目未完全适配微信 4.1，旧版微信 3.9 又被强制升级，导致常规登录方式无法正常使用；作者称网盘资源中有另一种登录方式，但未给出下载链接或技术细节，因此无法整理该方式。文章明确称其交互方式是通过对话框输入消息，而非注入或修改微信程序，并提示存在账号风控风险。

在 KouriChat 配置中心添加要监听的微信昵称（昵称，不是备注或微信号），API 注册地址选择 DeepSeek API，模型选择 `deepseek-chat`，填写 API Key。意图识别 API 使用：

```text
API 地址：https://api.deepseek.com/v1
模型：deepseek-chat
```

消息队列等待时间示例设为 `0`，保存后通过“微信掉线重连”再启动。原帖报告启动后程序会操作当前登录的微信，按配置监听昵称并调用模型解析意图、生成回复；这是文章演示报告，未独立验证。

## cpolar 远程访问
Windows 安装 cpolar 后，命令提示符检查版本：

```bat
cpolar version
```

本机管理界面示例：`http://localhost:9200`。在隧道列表编辑 `website` 隧道，将服务端口配置为 KouriChat WebUI 的 8502，示例隧道名 `kourichat-8502`。随机域名约 24 小时变化；固定二级子域名需先预留，再修改隧道域名类型。该远程访问章节没有提供实际生成的公网 URL。
