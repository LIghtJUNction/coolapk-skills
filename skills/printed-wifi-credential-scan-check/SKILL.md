# 打印 WiFi 凭据扫描核查

用于记录某设备或应用是否能从打印内容中识别 WiFi 凭据并发起连接。源帖提到“AI拍一拍”新增独立的 WiFi 连接入口，也提到此前可通过扫一扫连接；没有给出机型或系统条件，因此核查时应先记录实际测试环境，不推定兼容范围。

## 建议验证：区分两类识别

1. **二维码识别**：准备含 WiFi 配置的二维码，观察扫描器是否识别网络名称和凭据，并确认连接是否成功。记录二维码来源、扫描入口和结果。
2. **普通文字识别**：将 WiFi 名称和密码以清晰文字打印，不附二维码。观察功能是否分别识别名称与密码，以及是否能据此发起连接。记录字体、字号、排版、大小写、特殊字符和识别结果。

这两种测试不能互相替代。二维码测试通过不代表普通文字识别有效；文字识别失败也不说明二维码路径不可用。

原帖附图尚未读取；上述流程是建议验证方法，不是原帖已完成的测试。

## 记录与复核

记录设备型号、系统版本、应用或功能入口、打印样张形式、识别字段、连接结果及失败提示。测试时避免公开真实网络密码；使用专门的测试网络和凭据。分别重复测试，并记录网络可用性、凭据正确性等条件。
