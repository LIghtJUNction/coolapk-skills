# `rust-kit` / `rust-hook` 与高通平台第三方 ROM 基带处理笔记

整理自酷安社区开发者动态（未读配图与外部源码）。

## 1. `rust-hook` 与 `rust-kit`（HyperOS 4 纯 Rust 应用内存侧定位）

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74870312)（`imgs=0`）
- **定位**：针对 HyperOS 4 桌面、天气等纯 Rust 应用，提供类似 `dexkit` 的直接内存侧组件定位与修改能力（不改关键字符串即可跨应用版本生效），Demo 已内置于 `MitsuhaHyperOS`。

## 2. 高通开高通第三方 ROM 基带兼容性判断

- **来源**：[酷安原帖](https://www.coolapk.com/feed/74842466)（`imgs=1`）
- **经验总结**：作者指出同为高通平台间移植第三方 ROM 时，只要正确处理 `jar` 等必要组件，基带在硬件层通常表现为“全通或全不通”，一般不会因改包本身导致个别用户偶发炸基带或插卡重启（排查应以日志为准）。
