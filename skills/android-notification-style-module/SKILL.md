# 通知样式模块：作用范围与版本记录

原帖介绍的模块将通知背景改为纯白色并允许调节透明度，文字使用黑色或灰色，目标是通知横幅、通知中心及原帖提到的锁屏通知样式；作者称它只改通知，不影响其他界面的模糊效果。资料未给出模块名称、激活流程或完整安装步骤。

作者评论说明，曾尝试通过系统方式模拟低端机来减弱玻璃效果，但会连带削弱动画，因此改为单独控制通知样式的模块。该评论还表示方案需要修改系统界面，不能免 Root 使用。评论指出 Android 15 对应的 C15 系统没有该帖所讨论的玻璃设计；适配到其他版本或设备的情况未能确认。另有用户评论称新系统可能删除相关底层代码，也有用户称新版模块已适配；这两项用户反馈未验证，不能据此确定支持范围。

版本记录：

- 1.0.1（来源：[原帖](https://www.coolapk.com/feed/74117446)）：修复常驻通知刷新闪烁、焦点卡片背景被改变的问题；增加少量透明度。
- 1.0.2（来源：[更新帖](https://www.coolapk.com/feed/74132302)）：新增透明度滑块；修复常驻通知刷新闪烁、媒体播放器和手电筒等焦点卡片背景被改变、全屏状态下通知失效的问题。作者称若无 Bug 将不再更新。
