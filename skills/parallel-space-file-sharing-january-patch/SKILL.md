# 平行空间文件分享与一月补丁说明

## 在平行空间内分享文件

不同空间的文件不会直接互通，但可以借助对应空间自动创建的“文件”应用间接分享。该应用能够查看各空间的存储内容。

操作步骤：

1. 在目标空间打开该空间的“文件”应用。
2. 选择要分享的文件并点击分享。
3. 在分享目标中选择该空间内的应用，例如微信。

从哪个空间的“文件”应用发起分享，文件就会交给哪个空间中的应用。
