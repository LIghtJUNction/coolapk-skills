# NewFileTime 8.31：NTFS 文件时间批量调整

## 版本与平台
原帖记录 NewFileTime v8.31，发布日期 2026-10-11，压缩包约 153 KB。支持 Windows 11、10、8.1、7，以及 Windows Server 2012 至 2025；x86、x64 分开打包。原帖称免安装、双击运行、不写注册表、不装服务；支持 42 种语言，含简体中文。许可描述为个人与办公用途免费，允许不限量转发未修改副本但禁止售卖，均按原帖记录。

## 可修改的时间与批量操作
原帖称工具修改文件系统记录的创建时间、最后修改时间、最后访问时间，三个选项可独立启用。可批量拖入文件，设定后统一应用。时间设定方式包括：输入精确时间、按天数增减、按比例变新或变旧。

导入目录时可选择是否包含子文件夹，以及只处理文件或同时处理文件夹。工具还能从文件名解析日期串（例如 `20230815`）作为时间戳；可将文件清单及时间导出到 Excel，修改后再批量导回。

帖子提到的用途包括修正设备时区错误导致的文件时间偏移、整理从旧盘或压缩包恢复后时间被重置的素材、统一多设备素材时间、按文件名日期归档，以及构造测试时间戳验证增量备份、同步和文件监控逻辑。内置时区与夏令时校正用于处理时差偏移。

## 重要边界
- 文件系统时间戳与照片 EXIF 拍摄日期不同；修改前者不会改变相册读取的 EXIF 日期。
- 本地文件时间戳不会改变公司考勤系统的服务端打卡记录。
- 原帖称修改后不能撤销，重要文件应先用导出功能保存原值。
- 被其他程序占用的文件可能无法修改，需先关闭占用程序。
- 只支持 Windows。
- 原帖称标准版、Unicode 版、x64 版位于分享页，并报告其 SHA256 与官方下载一致；输入未给出哈希值、文件或校验过程，不能视作本文已验证。
