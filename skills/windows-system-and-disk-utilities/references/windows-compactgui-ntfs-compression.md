# CompactGUI 与 Windows NTFS 透明压缩

## 原理与功能
CompactGUI 调用 Windows 自带的 Compact，对 NTFS 文件进行文件系统级透明压缩。系统在应用读取时自动解压，因此游戏和软件通常不需要先手动解压；这与 ZIP、7Z、RAR 压缩包的使用方式不同。原帖列出的算法包括 XPRESS 4K、XPRESS 8K、XPRESS 16K 与 LZX，可在压缩率和 CPU 开销之间选择。

工具可预估压缩收益、显示压缩统计、集成文件夹右键操作，并支持还原。游戏或软件更新后，新增或改动文件可能需要重新压缩；原帖建议更新后再次执行压缩。

## 适用条件与权衡
- 视频、图片、音频及已压缩压缩包通常难以进一步节省空间。
- HDD 读取受磁盘 I/O 限制时，减少读取量可能抵消部分 CPU 解压开销；这是原帖给出的经验判断，不是特定硬件上的基准结果。
- SSD 上应权衡较快的磁盘读取与额外 CPU 开销。
- 原帖不建议压缩系统盘，理由是系统盘读写频繁，可能影响稳定性；数据盘、游戏盘和工具盘可按需评估。
- 建议先选约 10 GB 的游戏目录试用，先看预估再决定是否压缩；可逆操作仍会耗时。
