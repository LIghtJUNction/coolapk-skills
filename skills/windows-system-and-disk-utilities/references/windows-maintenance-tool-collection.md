# Windows 内部工具合集的功能范围

## 原帖描述的工具类别
原帖称该合集包含 196 款官方工具，覆盖：

- 系统清理与优化：垃圾文件清理、注册表修复、启动项和服务管理。
- DLL 与系统修复：缺失 DLL、系统组件及 DirectX 修复。
- 网络诊断：连通性测试、DNS 刷新、端口扫描、已保存 Wi-Fi 密码查看。
- 硬件检测：CPU 温度、硬盘健康、内存测试和显卡信息。
- 隐私处理：文件擦除、浏览痕迹清理和隐私数据擦除。

原帖将各工具描述为独立小程序、无需安装且不常驻后台，并称合集相当于为 Windows 内置工具和命令行能力提供集中索引。建议将其放在 U 盘备用。原帖所称“覆盖 90% 以上日常维护需求”是作者评价，未提供统计依据。
