# MangoDisk 磁盘清理与空间分析

## 原帖介绍的功能
MangoDisk（芒果磁盘清理）被原帖描述为支持 macOS 和 Windows 的免费开源工具，采用 GPLv3，无需登录，扫描和结果在本机处理；原帖称扫描不会自动删除文件，由用户确认后执行。

主要功能包括：

1. 扫描系统、应用、浏览器及开发环境缓存、临时文件和卸载残留；原帖列举 Node.js、Rust、Gradle、Xcode、Python、.NET 构建产物，以及本地 AI 模型和缓存。
2. 扫描整盘或指定目录，按类型和大小筛选大文件。
3. 按文件内容识别重复文件，而非仅按文件名判断；原帖称智能选择会让每组至少保留一份。
4. 卸载应用时查找缓存、配置和遗留数据。
5. 以 treemap（矩形树图）展示空间占用，可逐层进入目录定位大文件。

## 原帖建议的清理顺序
先用空间分析定位大户，再检查大文件和重复文件，最后处理卸载残留。确认每组重复文件留下所需副本；清理系统或应用缓存前，注意相关程序是否仍在运行。原帖分享者称习惯月底扫描，但这只是个人习惯，不是必要频率。
