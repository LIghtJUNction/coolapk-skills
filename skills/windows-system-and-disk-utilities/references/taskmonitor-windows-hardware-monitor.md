# TaskMonitor 任务栏硬件监控

## 监控与交互
原帖介绍 TaskMonitor 为 Windows 任务栏常驻监控工具，可显示 CPU、内存、磁盘、GPU、网络五类负载。点击任务栏图标可查看进程资源占用排行，以占用率排序。

原帖称多硬盘和多显卡可分别统计，例如分别查看 NVMe 系统盘与 SATA 数据盘的读写速度和占用率，以及独显、核显负载；没有提供具体指标定义或准确率测试。

## 代理流量接口
原帖称可读取“火箭”／Mihomo 的流量接口，在任务栏显示代理后的真实网速，以区别于网卡层面的流量数据。文章未提供接口名称、配置方法或支持版本，不能据此还原接入步骤。

## 适用环境与限制
- 原帖标明支持 Windows 10 和 Windows 11。
- 不支持其他系统；界面偏功能导向，没有皮肤系统或主题切换。
- 作者称后台 CPU 与内存占用很低，并报告使用一个月后减少了打开任务管理器的次数；未给出测量数据或独立测试。
