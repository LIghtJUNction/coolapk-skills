# 图吧工具箱 WinUI 3 重置版

## 版本与实现
原帖称重置版名为“图吧工具箱 WinUi3”，使用 WinUI 3 与 .NET 10 重写；原帖未给具体发行版本号。文章将其与旧版区分，称重置版提供亮暗主题、全局搜索、收藏和自动更新。文中称内置 80 多款常用工具。

## 内置工具和功能
- 硬件信息：CPU-Z、GPU-Z、HWiNFO、AIDA64。
- 压力与性能测试：FurMark、CrystalDiskMark。
- 磁盘：DiskGenius，原帖列举分区管理和数据恢复。
- 原生功能：系统优化和临时文件清理、电池报告、已连接 Wi-Fi 密码查看、屏幕坏点和漏光测试、CPU/GPU 天梯图。

原帖称程序免费、开源、便携，无需安装，可放入 U 盘使用；这些属性没有独立核验。单个内置工具的许可和更新方式未说明。

## 原帖建议的验机流程
1. 硬件检测核对配置。
2. 烤机观察稳定性。
3. 查看电池报告评估笔记本电池健康。
4. 屏幕测试可在暗环境用纯黑、纯白画面检查坏点和漏光。

原帖还建议装系统前先用 DiskGenius 整理分区，并将常用工具加入收藏。分区操作具有数据风险，文章没有给出备份或具体操作步骤。
