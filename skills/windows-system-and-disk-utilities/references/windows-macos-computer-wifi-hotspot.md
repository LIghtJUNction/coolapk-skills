# Windows 与 macOS 电脑开 Wi‑Fi 热点

## 工作原理
无线网卡既可接收也可发射。Windows 的软 AP（早期称“承载网络”）在 Windows 10 1803 之后改为基于 Wi‑Fi Direct 的实现：系统创建虚拟 AP 接口，并通过 NAT 将接入设备的流量转换为宿主电脑流量后转发。

同一块无线网卡同时接收 Wi‑Fi 上网并发射热点时需要分时复用，性能可能明显下降。原帖报告的实用建议是优先用以太网作为上游；该建议没有附网卡型号、驱动或测速数据。

## 系统自带热点

- **Windows**：设置 → 网络和 Internet → 移动热点 → 选择共享来源（以太网、Wi‑Fi 或蜂窝）→ 设置名称和密码 → 开启。
- **macOS**：系统设置 → 通用 → 共享 → 互联网共享，将以太网共享给 Wi‑Fi。

原帖称系统功能支持 WPA2/WPA3，并列出四项限制：最多 8 台设备同时连接；电脑睡眠会中断热点；看不到每台设备的流量；需要网页认证的酒店或校园网络无法由系统自带功能处理。8 台等数值来自原帖所述官方资料和公开实测，实际情况可能受网卡型号、驱动版本影响，不应视为所有设备的保证。

## 第三方方案与常驻部署
原帖报告 Connectify 免费版每 60 分钟断开一次，可手动重启；长期使用需 PRO，原帖记载当时终身授权原价约 35 美元，价格以官网为准。其网页认证网络支持说法来自厂商自己的对比表，属于厂商自述。

原帖称 Virtual Router Plus 依赖的旧“承载网络”接口已被主流网卡厂商的新驱动放弃：老笔记本可能仍能用，新机器可能报无法启动。mHotspot 官方标注支持到 Windows 10；Windows 11 兼容性未确认。

若需长期为固定位置供网，可用 Raspberry Pi 刷 OpenWrt，或使用二手小主机作为常开软路由，避免依赖办公电脑保持唤醒。此处是原帖方案建议，未提供具体设备配置或测试结果。

## 使用注意
热点密码建议至少使用 WPA2。原帖建议公共场合优先考虑 5GHz，以缩小覆盖范围；覆盖效果仍取决于环境和设备。笔记本开热点较耗电，建议接入电源。
