# 删除文件恢复的原理与操作边界

## 删除后数据为何可能仍在
以 NTFS 为例，文件系统的 MFT（主文件表）记录文件名、大小和位置等元数据。删除文件时，系统会将对应记录标为已删除，并把其数据区域标记为可分配；这不等于立即擦除数据块。只要数据块未被新内容覆盖，恢复工具可能仍能找回部分或全部内容。

SSD 的具体结果还可能受系统和存储设备处理机制影响；原帖没有讨论 TRIM 等条件，因此不能把上述说明理解为所有设备都可恢复。

## 扫描方式
- **快速扫描**：读取文件系统元数据（例如 NTFS MFT），寻找已删除记录仍可识别且数据尚未覆盖的文件。适合近期删除或清空回收站；依赖文件系统结构尚可读取。
- **深度扫描**：逐扇区读取，通过文件头特征（magic number）识别类型和边界并尝试重组。适用于格式化、文件系统损坏、分区丢失或删除较久的情况，速度取决于磁盘容量；重组不保证文件完整。
- 可先快速扫描，未找到目标再尝试深度扫描。

## 操作步骤与防覆盖
1. 选择误删文件所在分区或外接存储设备；原帖列举 HDD、SSD、U 盘、SD／MicroSD 卡和移动硬盘。
2. 先做快速扫描，未找到时再做深度扫描。
3. 按类型筛选并预览，确认目标文件内容。
4. 将恢复结果保存到另一块磁盘或分区，切勿写回源盘。

发现误删后，尽量停止对目标磁盘的写入：不要保存新文件、安装软件或继续进行会大量写盘的操作。若目标是系统盘，原帖建议关机后拆下硬盘并连接另一台电脑处理。重要业务数据或不可替代资料可咨询专业恢复机构。

## 恢复限制与备份
新数据覆盖原数据后，常规恢复工具无法从被覆盖区域还原原内容。快速格式化通常主要清除索引，原帖称未大量写入时仍可能恢复；完整格式化会增加难度。手机本地照片恢复受系统加密等机制影响；启用云同步时，可检查云端回收或同步副本。恢复文件打不开可能是数据被覆盖或文件头损坏，可尝试深度扫描或文件修复，但不能保证成功。

原帖称工具以只读方式扫描源盘、写入只发生在指定恢复位置；这属于对工具行为的概括，未对应具体软件，不能当作所有恢复工具的保证。RAID 等企业级存储应使用专业方案。定期备份比事后恢复可靠。
