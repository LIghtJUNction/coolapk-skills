# LightC 2.16.16：Windows 清理与维护模块

## 版本与分发许可
原帖记录版本 v2.16.16，发布日期 2026-10-13；技术栈为 Tauri 2、Rust、React 19、TypeScript。安装包 5.68 MB、便携版 7.48 MB，另有 212 MB WebView2 离线包。支持 Windows 10 及以上、四种界面语言。上述版本和体积为原帖数据。

许可为 LightC Source Available License v1.0。原帖说明源码可见，但不属于 OSI 开源许可，并禁止商用及分发编译产物；只有作者发布的版本属于官方分发。因此第三方所谓“绿色版”不属于原帖所述的官方分发。

## 功能模块
帖子将 12 个模块按操作风险概括如下：
- 清理类：临时文件、传递优化文件、缩略图、DirectX 着色器缓存和 Defender 可重建缓存；支持快速、深度扫描。大文件扫描按盘查找并标示风险。微信、QQ、钉钉、飞书、企业微信缓存分类列出、确认后清理，帖子称不删除聊天记录。
- 分析与残留：大目录逐级分析；比较两次磁盘快照；按置信度识别卸载残留；清理失效右键菜单项。
- 驱动与系统：清理未使用的第三方驱动包，保护正在使用的驱动并支持备份恢复；注册表冗余清理带备份；系统瘦身涉及可选组件、休眠文件、WinSxS 冗余，并可在 Windows.db 异常膨胀时重建搜索索引。
- 外壳图标：管理“此电脑”中的第三方图标，带注册表与 ACL 备份及防复活处理。
- AI 模型空间：扫描 Ollama、LM Studio、ComfyUI 的模型、LoRA、Embedding 和缓存，并定位目录与体积。

原帖称部分操作需要管理员权限，个别文件需重启后生效；这类任务会标记为未完成。其安全范围说明称 Defender 仅处理 LocalCopy、Support 两个可重建目录，不碰根目录、隔离区或病毒库；System32 仅涉及 DirectX 着色器缓存路径。注册表、驱动及外壳图标操作前先备份。具体实现未由输入中的代码或独立测试验证。

## 配置与操作限制
便携模式需在程序旁手动放置 `LightC.portable.json`，原帖称没有一键开关。系统瘦身、注册表模块说明较技术化；操作前应理解所选项的影响。原帖未给出 JSON 配置内容或具体命令。
