# 7-Zip 26.06：格式、加密与版本要点

## 版本与格式
帖文报告 7-Zip 26.06 于 2026-11-06 发布，官网为 [7-zip.org](https://www.7-zip.org/)，源码镜像为 [ip7z/7zip](https://github.com/ip7z/7zip)。帖文称 2026 年从 26.00 连续更新到 26.06，多个版本修复漏洞。

按帖文所列，7z、ZIP、TAR、GZIP 可压缩和解压；RAR、ISO、DMG、CAB 可解压但不能压缩。RAR 仅解压与 unRAR 许可限制有关；需要创建 `.rar` 时帖文建议使用 WinRAR。帖文称界面支持 87 种语言。Windows 图形版之外，帖文称 Linux 和 macOS 官方仅提供命令行包。

## 加密与文件名
- ZIP 可选择 ZipCrypto 或 AES-256；ZipCrypto 兼容性较好但强度较弱，创建加密 ZIP 时需确认选中了 AES-256。
- 7z 格式固定使用 AES-256。若还要隐藏压缩包内的文件名和目录，应选择 7z 并启用“加密文件名”。仅给 ZIP 加密码仍可能暴露内部文件清单。

## 安全与许可
帖文称旧版本解开嵌套压缩包时可能丢失 Windows 来源标记（Mark of the Web），使系统的来源警告不再出现；该问题于 24.09 修复。帖文指出相关问题进入已知被利用漏洞名录，但没有提供公告链接或具体编号。

许可方面，帖文称 `7z.dll` 大部分采用 GNU LGPL v2.1+，另含 BSD 3-Clause、BSD 2-Clause；RAR 解压部分带有禁止用于重建 RAR 压缩算法的 unRAR 限制。随包三个 TXT 文件包含许可原文及源码获取方式。帖文建议用包内 `SHA256SUMS.txt` 核对摘要；摘要匹配只能说明文件与该摘要一致，不能单独证明软件安全。

帖文对压缩率的限定是：官网称压 ZIP/GZIP 时比 PKZip/WinZip 好 2–10%。帖文没有提供 7z 与 ZIP 的受控对比数据，因此不支持“7z 一定小一半”之类结论。
