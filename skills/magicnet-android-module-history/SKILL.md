# MagicNet：模块版本记录、安装说明与验证边界

MagicNet 是面向 KernelSU、APatch、Magisk 生态的模块项目。本文整理公开动态中能确认的版本差异与作者描述，并把未经独立验证的内容明确标为报告或待测。项目入口：[LIghtJUNction/MagicNet](https://github.com/LIghtJUNction/MagicNet)。

## 版本记录

### v1.4

作者称 v1.4 优化了安装和使用流程，安装脚本会打开网页供用户在安装时配置，之后重启以启用开机自启；前端也进行了调整。该版本还声称增加 eBPF 入站支持，并改善 Tailscale 支持。

这段材料没有给出安装包下载链接、具体配置项、eBPF 所需内核条件或兼容性矩阵。作者明确表示 Tailscale 支持仍缺少测试。因此这些内容是版本说明，不应视作已验证的兼容性保证。

### v1.2

来源仅能确认作者发布了 v1.2，没有提供变更内容或操作步骤。不要从其他版本说明推断 v1.2 的功能。

### v1.0.36

作者描述该版本支持 sing-box 与米哈游内核，并称规则和规则组有更新。作者报告优先使用 sing-box，失败时回退到米哈游内核，并自述内存占用约为后者的十分之一；该数值没有测量方法或复验数据，不能当作性能基准。

原帖提到可在模块根目录放置一个名称形如 `.disable_????_box` 的文件来停用 sing-box，但文件名中间字符被原帖省略。由于缺失字符无法从材料恢复，不要猜测或照此创建文件。

## 反馈与隐私

v1.4 动态称模块 Web UI 可以创建 issue，并会自动脱敏收集相关信息。这是作者对功能的描述，不构成已独立验证的隐私保证。提交前仍应检查将要公开的内容，移除令牌、私钥、个人信息和其他敏感数据。
