# 六款移动固态硬盘的功能与测试记录

原帖比较闪迪 E81、致态灵·潮流版、三星 T9、WD_BLACK P40、宏碁掠夺者 GP30、雷克沙 SL500。作者称六款均为顺序读写约 2000 MB/s 级产品，但详细软件、热测试和使用体验有差异。

## 外形、重量与连接配件

- **闪迪 E81**：偏户外设计，正文称具备防护能力；塑料/亲肤材质外壳配金属中框，六款中尺寸最大之一；附 A 口与 C 口数据线。
- **致态灵·潮流版**：圆润外壳、背部磁吸模组，实测重量不到 52 g；附 C 口线及 C 转 A 转接器。
- **三星 T9**：硅胶缓震外层，实测 122 g，原帖称是六款中最厚；附 A、C 两根线。
- **WD_BLACK P40**：金属机身与 RGB 元素，长度较长；附 A、C 两根线。
- **宏碁掠夺者 GP30**：金属机身，实测 64 g；附一根二合一数据线。
- **雷克沙 SL500**：卡片式金属外观，实测 42.7 g；仅附 C 口线，旧设备需另备 A 口线。作者报告其放置时有跷跷板感。

原帖未给出各型号容量版本，重量为作者样品实测。

## 配套软件功能（原帖使用体验）

| 产品 | 原帖描述的软件功能与限制 |
|---|---|
| 闪迪 E81 | SANDISK Memory Zone 可备份、加密；自动备份目录只能选系统根目录下一级文件夹，不能单独选子文件夹。作者遇到插入设备后界面空白；手机端识别体验不佳。 |
| 致态灵·潮流版 | 致态天枢大师 PC 管理工具支持自动备份、固件更新、健康状态、设备优化和安全擦除；另有致态加密软件，原帖称 AES 256 位硬件加密；移动端致态备份管家可备份相册、通讯录、音频、文档，称支持 Android 11 及以上及部分 HarmonyOS 4.0 机型。 |
| 三星 T9 | Samsung Magician 可进行加密、健康监控、分区和固件更新；原帖称支持 AES-256 硬件加密与安全擦除，但无自动备份功能。 |
| WD_BLACK P40 | 原帖称使用 SANDISK Memory Zone，功能与 E81 相同，未报告专属游戏备份功能。 |
| 宏碁掠夺者 GP30 | Biwin Intelligence 提供性能测试、数据迁移、故障扫描、安全擦除和硬盘克隆；作者称可识别其他品牌 SSD/PSSD，但缺备份与加密。 |
| 雷克沙 SL500 | 原帖称无 PC 端软件，移动端 Lexar App 提供备份；需手动选择备份盘和文件夹，不能加密。作者称该 App 也能备份其他品牌 PSSD。 |

加密功能为厂商软件/产品功能的原帖描述，不代表独立安全审计；硬件加密、加密软件与备份也不能互相替代。

## 性能与温度测试

作者使用 CrystalDiskMark、PCMark 10 专业版数据盘基准，并在 iPhone 上录制 4K ProRes 10 分钟后测表面温度；另测写入满载内部温度。测试版本、连接线、容量和环境温度未完整提供。

- 顺序读写：作者称仅致态灵·潮流版与 WD_BLACK P40 的顺序读写均超过 2000 MB/s；其余产品也被归为同一性能等级。4K 单线程随机读取除 SL500 外均超过 30 MB/s；六款随机写入均超过 70 MB/s、接近 80 MB/s。
- PCMark 10 数据盘基准：闪迪 E81 带宽超过 200 MB/s、1550 分；致态灵·潮流版带宽超过 200 MB/s、1315 分；三星 T9 得分略高于 1000。其他型号具体分数未在正文列出。
- iPhone 4K ProRes 写入后的表面温度：WD_BLACK P40 最高约 48°C；原帖称致态灵·潮流版与 SL500 低于 40°C。
- 写入满载内部温度：致态灵·潮流版、宏碁 GP30 约 53°C；闪迪 E81（软件识别为 WD_BLACK SN850XE）57°C；三星 T9 59°C；WD_BLACK P40（软件识别为 WD SN560E）60°C；SL500 79°C。原帖将较高温与持续写入曲线波动联系起来，但没有提供曲线原始数据。

作者称致态灵与 GP30采用直连方案，其他产品采用桥接方案；原帖据此解释直连可能有较低延迟、较低功耗与发热，桥接则多一道接口和 SSD 主控。缺少每个型号拆解证据，作为原帖技术解释记录。

## 选型结论（作者观点）

原帖按使用场景推荐：手机拍摄、移动办公和多端备份优先考虑有磁吸与配套软件的致态灵·潮流版；户外防护需求考虑闪迪 E81；偏好 RGB/电竞设计可看 GP30 或 P40。作者指出不同产品的软件短板各异，且总体日常性能差异不一定明显。以上是个人选购建议，不构成对所有容量版本的性能保证。
