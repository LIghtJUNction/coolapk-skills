# 致态 SSD、PSSD 与存储卡选购和使用记录

## SSD 选购思路

原帖将 PCIe 4.0 描述为主流、PCIe 5.0 为旗舰接口，并提醒确认主板支持对应接口。缓存分为独立 DRAM 与无 DRAM/HMB 方案；作者认为日常用途且不常大量拷贝时，无缓存方案通常够用，举 TiPlus7100 为例。原帖称致态 SSD 使用长江存储 Xtacking 架构闪存。

- **TiPlus7100**：作者推荐用于大型游戏和 PS5 扩容，称其性能均衡；未给出本帖具体跑分。
- **TiPro9000**：定位读写密集型视频剪辑、AI 等生产力场景；作者称测试表现与三星 9100 Pro 相比不落下风，并称全盘写入表现突出，但本帖没有列出具体测试数值与平台。另提到黑神话：悟空联名版。
- **Ti600**：作者定位为日常办公和旧电脑升级的高性价比选择，称性能满足主流 PCIe 4.0 使用；作者报告其 4TB 样品用于 PS5 约一年半，使用稳定。没有提供具体温度、固件或跑分。

## 移动固态硬盘

作者称致态灵体积小于其使用多年的三星 T7，性能约为手中 T7 的两倍，并分别用于 MacBook Pro 扩容和随身携带；未给出型号容量、接口和基准数值。文章还推荐三星 T7，并指出新款 T9 性能提升但机身更厚，此为个人体验评价。

## 存储卡场景

- **致态 PRO 专业高速存储卡**：原帖给出写入速度 80 MB/s，称可用于 4K 拍摄，并提供终身质保。作者报告 256 GB 卡用于 Switch、1 TB 用于 DJI Osmo Pocket、128 GB 用于索尼微单；各设备容量与用途是原帖明确对应。没有给出卡片速度等级或具体型号编号。
- **致态 Endurance 高耐用存储卡**：定位行车记录仪、家用监控等 7×24 小时持续写入场景。作者称在小米监控中持续使用一年，未报告故障；没有给出容量和写入量。

原帖提及早年东芝白卡、三星 EVO 的个人使用经历，但未给出足以确认型号的参数，这些历史体验不作为当前购买性能保证。
