# 铠侠 VD10 1TB PCIe 5.0 SSD：规格与测试记录

## 规格

原帖称铠侠 VD10 1TB（文中也称 EXCERIA PLUS G4）为 M.2 2280、PCIe 5.0 SSD，使用第八代 BiCS FLASH TLC 闪存，厂商保修 5 年。作者说明其测试未安装散热片。文章列出的标称参数为：顺序读取最高 10000MB/s、顺序写入最高 8200MB/s、随机读取 130 万 IOPS、随机写入 140 万 IOPS。格式化后容量报告为 931GB，作者称有预留 OP 空间；文章未提供具体固件版本或 OP 配置。

## 测试平台与结果

测试平台：Intel Core i9-14900K、技嘉 AORUS Pro 冰雕 Z790A、宏碁掠夺者 VESTA II DDR5 7200 32GB 套条、RTX 4080 公版、铠侠 VD10 1TB。正文称以 CrystalDiskMark 进行单盘测试，报告结果：顺序读取 10244MB/s、顺序写入 8390MB/s；随机单线程 4K 读取 106MB/s、写入 414MB/s；随机读取 134 万 IOPS、写入 136 万 IOPS。作者认为随机 IOPS 与标称接近。

Windows 资源管理器复制 20 多 GB 视频文件时，作者报告写入约 3GB/s、读取约 4GB/s，并特别注明受 Windows 文件管理器限制、仅供参考。ATTO 测试在正文中提及，但没有文字结果。

裸盘大量写入时，作者报告整盘最高温度略高于 50°C，热量集中在主控附近；未给出环境温度、传感器来源或持续写入量。PCMark 10 快速系统盘测试得分 5655；与文中未点名的某品牌旗舰 PCIe 4.0 SSD 比较，作者称高 40% 以上。3DMark 存储基准得分 4542，作者称比旗舰 PCIe 4.0 SSD 高约 26%，与旗舰 PCIe 5.0 SSD 相差不到 10%。比较对象、测试版本及完整图表未在文字中给出，不能据此作普遍性能排名。

作者还报告 Lightroom 批量导入 RAW 和导出 JPG 时未感到 SSD 瓶颈，并称当时瓶颈在 CPU；游戏体验以《极限竞速：地平线 6》为例，称地图加载和场景切换迅速。此类应用体验取决于系统、软件、文件与游戏版本。

## 软件与维护

文章称铠侠提供原厂 SSD 管理软件，可查看运行和健康状态、升级固件及安全擦除；未给软件名称、下载地址或版本号。作者提醒不要撕掉背面参数/SN 标签，称可能影响保修，具体保修判定以购买地区与厂商条款为准。
