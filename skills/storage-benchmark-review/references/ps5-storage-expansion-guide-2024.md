# PS5 Slim 购买与 M.2 SSD 扩容记录（2024）

## 来源与证据边界
来源：[酷安原帖](https://www.coolapk.com/feed/54811853)，发表于 2024 年。兼容范围与拆装方法为原帖记录；原帖未列出索尼官方规格链接或扩容测试过程，无法独立确认最大容量等兼容性说法。

## 原帖记载的规格与差异
- 作者称 PS5 Slim 有光驱版与数字版，数字版之后可加装可拆卸光驱。
- 作者称初版 PS5 与 Slim 性能相同，并认为 Slim 处理器制程较新、发热可能较低；这是原帖判断，没有温度或性能对照测试。
- 原帖称内置 1TB 不够用，兼容 2230–22110 长度的 NVMe SSD，最大支持 8TB。该范围和容量上限应视为原帖说法，文中没有给出 SSD 型号兼容清单。
- 作者实际安装致态 Ti600 4TB SSD，但没有给出扩容后的测速或格式化容量。

## 原帖扩容步骤
1. 从主机正面拆开机身右侧上方盖板。
2. 找到 SSD 槽位并拧开槽位螺丝。
3. 拧下 SSD 固定螺丝，将管形垫片移至标记为 80 的位置。
4. 插入 SSD 并用螺丝固定。
5. 装回机身盖板。

## 手柄续航记录
原帖称 DualSense 手柄约 4–5 小时需要充电，并描述不同使用经历；没有给出测试亮度、振动设置或电池容量测量数据。
