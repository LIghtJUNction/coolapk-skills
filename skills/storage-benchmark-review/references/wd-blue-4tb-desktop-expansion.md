# WD Blue 4TB台式机扩容与性能记录

## 来源与证据边界
来源：酷安文章 [三月·女神节装机指南：西部数据蓝盘 装机扩容的“温柔守护者”](https://www.coolapk.com/feed/63040170)，发表于2025年。硬盘参数、跑分和耗时均按原帖报告整理，未独立验证。原帖有9张图片，本次输入未提供图片；不补写图片中的型号标签或测试曲线信息。

## 原帖描述的硬盘特性
文章对象为西部数据（Western Digital）蓝盘4TB台式机硬盘。原帖称其采用CMR垂直磁记录，持续写入表现相较SMR更适合频繁修改素材；配有256MB缓存，标称最高传输速度215MB/s。文章还称该盘使用NoTouch斜坡加载技术，以减少磁头与盘片接触造成的风险。以上为原帖的产品说明转述。

作者列出的用途容量估算：以单款3A游戏约50GB估算，可存70余款；4K WEB-DL电影按约15GB以内估算，可存250余部；100Mbps码率的4K视频约可存80小时。实际可用量取决于文件大小、格式及容量计算方式。

## 原帖测试结果

- CrystalDiskMark顺序读取236.06MB/s、顺序写入214.79MB/s。
- 选择64MB测试数据包时，作者报告读取超过550MB/s，并称随机4K多线程读取超过80MB/s；该小测试数据包结果受缓存影响，不能当作盘片持续吞吐速度。
- 从SSD向硬盘复制20GB电影文件：开始时突发速度较高，随后趋稳在约200–230MB/s。
- 复制约222GB零散素材：约1.7万多个RAW/JPG文件、35个子文件夹，平均传输速度约150–160MB/s，过程中有波动。
- 原帖给出的功耗：待机0.6W、读写时4.8W、平均工作功耗1.75W。文章据此估算每天运行8小时，每月电费约0.2元；电费取决于实际运行时间和电价。

## 台式机SATA安装与Windows初始化

### 准备
硬盘本体、十字螺丝刀（视机箱固定方式而定）、SATA数据线、SATA供电线。原帖称数据线通常随主板提供，供电线随电源提供。

### 安装与初始化
1. 关机后打开机箱，找到3.5英寸硬盘位。
2. 将硬盘放入托架，用螺丝或免螺丝结构固定。
3. 用SATA数据线连接硬盘与主板SATA接口；用SATA供电线连接电源与硬盘。接口的L形结构用于防呆对位。
4. 开机，在Windows开始菜单上点右键进入“磁盘管理”。按提示初始化硬盘；对未分配区域点右键，选择“新建简单卷”，按向导继续完成分区和盘符设置。

原帖提示，4TB硬盘在Windows等系统中可能显示约3.63TB，原因是厂商与操作系统采用不同容量单位换算方式。
