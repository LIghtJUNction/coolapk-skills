# DDR5、DDR4 与 SSD 选购：原帖记录

## 行情判断（原帖时点）

作者称当时 DDR5 32GB 低时序套条曾高至 4000 元，之后低于 3000 元；其转述渠道观点，预测 618 后可能升至 3500–4000 元或更高。作者还称部分 DDR5 库存可能优先流向行业客户与整机商，渠道补货成本上升。对 SSD，文章判断短期仍可能有百元以内的小幅降价，但不太可能迅速回到过去低价；并转述行业端对年底前继续涨价的预期。以上均是文章当时的市场观察、渠道转述与预测，不是已验证的现价或后续走势。

## 按平台和负载选择

- 已确定使用 AM5 或 Intel 新平台、整机只差内存的刚需用户，作者建议关注品牌、频率、售后和可接受价格，不要把等待最低价当作确定策略。
- DDR5 普通游戏用户可考虑 6000–6400MHz。作者不建议普通用户盲目追高频或低时序，因为 CPU、主板和内存体质会影响稳定运行；稳定性优先于极限参数。
- 已有 DDR4 平台（原帖举例：B660 D4、B760 D4、Z690 D4、Z790 D4）可按实际需求升级；作者举例从 16GB 升到 32GB、或 32GB 升到 64GB，对办公、多开、剪辑和修图可能有帮助。原帖认为 DDR4 更适合旧平台补强，不建议新建中高端平台只为省内存成本倒退平台代际。
- SSD 选择上，作者建议系统盘优先考虑颗粒与品牌口碑，游戏盘和素材盘可更看重容量与价格；同时关注售后、颗粒信息和温度表现。文章提醒 SSD 故障可能造成数据损失，保修不等于文件可恢复。
- 已有容量不足或明确装机需求的用户，可按可接受价格分批购买；纯囤货则承担价格波动与库存风险。
