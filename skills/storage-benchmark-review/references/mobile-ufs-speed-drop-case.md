# 移动端混用闪存同设备复测掉速个案

本记录仅提炼同设备在不同时间点的受控复测数值与原帖批次观察，未在本库实机复测，不将原帖关于芯片工艺或质保期限的推断作为通用结论。

- 设备：一加平板 3 Pro（512GB 版本，原帖同时提及一加 15 存在闪存混用）。
- 同设备复测对比（8 月 1 日购入后 vs 后续复测）：
  - 初期测试：随机速度约 `1300+` / `1700+`，混合随机速度约 `130`（原帖未标注单位与测速工具）。
  - 后续复测：随机速度降至约 `900+` / `1300+`，混合随机速度降至约 `80+`；作者同时报告日常使用中感知不到明显区别。
