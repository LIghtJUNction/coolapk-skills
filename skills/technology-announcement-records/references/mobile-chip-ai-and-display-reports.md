# 芯片、AI 模型、显示与能效报道摘要

## 玄戒芯片

周报将小米芯片写作玄戒 O3：一篇报道列出 Prime、Titanium、Little 三个集群，超大核 4.05GHz、GPU 1.5GHz，称移除上代 Big 集群。（71493121）另一篇仅称新一代芯片从十核四丛集转向“超大核+性能大核+小核”三丛集，主频突破 4GHz。（73356707）更早一篇称小米 18 Fold 搭载玄戒 O3。（73697914）这些是周报记载，未给芯片官方技术资料；不要把不同报道的细节视为独立验证。

## 麒麟 9050 Pro 的第三方实测转述

周报称极客湾对华为 Mate XT2（麒麟 9050 Pro）测试得到 Geekbench 7 单核 1813、多核 8159；GPU 较前代提升 39%，综合表现与天玑 9200 持平。在《原神》等重载游戏中，报道描述其在较高渲染分辨率下接近满帧，1% Low 帧超过搭载骁龙 8 Elite 的三星 Galaxy Z TriFold，整体达到 8 Elite 水平。（73832971）输入未包含测试视频、设置、固件或温控条件，因此不能视为可复现实验数据。

## 2026 芯片能效横评转述

周报称极客湾横评包括苹果 A20 Pro、第六代骁龙 8 超级至尊版（8EE6）、联发科天玑 9600 Pro、小米玄戒 O3，并以麒麟 9050 Pro 和 Google Tensor G6 作参照。原文概括 A20 Pro 综合领先、玄戒 O3 多核能效突出、天玑 9600 Pro 有争议但较前代进步、第六代骁龙表现不佳。（74726724）原文没有功耗数值、测试设备、测试方法或横评链接，不能据此补造排名依据或具体成绩。

## Adreno Neural Fusion

周报称 Qualcomm 的 Adreno Neural Fusion 将神经网络处理、AI 超分辨率和帧生成整合进移动游戏图形管线，以降低渲染开销和功耗并改善闪烁、重影、细节模糊。新一代 Adreno GPU 将加入 AI 专用 Adreno Matrix Cores 和 18MB Adreno 高速缓存，使相关任务可在 GPU 内处理。（73579611）输入没有给出支持芯片清单、API、驱动版本或实际测试数据。

## 显示材料与技术报道

周报称 iQOO 16 将首发三星 M16 发光材料，材料寿命提升 33%，支持 2800nits 全局峰值亮度、10000nits 局部峰值亮度，并采用 2K 165Hz、LEAD 2.0 显示技术。（73832971）这些数值是周报转述，未说明测试图样、屏幕模式或亮度持续时间。

## 模型架构、上下文和价格

- **DeepSeek V4.1 Flash**：周报称采用 552B 参数 MoE、Causal-Encoder-Decoder 非对称设计，输入激活 8B、输出激活 16B，原生支持多模态视觉。报道价格为闲时缓存命中输入 0.02 元/百万 Token、未命中 1 元、输出 4 元；高峰时段价格翻倍。原文还称自 9 月 14 日 12:00 起 V4 Pro 请求暂路由至 V4.1 Flash，直到 V4.1 Pro 上线。（73697914）价格和路由是有时间范围的报道，不是当前服务保证。
- **DeepSeek API V4-Pro / V4-Flash**：周报称 8 月 17 日零时起采用峰谷计费。V4-Pro 高峰缓存命中输入 0.30 元、未命中 9 元、输出 27 元；空闲时段为 0.15、4.5、13.5 元。V4-Flash 高峰为 0.10、3、9 元；空闲为 0.05、1.5、4.5 元。（73356707）输入未明确价格单位及后续变更，保留原文数值，不视为现价。
- **GPT-6 Astra**：周报称支持 105 万 Token 上下文、最高 12.8 万 Token 输出；API 输入 10 美元/百万 Token、输出 50 美元/百万 Token。（73579611）
- **Gemini 3.8 Flash**：周报称支持 100 万 Token 上下文、最高 6.4 万 Token 输出；推广期 API 输入 0.75 美元/百万 Token、输出 3.75 美元/百万 Token。（73579611）
- **DeepSeek V4.1 Flash 定价报道**及以上模型能力均没有附 API 文档或独立基准数据。另一篇关于 Gemini 4 Pro 的内容明确以网传模型名和传闻上下文长度、输出长度及跨会话记忆为主，不作为已确认规格。（73832971）
