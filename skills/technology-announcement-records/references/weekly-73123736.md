## 手机与电脑产品

### 华为新品与涨价判断

报道说，华为于8月5日发布尊界 V800/V680 汽车，起售价64.8万元；并推出以下产品：

- MateBook Fold 非凡大师折叠电脑：24999元起。报道特别记载，厂商代表事后澄清起售价是24999元，不是发布会口误中的2499元。
- MateBook Pro S 笔记本：7999元起。
- MatePad Pro 12英寸：5699元起。
- WATCH GT7 系列：1588元起。
- nova16 SE：2499元起。

厂商代表在发布会上称，内存价格高涨，手机之后可能大规模涨价，否则按原有价格销售会亏损。这是其对未来价格的判断，并非报道确认的统一涨价方案。

### OPPO A7 Pro Max 发布

报道列出的配置为：6.78英寸、1.5K、120Hz OLED 直屏；骁龙4 Gen5；5000万像素前置镜头；5000万像素 OIS 主摄和200万像素黑白镜头；10000mAh 电池；支持80W有线快充和27W反向充电。价格为：

- 8GB+128GB：2199元
- 12GB+256GB：2699元
- 12GB+512GB：2999元

### REDMI 17 5G 开售

报道说，该机已在中国市场开售，搭载紫光展锐 T8300、6.9英寸720P LCD 屏幕、1300万像素后置主摄、800万像素前置镜头和6300mAh 电池，支持15W有线充电；保留3.5mm耳机接口及侧边指纹识别，出厂搭载澎湃 OS 3。价格为4GB+128GB 999元、6GB+128GB 1199元。

### iQOO Neo11 至尊版官宣信息

报道说，项目团队宣布推出该机。已披露亮点包括国产2K OLED 屏幕、采用全新发光材料，以及 Neo 系列史上最大电池，容量超过9000mAh。报道还称设计、工艺和配色经过反复打磨；未给出具体机身设计细节、价格或上市日期。

### REDMI K100 Pro 与骁龙 8 Elite Gen5 V Series

报道说，高通官网近日上线骁龙 8 Elite Gen5 V Series，型号 SM8850-1-AB。其采用第三代 Oryon 全大核架构，含2颗最高4.6GHz超大核和6颗最高3.62GHz性能核；报道称这部分与标准版8E5一致。图形部分为 Adreno 840，规模从标准版12CU缩减至8CU；独立高速显存（HPM）从18MB降至12MB。

报道说 REDMI K100 Pro 将首发搭载该芯片，并称其将于8月11日发布。另有快讯称 REDMI K100 Pro 流萤追光配色亮相。以上为报道所述发布安排和快讯。

## 涨价、存储供应与市场渠道

### 小米商城调价

报道说，小米商城更新多款手机售价，涨价范围从中低端扩至旗舰，普遍上调300至500元：Turbo5 系列、K90 系列各涨300元；K90 Pro Max 涨500元；小米17系列涨400至500元。报道将原因归于存储芯片持续涨价、整机成本难以内部消化。这些是报道所述调价及解释；其中价格变化不代表当前实时售价，也不是今日购买建议。

### DeepSeek API 定价

报道说，DeepSeek 在 API 官方文档发布提示，计划近期整体上调 API 服务定价，预计涨幅较大；具体方案和生效时间待后续官方公告。报道还称，DeepSeek此前宣布引入峰谷定价机制，高峰时段调用 API 价格翻倍。当前提示属于计划，文中没有给出新价格或生效日期。

### 长鑫存储与苹果谈判：媒体报道

据报道转述韩国媒体《Digital Daily》，苹果近期与长鑫存储就 LPDDR5X 等移动 DRAM 产品谈价，希望降低下一代 iPhone 制造成本，降价要求遭长鑫存储拒绝。该媒体报道还称，长鑫存储坚持报价不低于三星电子和 SK 海力士；华为、小米等国内厂商已通过高价长期合同锁定部分产能，因此长鑫存储无需低价争取苹果订单，存储市场议价权正由终端厂商向上游供应商转移。此部分是媒体消息及其分析，原文没有提供谈判文件或双方公开确认。

## 软件与标准计划

### Windows 11 内存效率

报道说，微软承诺在2026年剩余时间继续优化 Windows 11 内存使用效率，重点面向配备8GB及以上内存的电脑，目标是降低系统自身内存占用、改善使用流畅度。微软还表示，已通过采用更高效的内存分配器、优化 WinUI 3，以及降低 Chromium、WebView2 等组件的资源开销，逐步改善 Windows 内存效率。报道没有给出内存占用的量化变化或完成日期。

### 新能源汽车可靠性试验里程：征求意见

报道说，全国汽车标准化技术委员会公开征求意见，拟将纯电动、插电混动、燃料电池三类新能源车型的可靠性行驶试验总里程，从1.5万公里统一提高至不低于3万公里，与传统燃油车测试标准对齐。这是拟议要求，报道没有说标准已经生效。
