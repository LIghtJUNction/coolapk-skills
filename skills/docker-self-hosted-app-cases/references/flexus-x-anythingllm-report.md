# Flexus X 上运行 AnythingLLM 与 Ollama 的体验报告

## AnythingLLM 功能概述

原帖将 AnythingLLM 描述为可连接商业或开源大语言模型及向量数据库的全栈应用，可本地运行或远程托管，并针对用户提供的文档进行对话。其功能说明包括：

- 用工作区组织文档和对话上下文；工作区可共享文档，但上下文彼此隔离。
- Agent 可浏览网页、运行代码；支持为网站嵌入聊天窗口。
- 管理向量数据库中的文档，支持 PDF、TXT、DOCX 等格式。
- “聊天”模式保留先前对话记录；“查询”模式针对文档问答，并可显示引用的文档内容。
- 可连接自定义或开源模型，原帖举例 GPT-4、Llama、Mistral，并提及开发 API。

上述是原帖功能介绍，未提供具体版本或配置步骤。原帖没有给出可恢复的 AnythingLLM 项目 URL、Docker Compose 文件、模型下载地址或启动命令。

## Flexus X 实验报告

原帖报告在 Flexus X 的 `4核12G-100G-3M` 基础模式上部署，并称本地运行 Ollama 模型时能够稳定输出，虽然推理速度较慢，CPU 和内存占用均未超过 60%。原帖没有给出操作系统版本、Docker/AnythingLLM/Ollama 版本、模型名称与量化规格、提示词、并发数、测试时长或资源监测方式。因此这是作者报告的单次使用现象，不能外推为不同模型或负载下的容量保证。
