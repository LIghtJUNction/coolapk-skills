# 华为云 Flexus X 上部署 Uptime Kuma

## 原帖提供的服务器信息

文章建议先购买 Flexus X 实例，根据实际需要选择 CPU、内存、存储和带宽；示例实例为 4 核、12 GB 内存。首次购买后，在华为云控制台重置登录密码，再通过 SSH 客户端（原帖举例 xShell）或 CloudShell 登录。

原帖介绍 Uptime Kuma 为基于 Web 界面的开源监控面板，并称其可用于监控 CPU、内存、磁盘空间和网络流量。此为原帖对软件功能的概述。

## Docker 准备

原帖说明部署使用 Docker，若服务器尚未安装 Docker，应先安装。随后给出的镜像拉取命令是：

```sh
docker pull louislam/uptime-kuma
```

文中提到可参考一篇 CSDN 上的 Halo 博客部署文章安装 Docker，但输入中没有该链接的真实 URL。
