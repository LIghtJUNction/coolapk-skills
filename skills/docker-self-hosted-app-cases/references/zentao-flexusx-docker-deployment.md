# ZenTao 在 Flexus X 上的 Docker 部署记录

## 软件用途

ZenTao（禅道）是面向产品研发团队的项目管理软件。原帖概述其包含产品、项目、质量、文档、组织和事务管理，并支持敏捷与瀑布式管理方式。

## Docker 部署记录

原帖描述通过宝塔面板安装 Docker，在应用商店搜索 ZenTao 容器并安装；初始化时按需设置端口和数据目录。文章展示的容器镜像为 `idoop/zentao:latest`，容器名为 `zendao`，容器 80 端口映射到主机 8005：

```text
3306/tcp, 0.0.0.0:8005->80/tcp, :::8005->80/tcp
```

文章要求在云安全组放行 8005，访问形式为：

```text
http://主机IP:8005
```

原帖记录的容器状态为 `Up 18 seconds (healthy)`。这只反映文章截取时的状态，不是对其他环境或当前镜像的健康保证。

文章给出的初始登录示例为用户名 `admin`、密码 `123456`，并称首次登录需修改密码。该凭据来自公开文章，不应直接用于实际部署。文中还记录可在界面切换综合研发与运营管理视图；基础操作依次包括添加用户、创建项目集、创建产品、提交研发需求和创建项目。

## 文章记录的云主机环境

文章描述的示例环境为 Flexus X、Rocky Linux 9、Docker `27.1.1`，并列出 4 vCPU/12 GiB、100 GB SSD 和 3 Mbit/s 公网带宽。正文未提供 Docker 拉取/运行命令、数据目录的具体挂载方式、ZenTao 版本或数据库持久化配置。
