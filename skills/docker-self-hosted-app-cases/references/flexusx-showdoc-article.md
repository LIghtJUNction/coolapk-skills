# Flexus X 上部署 ShowDoc：文章记录与可复现信息

## ShowDoc 功能定位

原帖将 ShowDoc 描述为 API 文档管理工具，支持在线协作编辑、历史版本回溯或恢复、访问权限设置、插件扩展、Web 访问和样式定制。列出的用途包括维护 API 文档、产品与技术协作、远程团队文档共享、内部知识库、测试案例记录、客户技术支持和代码文档化。

## 文章记录的环境与操作

文章列出的示例主机为华为云 Flexus X，Rocky Linux 9，4 vCPU/12 GiB，100 GB 通用型 SSD，公网带宽 3 Mbit/s，并记录 Docker 版本为 27.1.1。文章称通过 MobaXterm 使用弹性公网 IP 和 root 账号连接服务器。

ShowDoc 部署部分只描述了进入管理页面、新建项目、填写项目名称和描述、新建页面、编辑并保存文档，最后分享文档链接。正文没有给出 Docker 镜像名、拉取或启动命令、端口映射、安全组端口、ShowDoc 版本或项目链接；环境检查章节也没有留下可读命令输出。因此这份记录不能作为逐条可执行的容器安装教程。
