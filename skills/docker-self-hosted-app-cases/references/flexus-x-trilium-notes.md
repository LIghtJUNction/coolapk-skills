# Flexus X 与 Trilium Notes

## Trilium Notes 功能摘要

原帖将 Trilium Notes 描述为面向大型个人知识库的分层笔记应用，提及以下功能：

- 笔记可组成任意深度的树，同一笔记可放在多个位置；支持所见即所得编辑、表格、图片、数学公式及 Markdown 识别。
- 支持代码编辑与语法高亮、笔记导航、全文搜索、笔记版本管理、自定义属性和脚本。
- 支持自托管同步服务器及第三方同步服务；可发布笔记到公共互联网。
- 提供按笔记粒度加密、Excalidraw 绘图、关系图与链接图、REST API。
- 原帖称可处理超过十万条笔记，并提到移动端触摸界面、夜间模式、Evernote 和 Markdown 导入导出、Web Clipper。

以上是原帖的功能介绍，没有独立测试或版本号，不能视作对当前版本的性能保证。

原帖称该实践用于个人测试学习环境，提醒生产环境谨慎。列出的环境为：
