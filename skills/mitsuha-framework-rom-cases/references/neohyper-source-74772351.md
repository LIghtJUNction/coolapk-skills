## 本帖评论反馈

- 有用户询问从江南官改直接切换，另一用户回答“可以，不用清数据”；另一线程询问悍匪官改保数据切换，未见作者针对该问题确认。两条讨论均不能替代作者兼容承诺，并与正文跨作者ROM建议清数据的提示并存。
- 有用户报告从江南双清刷入后开机跳账号锁、Wi-Fi 无法开启、移动数据不可用，称线刷后恢复；作者在对应评论中回复“卡刷可能漏了点分区，下版本完善”。该事故和作者怀疑均为本帖评论内容；账号锁与 FRP 的因果未证实，也不能推为所有设备都会发生。
- 用户报告控制栏显示异常、Wi-Fi 无法开启、主题商店闪退、状态栏修改不生效；评论有人猜测掉基带并建议清 data 或刷回原包，未见作者给出确认诊断。
- 有用户报告调节内置模块后模块入口和 Neko 版本设置入口消失。后续评论分别称重刷仍无入口、清数据后没问题，另有人提醒一个“关闭后本页全部修改不生效”的开关；这些是用户反馈，没有明确的作者故障结论。
- 有用户报告应用商店无网络；评论建议关闭“无网状态”，有人称自己遇到后关闭即恢复。图片未读取，具体开关位置及是否适用于其他情况不明。
- 有用户称手机管家垃圾清理无法使用，没有作者确认或明确修复结果。另有超级小爱不能用的反馈，跟帖读者将其类比为应用商店的问题，未给诊断证据。
- 有用户称不用 Root 时很多功能不生效；另有用户报告使用 SukiSU Ultra GKI Root、刷对应 AK3 内核后不能进桌面，无法启用 SUSFS，只能使用 LKM，并询问适配内核。所给评论中没有作者答复或解决结论。
- 有用户提醒系统应用不要升级，否则 Hook 可能无效。这是用户提醒，与 shared-core.md 中作者“更新后不易失效”的说法并存，不能视为已确认规律。
- 评论还报告主题商店、机型选择及自带模块入口等问题；相关图片未读，评论历史不完整，不能补充图片所示信息。
