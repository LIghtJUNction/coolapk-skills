# FlymeAIOS 12.6 Beta6

## 来源与证据边界

来源：酷安帖子 [72884208](https://www.coolapk.com/feed/72884208)。帖子标题指向一加 Ace5；正文标签含 Project Treble。功能修复属于发帖者的更新说明，未有独立验证。帖子有图片但图片内容未提供。

## 更新内容

帖子称本次更新包括：

1. 修复魅族 Aicy 语音唤醒，并称可正常唤醒。
2. 修复魅族全功能相机，支持前后摄、拍照水印和动态图片。
3. 修复后台进程异常增多问题。
4. 优化系统整体功耗。
5. 将 `payload.bin` 打包为支持 TWRP 卡刷的形式。
6. 修复刷机后格式化 `DATA` 会循环进入 TWRP 的问题。

## 下载与开发状态

- 原帖给出的项目站为 `team.hanfy.asia`。原文没有协议，补全为 HTTPS 属推断：<https://team.hanfy.asia>。帖子称通过该站获取下载，但没有给出具体文件页或直链。
- 一加 13T 的 Flyme 适配当时仍在制作，帖子预告预计七天内更新；这是当时的计划，不代表已完成发布。
