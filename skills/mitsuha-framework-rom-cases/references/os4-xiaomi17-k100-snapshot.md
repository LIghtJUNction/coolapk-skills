# MitsuhaFramework 与 Xiaomi 17、Redmi K100 系列官改 ROM

## 来源与证据边界

来源：酷安帖子 [74395781](https://www.coolapk.com/feed/74395781)、[74357315](https://www.coolapk.com/feed/74357315)、[74355515](https://www.coolapk.com/feed/74355515)。以下为帖子对 ROM 功能的描述，不代表独立安装验证。帖子包含图片，但图片内容未提供；文中未列出 ROM 下载地址、刷机步骤或具体 Android X 实现细节。

本页只记录这三帖当时列出的功能，不把主技能后来补入的在线歌词、功耗刷新间隔或在线更新安装流程反推给这些版本。机型名称按帖子声明保存，未核实发布和可用性。

## 版本与机型

- 标题为 Xiaomi 17 系列 OS4.0.2 的帖子列出 Xiaomi 17、Xiaomi 17 Max、Xiaomi 17 Pro、Xiaomi 17 ProMax、Xiaomi 17 Ultra。
- Redmi K100 系列 OS4.0.0 帖子列出 Redmi K100 Pro、Redmi K100 ProMax。
- Xiaomi 17 系列 OS4.0.44 帖子列出 Xiaomi 17、Xiaomi 17 Pro、Xiaomi 17 ProMax、Xiaomi 17 Ultra；未列 Xiaomi 17 Max。
- 帖文称 MitsuhaFramework 基于 Android X 动态注入技术，随系统内置、脱离 LSPosed、免 ROOT。功能入口为「设置 → MitsuhaFramework」，按功能独立开关。发帖者称大多数设置立即生效，少数需重启系统界面或手机；系统框架增强项明确需在启用或关闭后重启手机。该技术机制和兼容性未在帖子中提供独立验证。

## 功能记录

### 状态栏、通知与锁屏

- 状态栏可设双排，第二行显示网速、歌词、功耗或日期；时钟格式可分别自定义状态栏、锁屏和通知栏。功耗可在电池图标旁实时显示；网速可改为经典单行大字并以 K/M/G 简写。
- 双卡信号可上下堆叠；前摄挖孔周围可显示电量环，帖子称省电模式为黄色、其他模式为蓝色，并可调环高和粗细。电量、Wi-Fi、移动网络可合并为三合一图标并调整尺寸、颜色、位置。
- 双击状态栏右半边息屏，左半边保留系统回到顶部操作。控制中心可加独立 5G 开关，长按进入 5G 设置；长按移动数据磁贴也可见 5G 开关。个人热点启用时，展开灵动岛可查看当日热点流量。可隐藏悬浮通知下方横条，帖子称下拉开小窗手势仍可用。
- 锁屏音乐封面可淡入为背景；另一个选项可让锁屏壁纸跟随专辑封面，并联动时钟颜色和媒体卡毛玻璃，关闭后恢复原壁纸。这两项可同时启用。歌词可显示在状态栏或灵动岛，并选择歌词、歌名和封面所在位置。
- 可下移锁屏通知、隐藏屏下指纹图标（仅锁屏一次或全局）、显示锁屏岛和充电时的温度/电流/电压/功率；第三方壁纸可启用锁屏与息屏景深效果。柔光玻璃对悬浮通知、焦点通知和第三方主题分别设开关。
- 锁屏通知可限制最大占用高度；快捷方式可调整背景、圆角、间距、图标大小和颜色。锁屏底部文字需先启用「锁屏底部文字自定义」总开关，再分别隐藏充电状态、勿扰模式和通知条数。这些锁屏外观设置需重启系统界面。

### 息屏、显示和设置入口

- 「连贯息屏」实现息屏、锁屏、桌面之间的连续动画，需配合系统自带连贯息屏壁纸，并在 HookManager「魅族连贯息屏」页面选择壁纸和样式；帖子称使用小米超级壁纸或官方壁纸不受影响。
- 可解锁息屏编辑器全部样式；放出 AI 相册编辑、AI 写作、AI 搜索等设置入口，以及性能模式、链路加速、批量通知管理、更多通知设置、AI 画质、最高刷新率、MEMC、永不停歇息屏、超分辨率和传送门等隐藏功能。另有「隐藏功能」页集中广告设置、隐藏应用、电池信息等入口。
- 青山护眼更换为新一代界面，首次打开后需重启设置应用。状态栏通知图标数可设 0～20；Wi-Fi 详情可显示已保存网络密码；屏幕超时选项可加入「永不」。帖子称恢复澎湃 3 被精简的屏幕色彩页，包括色温盘和调色盘。
- 开发者选项路径为「设置 → 更多设置 → 开发者选项 → 芯片性能面板」。帖子称面板按实际核数显示超大核、中核、小核频率卡及 GPU 最高频率，并可查看完整频率档位；没有给出具体频率数值。

### HookManager 设备信息与更新

- HookManager「设置 → 高级 → 关于手机」可选设备原始、框架原生美化、仿鸿蒙三种「我的设备」样式；两种美化样式互斥。原生美化页显示设备名称和存储信息并隐藏保修权益卡；仿鸿蒙页可给设备名卡圆形区域填一个字或表情，版本卡换图。
- 美化卡片可添加自定义参数行。关于本机可改型号、处理器、内存、存储和系统版本等显示值，留空项目沿用系统值。版本号 Beta 后缀仅在官方「关于本机」样式显示。点关于手机保修行可进入「关于悍匪ROM」页。
- HookManager 高级设置可在悍匪站与官方之间切换系统更新渠道；更新后首次开机提供版本变更导览。帖子称框架不介入 OTA 流程。

### 应用增强

- 短信验证码自动复制；录音机去 AI 水印并提供 AI 录音、高清录音参数；屏幕录制最高帧率 185 fps、最高码率 1200 Mbps（帖子给出的上限，未注明机型实测条件）。
- 安装包管理器移除安装广告、安装后小游戏推荐和备案弹窗；小米互传加入碰一碰；主题商店开放付费主题、字体、图标和小组件，并移除启动广告。
- 相机加入 Leica LCC 界面、保留原生焦段及徕卡一瞬/传奇一瞬模式。超级小爱输入法改用全局搜索外观，帖子称 AI 回复和语音输入不会因内容审核中断。
- 应用商店、小米音乐、日历、指南针、主题商店使用悬浮液态玻璃底栏，选中项跟手移动、松手回弹。
- JmComic 去广告默认关闭；帖子称启用后立即生效，关闭会还原并清除本地广告缓存。
- 手机管家相关增强包括跳过 Root 提示、危险权限倒计时和应用互相拉起确认，安全评分显示 100，允许电脑推装应用，晕车监测、电池详细信息及去除电池锁容（帖子称显示真实容量、放开满充）。备份项包括关闭国际版标记、坏屏数据备份和备份全部应用。

### 隐私、电量、安装限制与系统框架开关

- 隐藏应用列表的描述效果包括其他应用无法查到指定应用、打开其页面或读取其数据，并从无障碍与输入法列表隐藏。
- 电量与性能包含待机白名单（帖子称默认放行微信）和锁定最高刷新率。音量项包括关闭耳机安全音量提示、未播放音乐时按音量键直接调媒体音量、自定义媒体音量档数（需重启手机）。第三方输入法可读取剪贴板历史；双击或三击手机背部可开「超级小爱记忆」。
- 核心破解可分别关闭签名校验、完整性校验和降级安装限制；帖子称「绕过签名验证」默认关闭。此类选项改变安装限制，不构成对应用安全性的证明。
- 下列系统框架增强项默认全部关闭，启用或关闭后均需重启手机：绕过应用隔离违规校验；允许安装低 API 应用；禁用应用持久化检查；允许更新系统应用；绕过未知来源安装限制和强制小米应用商店；全应用深色模式；隐藏屏幕挖孔；AOSP 原生截屏；全局背景模糊；增强最近任务可见性；解锁全部屏幕旋转；关闭后台清理；删除通知时同步移除悬浮通知；禁用温控和手势监控；跳过设备日志访问验证；GMS Doze 修复；禁用 72 小时密码验证和应用链接验证；允许被其他窗口遮挡的触摸；禁用 MIUI 水印；小窗数量上限 256、解除小窗应用黑名单、小窗置顶；解除焦点通知（超级岛）白名单。
- 帖子称每个开关独立，出问题可关闭对应项而无需重刷；依赖应用未安装时框架会自动关闭相关开关并显示原因。未提供异常诊断细节或实测记录。

安全评分100、隐藏应用和关闭检查均是功能宣称，不代表设备真实安全、应用数据隔离已验证或硬件能力改变。
