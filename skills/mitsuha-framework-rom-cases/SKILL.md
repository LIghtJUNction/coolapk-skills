# Mitsuha Framework：功能与操作说明

> 本文是对所列 Coolapk 帖子内容的归纳，不代表独立测试或兼容性认证。各条目是原帖对框架功能的描述。

## 框架定位与运行条件

原帖称 MitsuhaFramework 基于 Android X 动态注入技术，随 ROM 内置，入口为「设置 → MitsuhaFramework」，无需另装插件或单独授权，并自称脱离 LSPosed、免 ROOT 运行。原帖另称框架在线更新可在 HookManager「软件更新」页识别 KernelSU、APatch 或 Magisk 并通过其安装，更新后重启生效。两种说法并存；在线更新涉及这些安装器的描述不构成“在线更新已在无 ROOT 环境验证”的证据。

原帖称每项功能有独立开关，关闭后恢复系统原行为；大多数改动即时生效，部分需要重启系统界面或手机，界面会注明。框架自称不改系统原有逻辑、不介入 OTA。若依赖应用缺失或设备不支持，原帖称框架会自动关闭对应开关并显示原因。出现问题可关闭相关开关；原帖称通常无需重刷系统。

## 重启条件

原帖明确指出：

- 「系统框架增强」中的开关默认全部关闭，**开启或关闭任一项都要重启手机**。
- 锁屏通知位置、锁屏快捷方式外观、锁屏底部文字相关功能：开启后重启一次系统界面。
- 青山护眼：第一次打开后重启设置。
- 媒体音量档数：修改后重启手机。
- 其余功能按各开关下方提示操作；原帖没有逐项列出全部重启要求，不应推定全部即时生效。

## 功能目录

### 状态栏与灵动岛

- 双排状态栏；第二排可放网速、歌词、功耗、日期。双卡信号可上下堆叠，单卡保持原样。
- 自定义状态栏、锁屏和通知栏时钟格式；时钟后可加爱心、星星、月亮或四角星，颜色随明暗背景变化。
- 电池图标旁显示功耗，刷新间隔可调 **0.5–10 秒**；网速可改为经典单行大字，单位简写 K/M/G。
- 前摄挖孔周围显示电量环：省电模式黄色、其他模式蓝色，可调环高度和粗细；横屏时自动隐藏（更新说明）。
- 三合一状态图标合并电量、Wi-Fi、移动网络，可调尺寸、颜色、位置；关闭后可恢复原生图标。
- 双击状态栏右半边息屏，左半边仍为系统「回到顶部」；可添加独立 5G 开关，控制中心磁贴长按进入 5G 设置，长按移动数据磁贴也可显示 5G 开关。
- 展开灵动岛可查看个人热点当日流量；可隐藏悬浮通知下方横条，向下拖出小窗手势仍可用。
- 更新说明另称状态栏自定义切换标签时，顶部实时预览会移动到对应图标。

### 锁屏、通知与息屏

- 播放音乐时专辑封面淡入锁屏背景；可让锁屏壁纸跟随专辑封面，并同步调整时钟颜色和媒体卡毛玻璃。关闭后恢复原壁纸；两项可叠加。
- 歌词可显示在状态栏或灵动岛，并可选择歌词、歌名、封面所在格；在线整首歌词支持 QQ 音乐、网易云音乐、汽水音乐，按播放进度逐句显示，支持暂停、拖动和切歌。
- 锁屏通知整体下移；柔光玻璃对悬浮通知、焦点通知、第三方主题分别设置；屏下指纹图标可仅在锁屏时隐藏或全局隐藏。
- 锁屏岛持续显示，解锁后交还系统；左侧人脸识别图标随识别动作变化，右侧提示「上滑解锁」。充电时锁屏功耗计显示温度、电流、电压、功率。
- 原帖称可解除第三方壁纸在锁屏和息屏上的景深限制。可限制锁屏通知占用高度，调整左右快捷按钮背景、圆角、间距、图标大小和颜色；开启锁屏底部文字总开关后，可分别隐藏充电状态、勿扰模式和通知条数。以上锁屏外观与文本相关开关需重启系统界面。
- 连贯息屏提供息屏→锁屏→桌面的连续动画，息屏可透出与锁屏同一帧壁纸。需使用系统自带连贯息屏壁纸，并在 HookManager「魅族连贯息屏」页选壁纸及样式；原帖称小米超级壁纸或官方壁纸不受影响。息屏编辑器样式可全部解锁，不再按机型限制。

### 设置、显示与设备信息

- 放出不受机型限制的 AI 设置入口，如 AI 相册编辑、AI 写作、AI 搜索；隐藏功能解锁项包括性能模式、链路加速、批量管理通知、更多通知设置、更多 xxx 类型、AI 画质、最高刷新率、MEMC 补帧、永不停歇息屏、超分辨率、传送门。
- 增加「隐藏功能」页，汇集广告设置、隐藏应用、电池信息等入口。青山护眼切换到新一代界面；通知图标数量可设为 **0–20**；Wi-Fi 详情可显示已保存网络密码；屏幕超时加入「永不」；恢复澎湃 3 屏幕色彩完整页面（色温盘、调色盘）。
- 开发者选项可显示芯片性能面板，展示超大核、中核、小核各自最高频率、GPU 最高频率及完整频率档位；按实际核心数显示。
- HookManager「设置 → 高级 → 关于手机」中，「我的设备」样式可选设备原始、框架原生美化或仿鸿蒙，两种美化互斥。原生美化显示设备名称和存储信息并隐藏保修权益卡；仿鸿蒙版可自定义名称卡圆形字符/表情和版本卡图片。美化卡片可添加自定义参数行；「关于本机」型号、处理器、内存、存储、系统版本等字段可改，留空则保留系统值。官方关于本机样式可显示版本号 Beta 后缀；点击保修行可打开「关于悍匪ROM」页。
- 高级设置可在悍匪站和官方之间切换系统更新渠道；首次更新后开机有更新导览。

### 应用增强

- 短信验证码自动复制；录音机去 AI 水印、提供 AI 录音和高清录音参数。
- 屏幕录制最高 **185 fps、1200 Mbps**；安装包管理器去安装广告、安装后小游戏推荐和备案弹窗；小米互传支持碰一碰。
- 主题商店可用付费主题、字体、图标、小组件，且去开屏广告；相机加入 Leica LCC 界面、保留原生焦段和徕卡一瞬/传奇一瞬模式。
- 超级小爱输入法改为全局搜索外观；原帖称 AI 回复和语音输入不再因内容审核中断。
- 应用商店、小米音乐、日历、指南针、主题商店底栏改为悬浮液态玻璃样式，选中项随手指移动并有回弹。
- JmComic 去广告（广告位及开屏广告），修改即时生效；关闭后恢复并清除本地广告缓存，默认关闭。
- 手机管家增强项：跳过 Root 提示、危险权限倒计时和应用互相拉起确认框；安全评分 100；不拦截电脑推装应用；晕车监测、电池详细信息、去除电池锁容（显示真实容量、放开满充）。
- 备份项：关闭国际版标记、坏屏数据备份、备份全部应用。

### 安全、省电与交互

- 隐藏应用列表：原帖称指定应用不会出现在其他应用的查询、页面打开、数据读取、无障碍和输入法列表中。
- 待机白名单默认放行微信；可锁定最高刷新率。
- 可关闭耳机安全音量提示；未播放音乐时按音量键直接调整媒体音量；媒体音量档数可自定义（修改后重启手机）。
- 允许第三方输入法读取剪贴板历史；双击/三击手机背面打开「超级小爱记忆」。
- 核心破解项可分别关闭签名校验、完整性校验、降级安装限制；「绕过签名验证」为常用项，默认全部关闭。

### 系统框架增强（默认关闭，切换均需重启手机）

原帖列出的开关包括：绕过应用隔离违规校验；允许安装低 API 应用；禁用应用持久化检查；允许更新系统应用；绕过未知来源安装限制和强制小米应用商店；全应用深色模式；隐藏屏幕挖孔；AOSP 原生截屏；全局背景模糊；增强最近任务可见性；解锁全部屏幕旋转；关闭后台清理及按耗电杀进程；删除通知时移除对应悬浮通知；禁用温控；禁用手势监控；跳过设备日志访问验证；GMS Doze 修复；禁用 72 小时密码验证；禁用应用链接验证；允许不受信任的触摸；禁用 MIUI 水印；小窗数量上限 **256**；解除小窗应用黑名单；小窗置顶；解除焦点通知（超级岛）应用白名单限制。
