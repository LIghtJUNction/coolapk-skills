# 蓝牙耳机测评：降噪、透传、频响与听感

## 华为 FreeBuds SE 4 ANC

- **结构与佩戴**：耳机单只约 4.2 g，入耳体积偏大，长时间佩戴可能胀耳；耳机顶部有风道设计。作者称机身合模线较明显。
- **降噪**：作者报告平均降噪深度 31.6 dB；100–3000 Hz 范围内基本维持 30 dB 以上，峰值在中频。作者将表现归因于耳道自适应算法，同时指出算法收敛较慢，转头或关门引起气压变化时可能重新介入并带来耳压感变化。
- **透传**：曲线未贴合噪声源，但较平直；作者认为在麦克风与芯片限制下，外界声音还原自然。
- **频响与听感**：开启降噪后，20–400 Hz 增益明显，400–1000 Hz 削减，1000–4000 Hz 增益，4–20 kHz 整体较平滑。作者主观评价为温暖、低频较多、适合流行人声；测试使用 AAC、默认调音。
- **功能与续航**：作者称续航较长、延迟较低、通话质量优秀；没有双设备连接和佩戴检测。原帖未给出量化续航、延迟或通话测试方法。

## Redmi Headphones Neo

- **佩戴**：整机约 263 g，耳罩内径较大、深度较深，作者认为夹持力适中。
- **降噪与透传**：作者报告主动降噪极限约 32 dB、覆盖频宽约 800 Hz，认为整体更多依赖头戴结构的被动隔音；尖锐噪声削弱较好，日常噪声削弱有限。透传约在 1000 Hz 开始明显滚降，听感偏沉闷。
- **频响**：开关降噪时频响变化很大。关降噪时低频增益高、高频不足；开降噪后低频减少、高频增加。降噪开启时，40–150 Hz 增益明显，300–600 Hz 有凹陷，1400–4000 Hz 稍削弱，4–20 kHz 增益较高。
- **听感与 EQ**：原帖作者主观认为高频暗、解析较弱，齿音明显，整体偏暖且听感粗糙。作者提供了降噪模式 EQ 方案，但输入未包含具体参数或图片，因此无法复现。
- **证据范围**：帖子将产品称为红米首款蓝牙头戴耳机；未给出精确型号后缀或测量设备信息。

## Redmi Buds 8 Pro

- **佩戴**：单只约 5 g；作者称长时间佩戴可能有挤胀感。
- **降噪**：作者报告平均约 30 dB，主动降噪频宽约 4000 Hz；峰值在 200–500 Hz，至约 3500 Hz 基本维持平均 30 dB 以上。中高频有小幅反向增噪。与同价位竞品相比，作者认为 250–700 Hz 略占优，20–200 Hz 与 1500–6000 Hz 有差距。
- **透传**：作者称中高频衰减较小，接近极高频才明显滚降。
- **频响与音量现象**：关降噪时整体大致贴合 JM1 参考，80–500 Hz 稍削弱，500–3000 Hz 与 4000–8000 Hz 略增益，8–20 kHz 滚降较早。开降噪后频响波动明显，低频及中低频增益、高频出现高峰。作者还报告高音量时中频出现异常凹陷，主观听感更“两头翘”；原帖未提供音量数值或复测条件。
- **听感与 EQ**：测试标注 LHDC、默认降噪模式。作者主观认为原始降噪调音偏低频；使用其自制 EQ 后，听感更均衡、清晰。EQ 参数未出现在输入中，无法复现。
- **软件问题（短暂一天测试）**：作者报告连接多个设备后频繁断连；第三方手机未同步设备音量；佩戴后降噪深度自动锁定、无法调节。帖子没有后续修复信息，不能据此判断当前固件状态。

## 天使吉米 RITA

- **佩戴**：整机约 290 g；耳罩开口偏小，但内腔倾斜且耳廓一侧较深。作者认为夹持适中、整体舒适，耳廓特别大者的适配情况未说明。
- **降噪与透传**：作者报告主动降噪主要覆盖 20–2300 Hz，平均约 25 dB；500–1200 Hz 出现较明显反向增噪。高频降噪对尖锐电气设备声较好，整体同价位表现被评价为前列。透传曲线较早滚降，但作者称高频仍未明显衰减。
- **调音功能与频响**：原帖称提供 8 种预设调音、自定义 PEQ 和调音社区。开降噪后频响有波动，中频削弱、极低频与高频增强；300–3000 Hz 大体贴合参考，4–20 kHz 增益稍高且滚降平滑。
- **有线模式**：作者认为有线模式没有专门腔体设计与调音，表现很差；建议使用带 DSP 的线，或开机经过 DSP。该建议属于作者经验，帖子没有给出 DSP 线型号或测试条件。
- **听感**：测试标注 LDAC、默认降噪开启。作者主观评价为偏暖、贴耳、包裹感较强的流行女声取向。

## 小米 Air5

- **产品销售背景**：帖子称官方标价 549 元但不实际售卖，是手机赠品；测评按当时二手约 200 元估价。该价格和销售状态是发帖时的信息，不代表当前价格。
- **佩戴**：单只约 5.5 g；入耳部分略大，作者称佩戴稍胀耳。顶部有对穿风道设计。
- **降噪与透传**：作者报告全频平均降噪约 30 dB，低频峰值较强，中频表现稍弱；认为嘈杂通勤环境更合适，安静人声环境相对较弱。与 Redmi Buds 8 Pro 对比时，作者观察到极低频略强、其他频段相似，并推测算法方案相近。透传约从 1300 Hz 开始滚降，高频偏差较大，主观听感偏沉闷。
- **频响与听感**：开启降噪后频响波动大。20–200 Hz 略增益，200–500 Hz 增益很高，500–3000 Hz 有增益且约 2.5 kHz 有补偿峰，3–20 kHz 增益偏低、滚降较平滑。作者主观评价为低中频偏多、温暖昏暗、适合抒情人声；测试未注明编解码器。
- **EQ**：作者称制作了降噪模式 EQ，使声音更明亮均衡；原帖未提供参数，无法复现。
