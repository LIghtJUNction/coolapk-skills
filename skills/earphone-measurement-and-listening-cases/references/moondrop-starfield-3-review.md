# 水月雨星野3：结构、频响与听感记录

## 结构与附件

- 双动圈入耳式耳机；作者称腔体结构改为更接近 Blessing 3 的构造，未采用其所称水月雨部分入门机型使用的锌合金腔体。
- 单只约 6.5 g，类私模外形；作者认为腔体不算大、耳甲部分不突出，多数人可能较舒适。此处没有不同耳型的实际适配统计。
- 附送 C 口转接器，原帖称其具有 32 段 PEQ 功能；未说明应用、控制方式或滤波器类型。原帖还提到可换插设计。

## 频响分析

原帖以倾斜扩散场为参考：

- 20–400 Hz 大致贴合，中低频略增益，作者认为会让中低频乐器和男声结像略前倾，增加温暖感与氛围，同时削弱纵深。
- 400–4000 Hz 大致贴合；其中 1000–4000 Hz 增益不低，作者认为高频乐器和女高音结像略前倾，并增强中低频厚度与穿透感。
- 4000–20000 Hz 整体滚降较平滑，但有明显压制；作者认为解析感、明亮感和横向声场会减弱，中频厚度感相对增强。
- 原帖总体将其描述为三频大致均衡、中低频与中频略增、高频略克制的温暖流行取向。

## 主观听感

作者评价高频柔顺、中频突出且饱满，低频量略多、混响较长；横向声场较开阔，纵向距离感较弱，整体偏贴耳、强调人声临场感。作者认为适合流行人声，并将其与 Aria 2 作主观风格比较。

作者称原装耳套偏硬并压缩声场表现，深插佩戴可能改善低频动态；此为作者个人体验。原帖重复出现推荐替换耳套的表述，但没有提供产品链接或尺寸参数。
