# 耳机测评记录：降噪、频响与听感

## 阅读说明

本文汇总的降噪、频响与听感结论来自对应酷安帖；属于帖内测试描述或主观体验。原输入未提供测量图、EQ参数图或详细测试条件，因而无法复核曲线、均衡器方案和跨机型测量的一致性。帖子中的推荐评级是作者评价。

## 真无线耳机

### 小米 Buds 6

- **结构与佩戴：**单耳约 4.4 g。入耳贴合处较扁平，出音嘴略向上倾斜；作者认为佩戴挤胀感较前代减弱，适合长时间佩戴。
- **降噪：**作者报告在理想紧密耦合下全频平均降噪约 20 dB；正常佩戴下效果很弱。作者称其降噪水平与 Redmi Buds 7S 接近。其手上样机开启降噪后有电流底噪，开启降噪续航约 3 小时。未提供机型配对或续航测试条件。
- **频响与听感：**作者在五种佩戴紧密程度下测试频响并取中间值。以倾斜扩散场为参考，开启自适应听感后低频有所补偿，但 20–400 Hz 仍偏少，极低频衰减较快；400–4000 Hz 增益较多，人声和中低频乐器更突出；4–20 kHz 滚降较早且平滑，极高频延伸较好。整体偏中频人声，低频与高频存在感较低。
- **编码与设置：**帖子原样写 `aptX ll`，不能据此判断具体 aptX 子协议或兼容矩阵；调音为“哈曼大师 - 自适应开”。非本家机型游戏延迟被作者评价为很高；头部追踪体验被评价为无明显作用。帖子未给出手机型号、固件或延迟测值。
- **作者结论：**相较上一代，音质和佩戴有所改善；降噪与非本家机型体验是主要短板。推荐评级 C。

### 华为 FreeBuds Pro 5

- **结构与佩戴：**单耳约 5.5 g；入耳部分较短且略倾斜，作者认为有利于长时间佩戴。
- **主动降噪与透传：**作者报告全频平均降噪深度 36 dB，低频 100–400 Hz 峰值平滑后接近 60 dB；50–3000 Hz 平均约 40 dB，至 3 kHz 仍接近 35 dB，主动降噪覆盖约 5500 Hz。高频有小幅反向增噪。透传曲线据作者描述几乎没有滚降，整体较贴合。原帖有测量配图，但图片未读取；正文没有完整测试和佩戴条件。
- **音调与听感：**帖子称有等响曲线补偿，并针对两种耳套分别调音；开启降噪后频响仅有轻微变化，极低频略增并在极高频附近补偿。以 JM1 为参考，20–150 Hz 增益较高；150–2000 Hz 较平直；2000–5000 Hz 补偿峰增益较低；5–20 kHz 滚降平滑且延伸较好。作者评价为三频均衡、略偏下盘、强调动态与声场规模。
- **编码与设置：**原帖写 `LHDC`；[华为官方规格](https://consumer.huawei.com/en/headphones/freebuds-pro-5/specs/)的测试模式写的是 `L2HC/LDAC` 与 `AAC`，不能把原帖写法当作已核实的 LHDC 支持，也不能混同 L2HC 与 LHDC。原帖听感使用默认调音、降噪开启。
- **作者结论：**作者在两个月以上的个人使用后，将其评价为综合体验很强的蓝牙耳机；推荐评级 S。此为个人体验，不是独立验证。

### Sony WF-1000XM6（帖子称“降噪豆6”）

- **结构与佩戴：**单耳 6.1 g（不含耳套），前代为 5.1 g。作者称腔体较前代更大、佩戴异物感更强；豆式结构的降噪较依赖紧密耦合。
- **降噪与透传：**作者报告平均降噪深度 36 dB，几乎全频段超过 30 dB；被动降噪在中高频较前代更好、在中低频较弱，主动降噪也较前代提升。作者认为实际效果受佩戴影响，舒适度与降噪耦合存在取舍。透传曲线据作者描述几乎全频贴合，高频附近有较大波动。
- **降噪开启后的频响问题：**作者使用 BK5128 测试，称开启降噪后频响出现明显变化：20–500 Hz 大幅增加，500–1000 Hz 出现凹陷，导致低频偏多、中频凹陷及声音沉闷；原帖称没有针对性优化。关闭降噪时，作者认为频响较均衡，仅高频略有增益。
- **作者提到的调整方向：**帖子提及一套降噪模式均衡器方案，但没有给出参数；也建议尝试 A Cup2 耳套，称可补中频、增强高频。两者效果未提供可复核数据。
- **编码与设置：**帖子列出 LDAC；听感评价基于默认调音、降噪开启。
- **作者结论：**开启降噪时的音质是其主要批评点，推荐评级 C。

### Samsung Galaxy Buds 4 Pro

- **结构与佩戴：**单耳 4.8 g（不含耳套）。耳套带塑料底座，作者称稳定性和密闭性较好，但更换第三方耳套不便；入耳腔体略大，长时间佩戴体验一般。
- **降噪与透传：**作者报告全频平均降噪深度 36 dB，峰值在 150–300 Hz；50–3000 Hz 较均匀，约 1 kHz 前平均接近 40 dB，至 3 kHz 接近 35 dB，主动降噪频宽约 5 kHz。高频有小幅增噪。透传曲线整体较贴合，2000–8000 Hz 附近有小幅波动。原帖有配图但尚未读取，正文未提供完整测试条件。
- **调音与听感：**帖子称新增等响曲线补偿；开启降噪后频响有小幅变化，作者认为对音质影响不明显。以 JM1 为参考，整体接近参考曲线；2000–4000 Hz 补偿峰略低，4000–8000 Hz 略有增益。作者评价为均衡、客观还原。
- **编码与设备适配：**帖子列出 AAC，并称非三星手机最高支持 AAC；作者还称不支持双设备连接。未提供设备与软件版本细节。
- **作者结论：**降噪、透传与调音评价较好；非三星设备支持是作者指出的限制。推荐评级 A；作者称三星用户或价格降至约 1200 时可评为 A+。

## 有线耳机与头戴耳机

### 飞傲 JT9

- **结构：**采用与 FT1 Pro 同款的蓝宝石与铝双镀层 1 μm 振膜。耳机重 368 g，较 JT7 重；作者称夹持力较小、佩戴舒适度尚可。耳罩由 JT7 的倾斜、较厚设计改为对称、较薄；拆下耳罩后可见内侧模具有不规则凸出。作者猜测该结构可能用于减少低频泄漏，这不是已证实的设计说明。
- **频响：**以倾斜扩散场为参考，作者描述 50 Hz 左右开始滚降；20–1000 Hz 较平直；1000–2500 Hz 有凹陷；补偿峰及其后高频增益偏高，滚降较平滑。作者认为其偏均衡、略两头翘、强调解析。
- **听感与驱动：**作者称相较 JT7 更容易驱动，在 DX1ii 下也有不错的动态和信息量。低频更突出、更硬朗，高频线条感与穿透力更强；中频人声更靠后、较易被乐器遮挡，齿音更明显。声场更贴耳，纵向表现较差。
- **型号比较与结论：**作者认为 JT9 是更易驱动、较动感且素质略高的改款，不是 JT7 的全面上位；已有合适前端与配件的 JT7 用户未必需要更换。帖子推荐评级 A+。

### 水月雨 竹3

- **结构与佩戴：**腔体面板由外凸改为内凹并开有泄压孔；单耳重 7.6 g，作者称腔体较小、佩戴舒适度不错。作者提醒该腔体设计不适合深插，实际佩戴较容易出现明显 Peak；原帖未提供佩戴深度和测量图。
- **频响：**以倾斜扩散场为参考。100–300 Hz 增益明显，作者认为会使中低频乐器前移、低频混响增加，但削弱纵深和分离度；400–1000 Hz 削减，使中频乐器及较高音调人声略远、厚度减弱；4–10 kHz 增益略低且滚降平滑；10–20 kHz 有一处 Q 值较低、增益略高的峰，可能增加空气感，也可能带来金属感与砂砾感。整体偏中低频、克制高频并强调动态。
- **代际差异：**相较竹2，竹3的低频与中低频更突出、中高频更收敛；作者认为高频与极高频更平整。个人听感方面，作者称细节、质感和动态有提升，但人声尤其女声不如竹2突出，整体更厚实澎湃。
- **作者结论：**适合节奏感较强的流行音乐；深插可能出现 Peak，令中频不自然。推荐评级 A。

### 飞傲雪漫天 Nature

- **结构与佩戴：**封闭式头戴，重量 275 g，卡扣式耳罩便于更换。原装耳罩偏薄偏软，作者称耳朵容易碰到单元内壁；更换厚实耳罩可缓解。原帖称单元后腔几乎没有声学处理，并称拆开后观察到这一点。
- **频响问题：**以倾斜扩散场为参考，20–70 Hz 衰减，80–150 Hz 略增；150–500 Hz 有明显衰减谷；500–3000 Hz 接近参考曲线；3000–5000 Hz 略削弱；5000–20000 Hz 滚降平滑、增益略高。作者认为中低频衰减削弱厚度与饱满度、突出声场分离；高频增益可能加重齿音与擦片声刺激。
- **作者提供的优化方向：**
  1. **PEQ：**原帖称提供软件均衡方案，但输入文本没有具体参数，不能据此复现。
  2. **物理调整：**在泄压孔贴 200 目阻尼网，并更换 A 罩。作者称此组合可填补中低频衰减谷、削弱高频并增强人声厚度与质感；原帖没有给出具体贴片位置、材料规格细节或独立复测结果。
- **配件与型号比较：**作者称活动配件可在耳罩与升级线间二选一；活动赠送耳罩改善佩戴，但原帖称它削弱中低频并抬高高频；这与前述阻尼网加 A 罩方案不同，个人更推荐搭配 A 罩。与 EP5、FT1、DT270 Pro 的比较是作者听感，原帖没有提供统一测量数据。
- **作者结论：**作者认为其声场和高频表现突出，但中低频厚度不足；推荐评级 A+。

### 兴戈 SuperMix5

- **结构与单元现象：**混合单元耳塞，类私模腔体体积稍大。作者称敲击腔体时有明显共振感，并推测与骨传导单元振动有关。
- **频响与相位推测：**作者使用 BK5128 测试，报告 100–200 Hz 附近出现较大凹陷；推测可能是骨传导单元横波与其他单元纵向声波产生相位差并抵消。作者同时称实际听感中这一区域没有凹陷，反而有明显增益和更长混响；这是测量观察与听感不一致，具体原因未证实。800–3000 Hz 有一定增益；4–20 kHz 滚降平滑、增益稍低。
- **听感与适用音乐：**作者评价为大体均衡、略凸出中低频，声音温暖、贴耳、宽松，适合华语流行和抒情类音乐。解析与声场表现被作者认为一般，不太适合背景乐器较多的编制或摇滚。
- **调音参照：**帖子称商品页标注 Harman 2019，但作者认为实际调音思路更接近较新的倾斜扩散场。原帖没有附商品页链接或曲线图供复核。
- **作者结论：**推荐评级 A。

## 证据边界

以上记录只复述各帖提供的型号、数值、设置、现象和作者判断。输入没有评论、图像内容、外链或资源链接；文中提及但未提供具体内容的 EQ 方案、测量曲线和配件页面无法从现有材料恢复。不同帖的测量条件未完整说明，不能将其数值直接视为统一条件下的横向实验结果。

## 复用测量记录时的检查顺序

先匹配型号、固件、连接手机、实际协商编码、ANC状态、耳套和佩戴密封；再检查人工耳/耦合器、参考曲线、测试音量、频段及平均方法。这里仅小米帖子描述了五种佩戴紧度取中间值，Sony和SuperMix5文字提到BK5128；其他条件缺失，不能拿同为36dB就认定三个型号降噪完全相同。PEQ图未读时，不补造频率、增益和Q值。

JT9原帖高频范围写成 `3000~1000Hz`，上下界倒置；这里只保留其高频增益偏高的定性报告，不擅自改成另一个上限。SuperMix5的横波/纵波相消解释属于原作者猜测，未凭频响图证明因果。
