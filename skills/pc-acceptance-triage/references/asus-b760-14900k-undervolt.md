# 华硕 B760-G 小吹雪 S 搭配 i9-14900K 降压记录

## 配置与兼容体验

原帖配置清单写为：Intel Core i9-14900K；华硕 ROG STRIX B760-G GAMING WIFI 小吹雪 S（正文另写完整名称 ROG STRIX B760-G GAMING WIFI S）；NVIDIA RTX480 Founders Edition；希捷酷鱼 530 2TB 与酷玩 520 1TB；金百达 DDR5 6800 24GB×2；华硕 ROG STRIX 吹雪 1000W 金牌全模组电源；爱国者星璨岚 M-ATX 机箱；Tt TOUGHLIQUID Ultra 360 一体水冷和振华 MEGACOOL 12cm 风扇。原帖后文将显卡明确写为公版 RTX 4080，因此配置行“RTX480”与后文不一致，本文保留此处差异，不擅自改写为同一型号。作者称处理器也可换 i7-14700K。

作者选择 B760 是因为其认为 14 代 i9 默频功耗已高且不再需要超频，搭配降压可获得接近其 Z790 使用体验。主板部分描述 12+1+1 供电、两个带散热装甲的 M.2 插槽、BIOS FlashBack、Wi-Fi 6E、2.5G 网口、20Gbps USB-C、雷电 4 插针及显卡易拆按键。水冷装机经验：先接好 `CPU_FAN` 和 `AIO_PUMP`，再固定冷排，避免冷排遮挡接口。

## 内存、SSD 与电源数据

原帖称金百达白刃 RGB DDR5 6800 48GB（24GB×2）使用 SK 海力士 M-Die，单面 8 颗、每颗 3GB；作者在 6800 MT/s 下报告稳定运行，并称主板中设置至 7200 MT/s 后可正常运行。原帖报告 6800 时读写超过 100GB/s；7200 时接近 110GB/s、延迟降低 2.1ns，鲁大师内存分约 42.7 万。具体跑分图未提供可读数据。

两块 PCIe 4.0 SSD 的原帖结果：

- 希捷酷鱼 530 2TB：作者称采用 Toshiba BiCS6 162 层 TLC。CrystalDiskMark 8 顺序读写 7050.848/6583.73 MB/s；35GB 文件 FastCopy 平均写入 5700MB/s。
- 希捷酷玩 520 1TB：作者称颗粒编号 HABHG95AXA，为 SK hynix 176 层 TLC。CrystalDiskMark 8 顺序读写 5210.8/4844.65 MB/s，单线程 4K 随机写入 395.42MB/s；35GB 文件 FastCopy 平均写入 4836MB/s。

原帖称两款 SSD 均为 5 年质保，1TB 版本 600TBW、2TB 版本 1200TBW；并报告更换主板后沿用原系统盘、无需重装系统，系统自动下载了主板驱动和控制软件。该结果属于单次装机报告。

电源部分原帖称支持 ATX 3.0，80 PLUS 金牌；在 220V、50% 负载下效率 91.5%，低负载和满载时均超过 89%；具备原生 PCIe 5.0 接口和额定 600W 的 12VHPWR 线材，并称负载低于 60% 时风扇停转。以上规格按文章记录，未独立验证。

## BIOS 更新与降压步骤

作者使用华硕 ROG STRIX B760-G GAMING WIFI S，下载 BIOS 1645 作为示例。原帖提醒不要选择描述中带有 `Intel Baseline Profile option` 字样的 BIOS 版本。文章未提供 BIOS 文件 URL，也未说明该建议适用于其他 BIOS 版本或主板。

更新步骤：将 BIOS 文件放入 U 盘，插入电脑并重启，按 `DEL` 进入 BIOS；按 `F7` 进入高级模式，在工具中选择“华硕升级BIOS应用程序3”，选中 U 盘中的 BIOS 文件并按提示更新。

降压设置：

1. BIOS 中按 `F7` 进入高级模式，进入 `Ai Tweaker > Tweaker's Paradise`。
2. 在 `Switch Microcode` 选择 `0x104 Microcode`。
3. 返回 `Ai Tweaker`，打开 `Global Core SVID Voltage`，选择 `Offset Mode`。
4. `Offset Mode Sign` 选择 `-`；原帖警告选择 `+` 会增加电压。
5. 在 `Offset Voltage` 中从 `0.08` 开始输入负向偏移，原帖建议范围为 `0.08–0.2`，单位 V。作者最终设为 `0.18V` 并报告稳定运行。

原帖没有给出 BIOS 完整版本列表、芯片个体差异、电压监控读数或稳定性测试时长；降压结果不能直接视为其他处理器的稳定参数。

## 降压前后原帖结果

- Cinebench R23：降压后 37198 分；作者称半年前标准模式成绩为 36346 分。
- Prime95 降压前：功耗超过 330W，CPU 温度达到 99℃并持续；作者观察到多个核心未满载，推测温度导致降频。
- 降压后：核心温度约 90℃，功耗约 270–290W。

这些是原帖在其硬件和设置下报告的结果；测试时长、Prime95 参数、室温及功耗测量方式未说明。原帖称降压后性能没有可见损失且更稳定，不代表其他系统能达到相同结果。
