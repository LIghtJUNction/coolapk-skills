# 宏碁掠夺者 Vesta II DDR5 RGB 7200：8000MT/s 超频记录

## 来源与证据边界
来源：[酷安原帖](https://www.coolapk.com/feed/51575907)，发表于 2023 年。以下配置、测试与稳定性均为原帖报告；图片中的设置细节未提供可读取文本，因此不能补写未见的 BIOS 参数。

## 平台与内存
- 处理器：Intel Core i9-14900K；主板：技嘉冰雕 X Z790；显卡：公版 RTX 4080。
- 内存：宏碁掠夺者 Vesta II DDR5 RGB 7200，原帖称使用 SK Hynix A-Die；单根约 77 克，套条标记为 019B、019C。
- 原帖称该型号支持 XMP 3.0、主流主板厂商 RGB 同步；XMP 规格为 7200MT/s、CL34。

游戏测试为 1080p、最高画质。原帖报告称 8000MT/s 下鲁大师 CPU 测试因过热失败，因此只引用内存分数；未给出温度、内存压力测试种类、测试时长或错误检查结果。作者称 8000MT/s 稳定运行，但这是单一平台的自述，不能视为对其他 CPU、主板或内存套条的保证。

## 原帖给出的调试顺序
1. 先启用 XMP，并确认系统运行正常。
2. 重启进入 BIOS，再手动提高频率。
3. 原帖建议初始时把 tRAS 设宽松些，例如从 100 开始，确认稳定后逐步降低；作者自己的 8000MT/s 设置为 90，并称另有玩家能压到 56 或更低。
4. 每次稳定后保存 BIOS 设置；超频失败时载入已保存设置，减少重复操作。
5. 原帖提醒稳定性取决于主板、CPU、颗粒体质及散热；散热较弱的内存可能需要改善机箱风道或加装风扇。

原帖称其技嘉主板给出的 CPU“饼干分”为 91，并推测 8266MT/s 可能可行，但没有提供该频率的实测结果。文中没有逐项列出达到 8000MT/s 所需的电压、完整小参或 BIOS 版本，不能据此复原完整超频配置。
