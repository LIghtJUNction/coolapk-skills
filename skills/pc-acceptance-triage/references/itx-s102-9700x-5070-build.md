# 机械大师 S102 + Ryzen 7 9700X / RTX 5070 ITX 装机记录

## 机箱与配置

作者报告机械大师 S102 为显卡倒装结构，最大可安装约 21cm 长的双槽显卡；所用 RTX 5070 Mini 长约 18cm。机箱左侧盖板拆下可接触主板背部 M.2 位，底部有搬运开孔和电源、机箱进气空间。作者称机箱电源仓只容纳 SFX 规格电源。

| 部件 | 原帖型号与价格 |
|---|---|
| CPU | Ryzen 7 9700X，1500 元 |
| 主板 | 铭瑄 B650i MS-esports，600 元 |
| 内存 | 佰维 DW100 DDR5-6000 C28，16GB×2，约 2000 元 |
| 显卡 | RTX 5070 Mini，4964 元 |
| SSD | 致态 TiPlus7100 4TB，约 3000 元 |
| 机箱 | 机械大师 S102，约 540 元 |
| 电源 | 追风者 REVOLT SFX 850W，约 900 元 |
| CPU 散热器 | 利民 AXP90-47 纯铜版，约 200 元 |
| 机箱风扇 | 利民 TL-B8 两把，共 67 元 |

作者称 CPU 游戏、办公和轻创作够用，约 100W 级功耗适合小机箱；其选用 32GB 内存与 4TB SSD。原帖推荐另可考虑利民 SS135 或机械大师 KK135，但未提供该推荐散热器的测试数据。REVOLT SFX 850W 被描述为全日系电容、白金认证、10 年质保；电源配短线便于 ITX 理线，但显卡倒装时原装 16-pin 短线够不到，作者另换长线。装机时应确认显卡供电线自然弯曲，避免线材抵住侧板。

## 装机顺序

作者先在机箱外完成主板平台：安装 CPU、内存、SSD 与散热器，再整体装入机箱。AXP90-47 需从主板背面用螺母固定；安装下压式散热器时要注意鳍片方向，避开内存与主板接口。电源建议尽早安装并预先接好线材，布线时避免遮挡风扇或顶住侧板。

## 温度与性能测试

CPU 与 GPU 双烤使用 AIDA64 FPU 和 Furmark 同时运行。关闭玻璃侧板进行 15 分钟测试时，作者报告 CPU、GPU 均约 80°C，CPU 功耗稳定在 115W 以上，显卡约 250W。拆下玻璃侧板后 CPU 温度下降约 3°C，GPU 温度未下降。该结果是单台机器、单次报告，原文未列室温、风扇转速或完整传感器数据。

作者报告 CPU-Z 单核 859、多核 7623；Cinebench R23 多核 19159、单核 2173。作者与此前将 9700X 限制在 90W 的小鞋盒配置比较，称多核分别增加约 500 分（CPU-Z）与 2000 分（R23），但对比条件未完整列明。3DMark 的 Time Spy Extreme、Fire Strike Extreme、Port Royal、Steel Nomad 四项正文未给出具体分数；作者称较此前半高 RTX 5060 配置高 57%–70%。

## 游戏结果（作者报告）

- 《极限竞速：地平线 6》：2K 高画质、关闭光追与 DLSS，原生 83.3 FPS；超高画质、开启光追，DLSS 与帧生成设为自动，报告 93.9 FPS；4K 同类设置约 60 FPS，作者观察到明显残像。3840×2560 下遇到 12GB 显存不足提示，降低画质后未再遇到。
- 《CS2》：2K 中画质平均 561 FPS、1% low 232；1080P 中画质平均 722 FPS、1% low 252。作者称 CPU 未超频、内存仅开启 EXPO。
- 《生化危机：安魂曲》：2K、路径追踪、最高预设、DLSS 性能档、2 倍帧生成，平均 103 FPS、1% low 48。
- 《黑神话：悟空》：预设超高、超采样 75、DLSS 与帧生成开启，报告平均 116 FPS、最低 100；4K、超采样 41、DLSS 与帧生成开启，其余超高，平均 88 FPS、最低 78。
- 《赛博朋克 2077》：高画质、关闭 DLSS 与帧生成，平均 165 FPS、最低 139；光追超级且关闭帧生成与 DLSS，平均 86 FPS、最低 77。

这些成绩均为原帖报告，文章未完整给出驱动、游戏版本、帧生成模式定义、测试场景和环境条件，不宜视为其他机器的保证值。
