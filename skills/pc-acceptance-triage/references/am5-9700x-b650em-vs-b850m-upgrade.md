# AM5 平台（9700X）升级与华硕 TUF B650EM vs B850M 取舍

- **来源**：[酷安原帖](https://www.coolapk.com/feed/73693238)（`imgs=9`）
- **选型对照**：
  - CPU 选用 65W TDP 的 Ryzen 7 9700X（看重 AM5 接口官方延续支持周期），面向网游、Lightroom 后期与轻度剪映剪辑。
  - 主板对比 `TUF GAMING B650EM-PLUS WIFI` 与 `TUF GAMING B850M-PLUS WIFI`：B650EM 板 U 套装便宜 200 余元，供电为 `12+2+1 相（80A）`（B850M 为 `14+2+1 相 80A`），主 PCIe x16 位于第一槽位，同样提供 3 个 M.2（1×5.0 + 2×4.0）；相比 B850M 主要缩减了音频芯片（标准 7.1 vs 瑞昱 `ALC1220P`）、后置 USB 数量（8 vs 12）与前置 USB-C 速率（5Gbps vs 10Gbps），对无高频多外设/音频刚需的场景性价比更高。
