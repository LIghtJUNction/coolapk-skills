# CPCS：关键路径与预算分配

CPCS 尝试由上一帧的线程依赖链预测下一帧瓶颈，把 FAS 总预算分配给各 CPU 集群。找关键链会考虑执行、同步及调度等待；算权重则只累计链上执行时间。

它依赖帧行为重复，以及固定计算量下执行时间近似反比于频率。非游戏负载关键链分散时可能不适用；文中集成在未公开分支，没有完整参数或量化收益。

若指标是耗时且 CPU 为瓶颈，超时应评估增加预算，不能照抄原文的超时降性能说明。这是对文字解释的纠正，不能证明未公开代码也写反。
