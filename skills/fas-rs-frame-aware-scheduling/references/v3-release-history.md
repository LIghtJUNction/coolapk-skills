# fas-rs：Android 帧感知调度的版本演进

fas-rs 是运行在 Android 上的帧感知调度项目。以下内容来自三个版本帖中的更新日志；日志没有提供完整实现说明、受支持机型列表或硬件测试数据，因此不能据此推断具体设备上的效果。

## v3.1.0

- 增加 Oplus 相关 workaround，并修复部分 Oplus 机型卡屏问题。日志未列出受影响或验证通过的具体机型。
- 最小频率控制改为按负载决定目标集群，并加入自动识别控制哪个集群最小频率的功能；日志也记录删除 `controll_min_freq` 开关及只控制 prime 集群最小频率。它同时列有自动选择集群与仅 prime 两类提交，未核对具体源码和先后关系，不能据此认定最终版本同时采用两套规则。
- 在打开文件前尝试卸载 mount bind，并在打开文件前设置可写权限；还修复可能写入无效频率的问题。日志没有列出文件路径或具体命令。
- 修复 `os error 22`，并更新 README。

## v3.3.0

- 日志记录不控制小核最小频率，并优化参数。
- 增加非标准目标帧率兼容性；优化 auto offset 算法、CPU 分析器、卡顿（jank）算法和权重分析器。
- auto offset 按模式设置因子，并按幂缩放、归一化扩大效果；仅在线程放置正确时启用 offset。更新日志没有给出因子数值、模式定义或线程放置判定细节。
- 调整 jank 检查间隔，采用更合理的 cycles 跟踪；使用 mimalloc，并以无锁结构优化配置性能。
- 修复可能的 panic、切换无锁结构后 binder 版本编译失败，以及部分 Oplus 机型卡屏。

## v3.8.0（Silver Silence）

- 日志还记录降低 restart analyzer 开销、补齐文档中缺省配置值的标记。
- 温控逻辑改为基于目标频率控制，并提供关闭温控的功能；优化核心温控逻辑。日志没有给出温度阈值、目标频率或默认配置值。
- 将 PID 控制改为 P 控制，移除 PID 残留代码和进化算法；移除按目标 FPS 统一变化频率速度的逻辑，并缩短进化间隔（此项描述来自日志，未说明其与移除进化算法之间的具体关系）。
- 不再强制忽略 policy0；写入频率时增加 clamp。修复 Oplus 插帧时频率偏向高频的问题。
- 修复卸载时可能误删其他文件、数据库语句错误，以及非 nightly Rust toolchain 无法构建的问题。
- 日志时间精确到秒；release 编译时去除本地编译路径信息。
