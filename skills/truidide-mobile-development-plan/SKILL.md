# TruidIDE：Android 本地开发环境计划

帖子将 TruidIDE 描述为正在开发的 Android 手机本地开发环境，并列出计划功能：

- 面向移动端优化的 UI 布局
- 基于 proot 的完整 Arch Linux ARM 运行环境
- 内嵌终端
- 网页开发服务器预览
- 插件扩展
- 语言服务器插件支持
- 语法高亮插件支持

这些内容在原帖中是开发计划；帖子没有说明哪些功能已经完成，也没有提供仓库、下载地址或版本号。帖子含 6 张截图，本整理未读取图片，因此不据此补充功能或进度。
