# Android 设备案例

## Samsung Galaxy S23 Ultra：原帖所称“偷渡 8.5”

原帖：[S23U 更新教程](https://www.coolapk.com/feed/71072046)。步骤和条件按原帖记录，不代表当前版本适配保证：

- 原帖要求已安装 ZB6 更新，并称最新 ZC1 不行；将适用版本描述为“第一个基带 7 的更新，3 月初那版”，并称有且仅有这一版可以刷到 8.5。
- 不满足该条件时，原帖称只能用 Odin 刷 ZB6 四件套，且不保留数据。
- 原帖步骤：安装 Shizuku 和 sideloadopen；把系统包移动到根目录；点击粉色按钮授权；在弹出的新界面点击第二项，等待运行完成并重启。
- 原帖报告第二版已知 Bug：系统分享无法使用，凡是弹出与分享有关的操作都不行。
- 原帖提醒回到正式版需要清数据。

## iQOO 10（Origin4）：临时 root 修改 devinfo 解锁

原帖：[iQOO 10 临时 root 解锁教程](https://www.coolapk.com/feed/74915679)。作者把方法限定为 iQOO 10（Origin4）实机步骤，并称理论上只要有临时 root，其他系统版本也可能适用；这不是其他版本已验证保证。该过程会清除数据，原帖要求提前备份。以下仅作来源记录，不执行：

1. 下载 Scene，授予 root 权限并打开。进入顶部“功能”→“进阶功能”→“备份还原”→“备份分区镜像”；搜索并选择 `devinfo`，确认后导出到 `/sdcard`（共享存储根目录，不是Linux系统的 `/`）。
2. 在 MT 管理器找到 `devinfo.img`，长按选择“打开方式”→“十六进制打开”。原帖描述将第二排第 5、6 个 `00 00` 改为 `01 01`，并要求保存前确认末尾是 `21 01 01 01`。这是原帖的界面相对位置描述，不是对所有镜像或版本通用的绝对字节偏移。
3. 回到 Scene 的“备份还原”，选择“刷入分区镜像”，将修改后的 `devinfo.img` 刷入 `devinfo` 分区后重启。原帖称启动过程中会多次重启；出现数据损坏、要求清除数据的界面时选择清除数据，之后可重新进入系统。清除会丢失数据，需事先备份。
4. 原帖给出的可选电脑核验命令：`fastboot oem device-info`。其所述成功显示项为 `Device unlocked: true` 和 `Device critical unlocked:true`。
5. 原帖随后描述使用临时 root 与 Scene 刷入 KSU 修补后的 boot；在 KSU 修补时弹出 KMI 选择 `Android12-5.10`。这是该来源中的设备案例，不是对所有设备或版本的保证。

来源没有提供镜像 URL，也没有完整救砖流程；此处不补写。
