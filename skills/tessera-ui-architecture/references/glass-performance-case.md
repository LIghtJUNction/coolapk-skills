# Tessera UI 玻璃组件性能记录

原帖称 Tessera UI 的玻璃组件在移动端性能上“基本可用”，但大面积玻璃与高斯模糊仍需优化开销。原帖观察到：大量使用时勉强可达 120 帧；小面积玻璃组件没有明显性能问题；插件式渲染架构改进后，多个小组件的开销没有高于相同总面积的组件。

这些是原帖报告的观察，未提供测试机型、系统版本、测量方法或可复现基准，不能视为普遍性能保证。帖子含 6 张图片，但图片内容未提供；不据此补充组件外观或测试条件。
