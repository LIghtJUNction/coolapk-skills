# 用 Android 设备通过 OTG 刷入 Root 镜像或执行小米线刷

来源：https://www.coolapk.com/feed/68694686

> 这是来源帖所述流程的整理。刷机有风险，操作前备份数据，并确认 OTG 连接稳定。小米线刷流程会清除数据。目标设备执行这些操作前必须已解锁 bootloader。

## 适用设备与准备

需要两台手机或平板：一台作为操作端，另一台作为刷入目标；目标设备必须已解锁 bootloader。作者建议操作端也解锁。准备一条能稳定读取已连接设备的 OTG 数据线。

目标设备的 boot 或 init_boot 镜像应对应其当前软件版本。帖子建议在目标设备的“设置 / 关于手机 / 版本信息”查看版本，再下载对应全量包提取镜像，或在线提取。之后在目标设备安装所需的 Root 管理器（例如阿尔法或 KSU），用它修补 boot/init_boot；修补日志会显示生成文件的路径。把修补后的镜像传到操作端，供后续刷入。

## 流程一：不需要操作端 Root，使用甲壳虫

1. 在操作端安装甲壳虫。帖子给出的下载入口是公开分享链接：https://www.123865.com/s/kHrfvd-XgIq3 ，提取码：`H1sO`。帖子正文对甲壳虫和 Termux 使用同一下载入口，但没有说明该分享中各文件的具体名称或版本。
2. 让目标设备关机，按住音量下键和电源键进入 fastboot 模式，再用 OTG 线连接操作端。
3. 打开甲壳虫，点击右上角闪电图标进入设备连接界面。帖子称连接后会显示对应模式；确认识别到目标设备后继续。
4. 选择要写入的分区。boot 镜像选择 `boot`；若写入 `init_boot`，在自定义分区中输入 `init_boot`。
5. 在镜像文件路径选择器中找到之前已修补并传到操作端的镜像，开始刷入。帖子描述刷入弹窗会显示进度，所有结果显示 `OK` 即为成功。
6. 确认写入成功后重启目标设备。

## 流程二：操作端已有 Root，使用 Termux 和 fastboot

1. 在已有 Root 的操作端安装 Termux。帖子给出的下载入口同上：https://www.123865.com/s/kHrfvd-XgIq3 ，提取码：`H1sO`。
2. 安装帖子所称的“刷入我模块”，可用任意 Root 管理器刷入。作者称模块刷入较慢；刷入完成后重启，再打开管理器确认模块已生效。帖中没有给出模块名称、版本、项目页或独立下载地址，无法据此确定具体模块。
3. 给 Termux 授予 Root 权限，打开 Termux 输入：

   ```sh
   su
   ```

4. 按前述方法为目标设备的软件版本取得 boot/init_boot 镜像，并在目标设备的 Root 管理器中修补；把修补结果传到操作端。
5. 使目标设备进入 fastboot 模式并通过 OTG 连接操作端。在 Termux 输入：

   ```sh
   fastboot devices
   ```

   帖子称若连接正常，输出会包含设备序列号和对应模式。若没有识别结果，先不要执行刷写命令。
6. 用文件管理器（帖子举例 MT 管理器）找到修补后的镜像，查看属性并复制完整路径。作者提示，如果一次复制出来的路径不完整，可先复制目录，再复制文件名，随后在 Termux 中拼接。
7. 刷入 boot：

   ```sh
   fastboot flash boot 你的路径地址
   ```

   帖子称看到两个 `OK` 即为成功。刷入 init_boot 时把命令中的 `boot` 换为 `init_boot`；作者也说明可以替换成其他分区名，但没有提供其他分区的适用性说明。
8. 确认刷入完成后重启：

   ```sh
   fastboot reboot
   ```

   也可以手动重启。

## 小米设备线刷：已解锁 bootloader、没有电脑

此流程针对已解锁 bootloader 的小米设备。原帖给出域名 `xiaomirom.com`；本页为便于点击补为 https://xiaomirom.com ，协议为整理补全，不代表官方归属已核验。先在另一台设备下载并解压目标机型对应的线刷包；之后把目标设备置于 FASTBOOT 模式，通过 OTG 连接已有 Root 的操作端。

1. 打开 Termux，输入 `su` 获取 Root shell。
2. 检查设备连接：

   ```sh
   fastboot devices
   ```

3. 用文件管理器找到**已经解压的线刷包文件夹**，复制文件夹完整路径。帖子特别指出，`cd` 的目标是解压后的文件夹目录，不是压缩包文件；若路径复制不完整，可先复制目录、再复制名称。
4. 在 Termux 中切换到该目录：

   ```sh
   cd 线刷包文件夹完整路径
   ```

5. 执行线刷包自带的脚本：

   ```sh
   fastboot_all.sh
   ```

   帖子说明这是线刷包内的脚本，并称该脚本会清除数据但不会回锁 bootloader；若需要回锁，应使用包内相应的回锁脚本。来源没有提供该脚本的内容、参数、适配机型清单或回锁命令的准确文件名。
6. 帖子称线刷完成后设备会自动开机。
