# 穿越火线：枪战王者分辨率选项

帖文称，超清和极清选项需要使用标识为“红米电竞平板3Pro”的改机型模块才能开启。该条件是原帖描述，未提供模块链接或独立验证。

## 分辨率示例与复算

原帖假设设备为 `1080×2460`，把长宽比写为 `2.277`。原帖给出的结果并不能全部由这一截断比例与同一种向下取整规则得到：

| 画质 | 原帖分辨率 | 保留完整比例 `2460/1080` 后计算的高度 | 用截断比例 `2.277` 计算的高度 |
|---|---|---:|---:|
| 性能 | `640×1457` | 1457 | 1457 |
| 平衡 | `720×1639` | 1640 | 1639 |
| 高清 | `971×2211` | 2211 | 2210 |
| 超清 | `1079×2457` | 2457 | 2456 |
| 极清 | `1080×2460` | 原设备高度 2460 | 不适用 |

复算只是数学检查，不是游戏实测。原帖表混合了精度，不能把它当通用分辨率公式；2K/4K 屏或其他游戏版本的输出也需另测。完整比例计算为 `floor(宽度×2460/1080)`。

## 查看与调整分辨率

帖文给出的 shell 检查命令：

```sh
dumpsys SurfaceFlinger | grep com.tencent.tmgp.cf
```

帖文称可用以下命令修改设备分辨率后进入游戏测试：

```sh
wm size WxH
```

其中 `WxH` 是待设置的分辨率格式。恢复原始分辨率：

```sh
wm size reset
```

原帖没有说明是否需要 root、命令在哪种 shell 中执行，也没有提供配图中的输出细节。
